# D13 実装指示文：浮かぶ乗りもので巨木の森を抜ける

## 0. 実装の基本方針

5歳の女の子が、葉の形をした浮遊艇に乗り、朝日の差し込む巨木の森から、果てしない雲海の上へと旅をする、写真のような写実3Dウェブゲームを実装してください。

プレイヤーが光る種に触れるたびに、何もなかった空中に岩の島が生まれ、根が伸び、木が育ち、浮遊艇がさらに高い場所へ進んでいきます。

このゲームで最も重要なのは、**自分の指先から新しい世界が生まれ、その世界を自分の乗りもので旅していく感覚**です。

単なる飛行鑑賞アプリや、光るものを集めるだけのゲームにはしないでください。種へのタップが地形の誕生、植物の成長、浮遊艇の移動、景色の変化に直接つながるようにしてください。

人物のモデルは登場させません。浮遊艇の斜め後方からの視点によって、プレイヤー自身が乗っている感覚を表現してください。

## 1. ゲームの狙い

- **夢×写実：** 空中を進む葉の形の浮遊艇と、種から誕生する浮き島という夢の世界を、本物らしい樹皮、苔、岩石、葉脈、木漏れ日によって現実に存在するかのように感じさせる。
- **高揚感：** 巨木に囲まれた森の低層から徐々に高度を上げ、樹冠を突き抜け、最後には壮大な雲海と浮き島の世界へ到達する喜びを生み出す。
- **爽快感：** 巨木の間を滑るように通り抜け、視界が一気に開ける瞬間と、自分が育てた島々の上を飛び越えていく気持ちよさを体験させる。

美しい景色だけで満足せず、「次の種に触れたい」「次はどんな島ができるのだろう」「もっと高い場所へ行きたい」という期待が途切れないゲームにしてください。

## 2. 元にした絵から借りる光と色

### 2.1. 美術的な方向性

提示されたB8・B9の作品説明から、以下の要素だけを借りてください。

- 実在する樹木や岩石を観察して作ったような自然の造形。
- 空中に浮かぶ岩の島と、その上に根を張る植物。
- 自然の造形を取り入れた浮遊艇。
- 光に満ちた、希望と解放感のある空間。
- 現実と想像の境界が溶け合う世界。
- ファンタジー映画のような魔法の光と、未知の景色に出会う驚き。

元の作品の構図、樹木の配置、乗りものの具体的な形状、絵柄は再現せず、独自の3D世界を構築してください。参照対象は提示された作品説明に限ります。

### 2.2. 段階ごとの色彩と照明

全編を朝から午前中の時間帯とし、上昇するにつれて空の見える面積、空気の透明感、太陽光の存在感を増してください。

以下は、Three.jsにおける初期調整値の目安です。単位は1 world unit＝約1mとします。

| 項目 | 第1段階：巨木の森 | 第2段階：樹冠への上昇 | 第3段階：雲海 | 第4段階：天空の庭園 |
|---|---|---|---|---|
| 天頂の空 | `#76B9DC` | `#65BCEB` | `#429FE3` | `#348BD6` |
| 地平線付近 | `#FFF1C5` | `#FFF4D5` | `#E4F8FF` | `#FFF5D8` |
| 太陽光 | `#FFE2B1` | `#FFEBC8` | `#FFF5E6` | `#FFF0CA` |
| 太陽の色温度 | 4300K | 4900K | 5700K | 5200K |
| DirectionalLight強度 | 2.0 | 2.4 | 2.8 | 3.0 |
| HemisphereLight強度 | 1.4 | 1.6 | 1.8 | 1.9 |
| 霧の色 | `#C7E0D1` | `#D2EDF1` | `#E3F5FF` | `#E9F6FF` |
| Fog near / far | 18 / 140 | 30 / 220 | 70 / 420 | 100 / 550 |
| Bloom strength | 0.24 | 0.30 | 0.38 | 0.45 |

色温度は光源色を決めるための目安であり、Three.jsでは対応するRGB色を使用してください。

レンダリングにはACESFilmicToneMapping、sRGB出力を使用し、toneMappingExposureは1.0〜1.25を初期値としてください。ポストエフェクト使用時は色変換やトーンマッピングを二重に適用しないでください。

### 2.3. 光の演出

森の中では、枝葉の隙間から斜めに差し込む光の筋を表現してください。実際の高負荷なボリュームレンダリングではなく、透過メッシュや深度を考慮した簡易シェーダーによって再現します。

光の筋には微細な花粉や水滴が漂い、浮遊艇が通過すると空気の流れに沿って動きます。

種は内部に金色または青緑色の光を持ち、表面には植物らしい繊維と半透明感を残してください。Bloomのthresholdは0.85〜1.0程度を目安とし、風景全体ではなく発光体を中心に作用させます。

夜や夕闇への移行は不要です。森の内部でも黒くつぶれた領域を作らず、葉や岩の質感を十分に視認できるようにしてください。

## 3. 舞台と登場するもの

すべての3Dモデル、テクスチャ、背景、エフェクトをプロシージャル生成してください。外部の画像・3Dモデル・音声ファイルは使用しません。

### 3.1. 巨木の森

森の主役は、樹高25〜65m程度の巨大な樹木です。プレイヤーが樹木の巨大さを実感できるように、浮遊艇との大きさの対比を重視してください。

樹木は以下の方法で生成します。

- 幹は曲線に沿って断面の形状と半径を変化させたメッシュとする。
- 幹の太さ、傾き、枝分かれ、根の広がりに個体差を持たせる。
- 樹皮には複数スケールのノイズを使い、縦方向の溝、ひび割れ、色むらを表現する。
- 根は地表に沿って広がり、一部が苔や土に覆われるようにする。
- 葉は単純な球体の集合ではなく、大小の枝と葉の集団によって樹冠を形成する。
- 手前の樹木ほど精密にし、遠方では簡略化したメッシュを使用する。

樹皮には `#69513B`、`#89715A`、`#473C30`、苔には `#426B30`、`#759644`、葉には `#398443`、`#73AD42`、`#A7C761` を使用してください。

MeshStandardMaterialを基本とし、樹皮のroughnessは0.85〜0.95、metalnessは0とします。ノイズから生成した法線テクスチャによって微細な凹凸を表現してください。

森全体を同じ緑色にせず、新芽、成葉、日光を透過する葉、日陰の葉を描き分けます。

### 3.2. 浮遊艇

プレイヤーが乗る浮遊艇は、巨大な一枚の葉を自然素材の船に仕立てた、独自のデザインとしてください。

全長3.2m、幅1.6m程度を目安とします。

- 船体は先端が上を向いた流線形。
- 葉の中央には太い葉脈が通り、左右に細い葉脈が分岐する。
- 足元には平坦な木製の床があり、実際に立てそうな構造を持つ。
- 船体の縁は適度に反り返り、乗りものとしての安心感を表現する。
- 船体の下には青緑色の微細な発光粒子が流れる。
- 推進時には後方へ細い金色の光の航跡を残す。

葉の色は `#598A35`、葉脈は `#A1C56E`、木製床は `#B88D59`、推進光は `#8FEBDD` を基調とします。

葉のroughnessは0.35〜0.55程度とし、表面の微細な起伏と光沢を表現してください。

停止時には上下に約0.05〜0.10m、周期3〜5秒で浮遊します。飛行時の船体の傾きは最大5度程度とし、激しく揺らさないでください。

### 3.3. 光る種

光る種は、毎回プレイヤーが直接触る最重要オブジェクトです。

- 長径0.7〜1.0m程度の植物の種。
- 半透明の外皮と、内部に見える発光する核。
- 表面には細い繊維や植物の模様。
- 周囲に8〜16個程度の微細な光粒子。
- ゆっくりした回転と、周期1.5〜2秒の発光の変化。

種の基本色は琥珀色 `#FFC65C`、内部光は `#FFF4BA` とします。段階が進むにつれて、エメラルド、桃色、青紫、金色などの変化を加えてください。

種を単なる発光球にせず、ここから植物が育つことを想像できる形状にしてください。

### 3.4. 種から生まれる浮き島

浮き島は、岩石、土、根、草木が一体となった自然の地形です。

島の生成には、頂点をノイズで変形させた岩石メッシュを使用します。上面には土と草地を作り、側面には岩石の地層、亀裂、苔を配置してください。底部は不規則な岩が下方向に伸び、大小の根が垂れ下がります。

球体に草を載せただけの形状は避けてください。

| 段階 | 島の直径 | 島に育つもの |
|---|---:|---|
| 第1段階 | 2.5〜4m | 若木、草、シダ |
| 第2段階 | 4〜6m | 枝の広がった木、花 |
| 第3段階 | 6〜9m | 複数の木、花畑、小さな泉 |
| 第4段階 | 8〜12m | 大樹、花畑、滝、豊かな植生 |
| クライマックス | 20〜26m | 巨大な生命の樹と天空の庭園 |

同じ形状を繰り返さず、島ごとに輪郭、岩の色、木の形、花の色を変化させてください。乱数シードを使い、再プレイ時にも異なる島が育つようにします。

### 3.5. 空、雲海、水

空には大型のスカイドームまたは専用シェーダーを使用し、天頂から地平線まで連続した色の勾配を作ります。

雲海は、複数スケールのノイズを持つ雲のメッシュと、遠方の雲を表現する半透明レイヤーを組み合わせてください。雲を白い球体の集合に見せず、立体感、光の散乱、奥行きを重視します。

第3段階以降、一部の島に小さな泉や滝を配置します。

水面は以下の要素を持つ軽量なシェーダーで表現してください。

- Fresnel効果による視線角度に応じた反射。
- 2方向以上の波による法線のゆらぎ。
- 空の色と太陽光の疑似反射。
- 浅瀬の透明感。
- 水滴と水しぶきの小規模なパーティクル。

水の基本色は `#50BAC8`、反射光は `#DDF8FF` とします。リアルタイムの全面反射処理は必須とせず、性能を優先してください。

滝は島の縁から雲海へ流れ落ちますが、プレイヤー自身が落下する演出は行いません。

### 3.6. 動物

動物はゲームの主役にせず、世界に生命を感じさせる補助要素とします。

森では小さな蝶、樹冠や雲海では白い鳥が時折飛びます。蝶の翅や鳥の翼はプロシージャルメッシュで生成し、関節の回転によって羽ばたきを表現してください。

動物が画面を占有したり、種を隠したり、プレイヤーに向かって急接近したりしないようにします。

## 4. 指1本のゲームループ

### 4.1. 基本ループ

すべての段階で、以下の因果関係を維持してください。

**光る種を見つける → 種に触れる → 島が生まれる → 木が育つ → 浮遊艇が進む → さらに高い場所へ到達する。**

1回の成功を、以下の時間配分で構成します。

| 経過時間 | 画面上の変化 |
|---|---|
| タップ直後〜0.1秒 | 種が発光し、反応音が鳴る |
| 0.1〜0.5秒 | 外皮が開き、光の粒子が広がる |
| 0.5〜1.4秒 | 空中に岩石が集まり、島の形になる |
| 1.0〜2.0秒 | 土と苔が広がり、草が生える |
| 1.4〜2.8秒 | 根、幹、枝、葉が成長する |
| 2.8〜6.5秒 | 浮遊艇が島の上を滑るように通過する |
| 6.5〜8.0秒 | 次の種が前方に現れる |

数値は調整可能ですが、タップへの最初の反応は遅らせないでください。

### 4.2. 島の成長を気持ちよく見せる

島全体を単純にscale 0から1へ拡大するだけでは不十分です。

岩石が集まり、土が覆い、根が伸び、幹が立ち上がり、枝葉が開くという順序を視覚的に認識できるようにしてください。

木の成長は、幹の下部から上部へ進み、枝が順番に伸び、最後に葉が展開するようにします。

完成時には、島の表面を金色の光が波紋状に走り、花粉が上空へ舞い上がります。プレイヤーが自分で島を誕生させたことが、一目で理解できる演出にしてください。

### 4.3. 飛行の手ごたえ

島が完成すると、浮遊艇は自動的に加速します。

浮遊艇の進路は、完成した島の上空を通り、次の種の位置へつながる曲線としてください。

通過時には以下の変化を発生させます。

- 足元を通り過ぎる草や花。
- 浮遊艇の風圧で揺れる葉。
- 後方へ伸びる光の航跡。
- 速度の上昇に連動した風の音。
- 次第に高くなる視点と、広がっていく景色。

種の誕生と飛行は別々のイベントではなく、島が生まれたから前に進めるという一連の体験として表現してください。

### 4.4. 操作しない場合

種が現れてから2〜3秒間操作がなければ、発光を一時的に強め、種の周囲に小さな光の波紋を発生させます。

さらに待った場合は、種がわずかに前後へ動き、内部の光が脈打ちます。

合図は約4秒間隔で繰り返してください。

浮遊艇は種の手前で静かに浮遊し、プレイヤーが触れるまで待ち続けます。種が逃げたり、画面外へ消えたり、制限時間が切れたりしてはいけません。

種以外の場所に触れても、減点、失敗音、警告、やり直しは一切発生させません。

## 5. 盛り上がりの設計

本実装では、全4段階、各6回、合計24回の種の発芽を基本構成とします。

通常のプレイで約3分30秒〜4分30秒を想定します。ただし、操作を待つ時間には上限を設けません。

### 第1段階：巨木の森

**テーマ：最初の命を生み出す。**

開始時の高度は地上約5m。巨大な幹、苔、根、シダ植物に囲まれた場所から出発します。

最初の種は画面中央に大きく表示し、これに触れるだけでゲームが始まるようにします。開始操作を第1回目の発芽として扱います。

小さな浮き島を6つ生み出しながら、巨木の間を通って約20mの高度まで上昇します。

飛行速度は3〜5m/s程度。森の中でも十分な見通しを確保し、木々の巨大さと飛行の楽しさを伝えてください。

### 第2段階：木々の頂上へ

**テーマ：空が近づいてくる。**

高度20〜65m程度。

島の規模が増し、種から育つ木には花が咲くようになります。

浮遊艇は太い枝の間を滑り抜け、葉の隙間から見える青空へ向かいます。飛行速度は5〜8m/s程度まで上げます。

6つ目の島を通過する際には、巨大な樹冠の上へ到達します。前方を覆っていた葉がなくなり、遠方の空と雲海が初めて大きく見えるようにしてください。

ここを中間のクライマックスとします。

### 第3段階：雲海の上の浮き島

**テーマ：世界が一気に広がる。**

高度65〜115m程度。

周囲には白い雲海が広がり、遠くに複数の浮き島が見えます。

新たに生み出す島には、色とりどりの花畑、小さな泉、滝、複数の樹木などが現れます。

飛行速度は8〜11m/s程度。開放された空間を進む爽快感を重視してください。

すでに生み出した島々も、一部が遠方に見えるようにします。自分が世界を作りながら進んできたことを感じられる景色としてください。

### 第4段階：天空の庭園

**テーマ：最後の奇跡へ向かう。**

高度115〜160m程度。

生まれる島はさらに大きくなり、種の発光色も豊かになります。

遠方に最大の種が浮かび、周囲を金色の粒子がゆっくり旋回します。最後の5つの島を生み出しながら、その種へ向かって進みます。

飛行速度は10〜14m/s程度まで上げますが、急加速や急旋回は行いません。

24回目のタップが最後のクライマックスを引き起こします。

### クライマックス：天空に巨大な樹が生まれる

最後の種に触れると、これまでとは明確に異なる規模の浮き島が誕生します。

1. 種から金色の光の輪が広がる。
2. 岩石が集まり、直径20〜26mの大きな島が形成される。
3. 島の中央から高さ18〜24m程度の大樹が成長する。
4. 枝が四方へ伸び、葉と花が次々に展開する。
5. 島の縁から複数の滝が流れ始める。
6. 周囲の浮き島からも光が立ち上がる。
7. 巨大な樹を中心に、虹色と金色の光の粒子が上空へ広がる。

光の解放は約4〜7秒かけて展開します。白一色の画面、強い点滅、爆発音、画面振動は使用しません。

浮遊艇は大樹の手前まで進み、庭園全体を見渡せる位置で停止します。

### 余韻と再プレイ

クライマックス後は10〜15秒程度、花びらが舞い、滝が流れ、鳥が飛ぶ天空の庭園を楽しめる時間を設けます。

その後、白い雲を利用した穏やかな場面転換によって、最初の森へ戻ります。

急降下する映像は使用しません。再び中央に光る種を表示し、次のタップで新しい旅を始められるようにしてください。

## 6. カメラ

### 6.1. 基本構図

PerspectiveCameraを使用し、浮遊艇の斜め後方かつ少し上から追従する視点を基本とします。

- 基本FOV：45〜55度。
- 浮遊艇からの距離：7〜12mを初期値とする。
- 浮遊艇からの高さ：2.5〜4m程度。
- 浮遊艇は画面中央よりやや下に配置する。
- 次に触る種は画面中央に配置する。
- カメラのロール角は原則0度とする。

浮遊艇の進行方向ではなく、次の種や成長中の島など、その時点で最も重要な対象をカメラの注視点としてください。

### 6.2. ゲーム状態ごとの注視対象

| 状態 | 画面中央に置く対象 |
|---|---|
| 操作待ち | 光る種 |
| 発芽 | 種から生まれる島 |
| 成長 | 島と成長する木の全体 |
| 飛行 | 進行先または次の種 |
| クライマックス | 巨大な島と大樹の全体 |
| 余韻 | 完成した天空の庭園 |

島が成長する際には、完成時の大きさをあらかじめ考慮してカメラを引き始めてください。

対象が成長してから慌ててカメラを引く実装は避けます。

### 6.3. 縦向き・横向きへの対応

カメラの距離を固定せず、対象のBoundingBoxまたはBoundingSphereと、水平・垂直FOVから必要な撮影距離を算出してください。

対象全体が画面内に収まり、上下左右にそれぞれ8〜12％程度の余白が残るようにします。

特に縦向きでは、水平方向の画角が狭くなることを考慮してください。

対象のBoundingBoxの各頂点を画面座標へ投影し、画面外へ出ないことを確認する仕組みを設けることを推奨します。

クライマックスでもこの条件を緩和しないでください。巨大な樹の頂上や島の底部が見切れることは禁止します。

### 6.4. 飛行経路と酔い対策

飛行経路にはCatmullRomCurve3などの滑らかな曲線を使用します。

あらかじめ樹木と岩石の位置を考慮し、浮遊艇とカメラが障害物を通り抜けない安全な経路を生成してください。

- カメラの回転速度は通常10〜20度/秒以下。
- カメラの位置と注視点は0.4〜0.8秒程度の時定数で追従。
- 加速と減速には連続的なイージングを使用。
- 水平線を大きく傾けない。
- 急激なFOV変更、画面振動、モーションブラーは使用しない。

爽快感はカメラを激しく動かすことでなく、周囲の風景が後方へ流れること、光の航跡、風の音、視界の拡大によって表現してください。

## 7. 操作

iPad SafariおよびPCのタッチ・マウス操作に対応してください。

Pointer Eventsを使用し、操作は基本的に種への1回のタップのみとします。

- 種のタップ判定は見た目の1.4〜1.8倍程度。
- 画面上の当たり判定は最低直径80〜96 CSS px程度を確保。
- Raycasterによる判定に加え、画面座標上での補助判定を設ける。
- タップ直後に視覚的な反応を返す。
- 成功処理中の連打で複数の島が生成されないようにする。
- 2本目以降の指による入力は無視する。

浮遊艇の操縦、方向転換、上昇はすべて自動です。仮想ジョイスティックやスライダーは設置しません。

CSSとイベント制御によって、ピンチズーム、ダブルタップズーム、スクロール、長押しメニュー、テキスト選択、ブラウザのオーバースクロールを可能な範囲で抑制してください。

`pointercancel` や画面回転が発生しても、ゲームが操作不能にならない設計とします。

## 8. 音

すべての音をWebAudio APIによって手続き的に合成してください。外部音声ファイルは使用しません。

最初の有効なユーザー操作でAudioContextを生成またはresumeしてください。

### 8.1. 成功音

種へのタップ、岩石の形成、植物の成長、浮遊艇の加速を異なる音で表現します。

| イベント | 音の方向性 |
|---|---|
| 種へのタップ | 澄んだ短いベル音 |
| 岩石の形成 | 低域を含む穏やかな集積音 |
| 根や幹の成長 | 上昇する木琴風の音 |
| 葉や花の展開 | 複数の高音が連なる音 |
| 島の完成 | 心地よい長調の和音 |
| 飛行開始 | 滑らかに上昇する風切り音 |
| クライマックス | 広がりのある豊かな和音 |

音階はCメジャー・ペンタトニックを基本とし、段階が進むにつれて音域と同時発音数を増やしてください。

第1段階では単音と2音程度、第2段階では3和音、第3段階では分散和音、第4段階では複数音域に広がる和音を使用します。

### 8.2. 環境音

森の風、葉のざわめき、小鳥の声、雲海の上を吹く風、滝の音をノイズ、フィルター、オシレーターによって合成します。

環境音は成功音よりも十分に小さくし、繰り返しが目立つ旋律は避けてください。

飛行速度に合わせて風音の音量とフィルター周波数を変化させます。

DynamicsCompressorNodeなどを使用して急激な音量上昇を防止します。音が再生できない場合でも、ゲームの進行に影響させないでください。

## 9. 画面の文字と世界観の制約

ゲーム画面には文字、数字、説明文、スコア、ボタンのラベル、段階表示を一切出さないでください。

開始画面も独立したメニューにせず、巨木の森と浮遊艇、中央に光る種がある状態から始めます。

次の操作は、種の形、発光、動き、配置によって伝えます。矢印、手のアイコン、文字によるチュートリアルは使用しません。

人物、不気味な生物、おばけ、怪物、お姫様、シュールな造形、既存のキャラクター、ブランドや作品を識別できる要素は登場させないでください。

別紙の禁止語については、ゲーム画面、ソースコード、変数名、コメント、実装時の説明文においても使用しないでください。

## 10. 画質の自動調整

2020年モデルのiPad ProのSafariを主要な性能基準とし、実機で50fps以上を目標にしてください。

起動時と実行中にフレーム時間を測定し、high / mid / lowの3段階を自動で切り替えます。

| 設定 | high | mid | low |
|---|---:|---:|---:|
| Pixel ratio上限 | 1.5 | 1.0 | 0.75 |
| シャドウマップ | 2048² | 1024² | なし |
| Bloom | あり | 低解像度 | 疑似発光のみ |
| 光の筋 | 16本程度 | 8本程度 | 3本程度 |
| 最大同時パーティクル | 900 | 450 | 180 |
| 樹木・葉の密度 | 100% | 65% | 40% |
| 水のシェーダー | 標準 | 簡略版 | 最小構成 |
| 雲の詳細度 | 高 | 中 | 低 |

初期状態はmidとし、最初の約2〜3秒間の描画性能から調整してください。

実行中は直近数秒間のフレーム時間を継続的に評価します。

- 平均FPSが50未満の状態が3秒程度続けば1段階下げる。
- 平均FPSが58以上の状態が10秒程度続けば、余裕がある場合に限り1段階上げる。
- 頻繁な設定変更を防ぐため、変更後に十分な待機時間を設ける。
- バックグラウンド移行中の測定値は判定に使用しない。

`?q=low`、`?q=mid`、`?q=high` で指定された場合は画質を固定します。

品質を下げる際も、種、浮遊艇、成長中の島など、ゲームの核となる対象の視認性は維持してください。

### 最適化

- 葉、草、花、岩石、パーティクルにはInstancedMeshを活用する。
- ジオメトリとマテリアルを可能な限り共有する。
- 遠方の樹木と島にはLODを使用する。
- 画面外や遠方のオブジェクトは描画を省略する。
- 通過済みの島は簡略化し、必要に応じて再利用する。
- パーティクルにはオブジェクトプールを使用する。
- 毎フレームの不要なメモリ確保を避ける。
- 再プレイ時のGPUリソースの増加を防ぐ。

写実性のためにフレームレートを犠牲にせず、滑らかな操作と飛行を優先してください。

## 11. 技術構成

### 11.1. ファイル構成

実装先は `site/games/d13/index.html` とします。

HTML、CSS、JavaScriptをこの1ファイルにまとめてください。

Three.jsはリポジトリ内に同梱された以下のファイルを使用します。

- `site/vendor/three/build/three.module.min.js`
- `site/vendor/three/examples/jsm/`

importmapを使用し、`three` を `../../vendor/three/build/three.module.min.js` に、`three/addons/` を `../../vendor/three/examples/jsm/` に対応させてください。

CDN、外部API、外部素材、外部フォントには依存させません。

`<head>` 内には `<meta name="robots" content="noindex">` を配置してください。

`</body>` の直前には `<script src="../../gf-playlog.js" defer></script>` を配置してください。

既存の共通スクリプトおよびThree.js本体は変更しないでください。

### 11.2. ゲーム状態の管理

ゲーム進行は、以下の状態を持つステートマシンで管理してください。

| 状態 | 処理 |
|---|---|
| INIT | シーン、素材、描画環境の準備 |
| WAIT_SEED | 種へのタップを待つ |
| GERMINATE | 種が開き、島が形成される |
| GROW | 植物が成長する |
| FLY | 浮遊艇が次の地点へ移動する |
| STAGE_TRANSITION | 段階に応じた景色と光の変化 |
| FINALE | 最後の巨大な島の誕生 |
| AFTERGLOW | 完成した庭園の余韻 |
| RESET | 次回プレイの準備 |

状態の切り替えによる入力競合、重複したアニメーション、音の多重再生を防いでください。

ゲーム内の時間管理にはdeltaTimeを使用します。フレームレートによって島の成長速度や飛行速度が変わらないようにしてください。

### 11.3. 準備完了とエラー管理

`window.__ready` は初期値falseとし、ゲームの初期描画と操作受付の準備が完了した時点でtrueに設定してください。

`window.__errors` は空の配列として初期化し、実行時エラーや未処理のPromise rejectionを記録してください。

これらの情報はゲーム画面には表示しません。

### 11.4. 自動テスト

URLに `?autotest` が付与された場合、自動で種をタップする処理を有効にしてください。

自動テストは通常操作と同じ成功処理を使用し、以下を順番に実行します。

- 24回の種へのタップ。
- 全浮き島の生成と植物の成長。
- 全4段階の飛行。
- クライマックスの発生。
- 余韻と再プレイ可能状態への復帰。

段階を直接書き換えて処理を飛ばす実装は不可とします。

ブラウザの音声再生制限により自動テストでAudioContextが起動できなくても、進行を継続してください。

テスト結果として、到達段階、成功回数、クライマックス到達の有無、平均FPS、エラー数をコンソールで確認可能にしてください。

## 13. 実装時の最重要原則

品質を判断する際は、景色の美しさだけでなく、以下の体験が成立しているかを最優先してください。

**小さな種に指で触れたら、大きな島が生まれた。その島に木が育った。自分の乗りもので、その上を飛ぶことができた。そして、森の向こうには、もっと広く美しい世界が待っていた。**

この因果関係と期待感を、最初のタップから最後のクライマックスまで維持してください。
