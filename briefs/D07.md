# D07 実装指示文：夕焼けの町に灯りをともすクジラ

## 1. ゲームの狙い

5歳の女の子が、夕焼けに染まる海でザトウクジラと遊び、自分の指でクジラを跳ばすたびに、港町に灯りをともしていく写実3Dウェブゲームを制作する。

- **夢×写実**：クジラの皮膚、水滴、波、夕日の反射を現実の海のように描きながら、クジラのジャンプで町に灯りがともり、最後には星空を泳ぎ出すという幻想的な体験を作る。
- **高揚感**：クジラを跳ばすたびに町が輝きを増し、燃える夕焼けから星の輝く夜へと世界全体が変化していく喜びを作る。
- **爽快感**：巨大なクジラが海面を突き破る迫力、大量の水滴が飛散する美しさ、着水の波が町へ届いて灯りが連鎖する気持ちよさを組み合わせる。

最も重要なのは、景色を鑑賞するだけの作品ではなく、**自分がクジラを跳ばしたからこそ、世界が変化した**と子どもが実感できる遊びにすることである。

複雑な操作や説明を必要とせず、最初の10秒以内に遊び方を自然に理解できるようにする。

## 2. 絵から借りる光と色

### 2.1. 美術の方向性

指定された参考作品から、以下の要素だけを抽出する。

- B6：夕日の港町、火山性の山々、ザトウクジラのブリーチ、透明感のある海。
- B7：燃えるような夕焼け、金色と赤紫色に染まる水面、空と海が溶け合うような色彩。
- B22：同じ景色が昼から夜へ移り変わり、建物の窓や街灯が順番にともる仕掛け。

元作品の構図、建物の配置、絵柄、特徴的な造形は再現しない。架空の港町を独自に設計する。

海洋幻想画に通じる「現実と想像が溶け合う世界」と、魔法を題材にした長編アニメーション映画に通じる光の演出や驚きの空気感を、写実的な3D空間として表現する。

### 2.2. 時間帯ごとの色彩設計

ゲームの進行に合わせて、以下の4段階で空と海の色を変化させる。

| 項目 | 第1段階：黄金の夕日 | 第2段階：燃える夕焼け | 第3段階：薄暮 | 第4段階：星月夜 |
|---|---|---|---|---|
| 空の上部 | `#66B5E8` | `#7666BC` | `#405CA5` | `#243D78` |
| 地平線 | `#FFD18A` | `#FF7951` | `#E598C5` | `#718FD1` |
| 雲の受光面 | `#FFE3AD` | `#FFAA73` | `#C7B2F3` | `#B6CDF4` |
| 海の基本色 | `#237D98` | `#386B93` | `#315D97` | `#254E83` |
| 主光源の色 | `#FFD3A0` | `#FFAE78` | `#C8D4FF` | `#C0DEFF` |
| 主光源の色温度目安 | 3800K | 2600K | 7500K | 8500K |
| 環境光の強さ目安 | 1.5 | 1.4 | 1.3 | 1.4 |
| 太陽光の強さ目安 | 3.0 | 2.3 | 0.7 | 0 |
| 月光の強さ目安 | 0 | 0.2 | 1.1 | 1.8 |

光源の強さはThree.jsの初期調整値であり、実際のレンダリング結果に応じて調整する。色温度は演出上の目安とし、光源の色はHEX値を基本とする。

段階が切り替わる際は、空、雲、光源、水面反射、霧の色を6〜10秒かけて連続的に補間する。突然背景が切り替わる演出は禁止する。

### 2.3. ライティングと大気

- `ACESFilmicToneMapping`を使用し、露出は1.0〜1.25を目安とする。
- 太陽は地平線近くに配置し、海面に長い金色の光の道を形成する。
- 太陽が沈むにつれて月が現れ、月光によってクジラの背中と波の輪郭が青白く輝く。
- `HemisphereLight`で空からの光と海からの反射光を再現する。
- 距離の霧は開始60〜90m、終了300〜450m程度とし、遠方の山々を大気遠近法で表現する。
- 霧の色は地平線の色と連動させる。
- ブルームは通常時の強さ0.25〜0.45、半径0.35〜0.55、閾値0.85〜1.1を初期値とする。
- クライマックスのみ、ブルームの強さを0.8〜1.1程度まで一時的に上げる。

夜になっても、海面、クジラ、町、雲の輪郭が十分に識別できること。黒一色に近い海や、不安を感じさせる暗闇は作らない。

発光演出は、画面全体を白くするのではなく、水滴、窓、波の縁、星など、具体的な物体に光が宿る形で行う。

## 3. 舞台と登場するもの

すべての3Dモデル、テクスチャ、エフェクト、音響をプロシージャル生成する。外部の画像、3Dモデル、音声ファイルは使用しない。

### 3.1. 海

海は単なる青色の平面ではなく、このゲームの写実性を支える重要な存在として制作する。

- 複数のGerstner Wave、または同等の頂点変位によって、周期の異なる波を重ねる。
- 波長は0.8〜18m、波高は0.03〜0.35m程度を目安とする。
- 細かな法線のゆらぎによって、水面の微細な反射を表現する。
- Fresnel効果によって、見る角度に応じて透明感と空の反射の割合を変える。
- 太陽や月の反射は、波によって細かく分断され、絶えず形を変えるようにする。
- クジラの周囲では浅い青緑色を混ぜ、水面下にいるクジラの影や姿が見えるようにする。
- 着水による同心円状の波紋は、通常の波とは別に管理する。

高画質設定では水面の反射を充実させ、低画質設定では空の色と光源から計算した疑似反射に切り替える。

海中へのカメラ移動は行わない。水面越しにクジラが潜る様子を観察できるようにする。

### 3.2. 港町

架空の南国の港町を、海岸線に沿って制作する。

港町は、石造りの護岸、木製の桟橋、白壁の住宅、赤褐色の瓦屋根、小さな商店、街灯、ヤシの木などで構成する。

- 建物は40〜60棟程度。
- 町全体を20区画に分ける。
- 各区画には2〜3棟の建物と、窓、街灯など複数の発光箇所を配置する。
- 建物の高さ、屋根の形状、壁の色、窓の位置に適度な個体差を設ける。
- 海岸線の幅は55〜70m程度を初期値とし、縦画面でも町全体を見渡せる規模に収める。
- 町の背後には、なだらかな火山性の山と緑の丘を配置する。

窓は実際の建物の開口部として認識できる形状にする。発光する四角形を壁の上に大量に貼り付けるだけの表現は避ける。

灯りの色は、窓が`#FFD38A`、街灯が`#FFE5B5`を基本とし、色温度2200〜2800K程度の温かみのある光とする。

一度ともった灯りは、クライマックスと余韻が終わるまで消さない。

建物ごとに多数のPointLightを設置することは避け、emissiveマテリアル、疑似的な照り返し、インスタンス化した発光面を組み合わせる。

### 3.3. 山・空・雲

遠景の山は、複数のノイズを組み合わせた地形メッシュから生成する。山頂を過度に尖らせず、海岸から緩やかに隆起する自然な地形とする。

空はグラデーションを計算するSky Domeまたは専用シェーダーで生成する。

雲は複数のノイズ層を重ね、夕日を受ける部分と陰になる部分を作る。単色の球体の集合には見せない。

雲の移動は非常に緩やかにする。第3段階から星を少しずつ出現させ、第4段階では月と多数の星が海面にも反射するようにする。

### 3.4. 小舟

プレイヤーが乗っている小さな木造ボートを制作する。

- 全長4m前後。
- 木目、板の継ぎ目、船縁、座席、小さな真鍮製の金具を再現する。
- 木材のroughnessは0.5〜0.75程度とする。
- 波によって上下に数cm〜十数cm揺れる。
- クジラが着水した際には、小舟も波を受けてゆっくり上下する。

人物は登場させない。

小舟はプレイヤーの存在を象徴するものであり、操作対象にはしない。画面下部の視界を遮らない位置に置き、クジラの全身が見えることを優先する。

カメラを小舟の揺れと直接連動させてはならない。

### 3.5. ザトウクジラ

本ゲームの主役であり、最も制作工数を割くべき3Dモデルとする。

体長12〜14m程度のザトウクジラを制作する。単純な楕円体にヒレを付けただけのモデルではなく、滑らかな断面を連結したメッシュなどによって、頭部から尾部に至る自然な体の曲線を形成する。

特に以下の特徴を再現する。

- 大きな頭部から尾部に向かって細くなる胴体。
- 長く伸びる胸ビレと、その縁の小さな起伏。
- 幅広い尾ビレと中央の切れ込み。
- 喉から腹部に続く縦方向の溝。
- 頭部の特徴的な小隆起。
- 背中の濃い青灰色と、腹側の白灰色の境界。
- 皮膚の微細な模様と自然な色むら。
- 小さく自然な目。

マテリアルの初期値は以下を目安とする。

| 項目 | 設定 |
|---|---|
| 背中の基本色 | `#354B5A` |
| 側面の基本色 | `#647C8A` |
| 腹部の基本色 | `#CBD5D6` |
| Metalness | 0.0 |
| Roughness | 0.20〜0.38 |
| Clearcoat | 0.4〜0.7 |
| Clearcoat Roughness | 0.12〜0.25 |

クジラの皮膚には、濡れた皮膚特有の光沢と環境反射を与える。プロシージャルノイズで生成した法線の変化は控えめにし、岩石や金属のように見せない。

アニメーションでは、頭部、胴体、尾部、胸ビレを独立して変形させる。尾の上下運動が胴体へ伝わるようにし、巨体に重量感を持たせる。

デフォルメされた大きな目、人間のような表情、過剰な擬人化は使用しない。穏やかで親しみやすい本物のザトウクジラとして描く。

### 3.6. 海の生き物

海面近くに小さな銀色の魚の群れを配置する。

クジラが潜る際には魚が左右へ散り、少しすると再び集まる。必要に応じて遠方を泳ぐウミガメを1匹配置してもよいが、操作対象は増やさない。

生き物の追加によって主役のクジラの品質やFPSが低下する場合は、省略を優先する。

## 4. 指1本のゲームループ

基本操作は、**光の円を長押しして、指を離すだけ**とする。

### 4.1. 課題：海面に光の円が現れる

クジラの近くの海面に、直径4〜5m程度の金色の光の円が浮かび上がる。

円は平面的なUIではなく、海面に浮かぶ光の波紋として表現する。細かな光の粒が円周に沿って動き、中央には夕日が集まったような輝きを作る。

光の円を常に画面中央付近に配置する。

クジラは円の近くをゆっくり泳ぎ、ときどき背中や尾ビレを水面から出す。子どもが光の円とクジラの関係を自然に理解できる構成とする。

### 4.2. 取り組み：長押しでクジラが潜る

円に触れた瞬間に、以下の反応を同時に開始する。

- 円が一度脈打つ。
- 触れた位置から小さな光の波紋が広がる。
- クジラが頭を下げて潜り始める。
- 尾ビレが海面の上に持ち上がり、水滴が落ちる。
- 水中に青白い気泡が発生する。

押し続けると、円の外側にある光が中央へ集まっていく。約1.0〜1.5秒で十分にエネルギーが集まる。

数値による充填ゲージは表示しない。

長押しが十分な時間に達した後も、指を離すまでは準備状態を維持する。長く押し続けても悪いことは起きない。

### 4.3. 結果：指を離すとクジラが跳ぶ

指を離した瞬間から、以下の一連の動きを開始する。

| 経過時間の目安 | 動き |
|---|---|
| 0.0秒 | 光の円が中央へ収束する |
| 0.1〜0.5秒 | 水中のクジラが上昇し、海面が盛り上がる |
| 0.5〜1.0秒 | クジラが大量の水しぶきとともに海面を突き破る |
| 1.0〜2.3秒 | 胸ビレを広げ、背中を反らせながら空中を舞う |
| 2.3〜3.3秒 | 胴体を緩やかにひねり、海へ戻る |
| 3.3〜4.2秒 | 着水し、大きな波紋が広がる |
| 4.2〜6.0秒 | 金色の波が岸へ進む |
| 6.0〜7.5秒 | 町の一区画に灯りがともる |
| 7.5〜8.5秒 | 次の光の円が現れる |

クジラの最高到達点は、通常時で海面上7〜11m程度を目安とする。

空中では、水滴がクジラの輪郭に沿って飛散し、夕日や月光を反射する。胸ビレや尾ビレの動きには慣性を持たせ、巨体が本当に水を割って飛び出したように見せる。

同じ動きを毎回完全に繰り返すのではなく、胸ビレの角度、体のひねり、着水姿勢などに小さな変化を加える。

### 4.4. 円の中央で跳ばした場合

長押しを開始した位置が円の中央に近い場合は、通常よりも水滴が多く、金色の光が強いブリーチにする。

ただし、中央から外れていても必ず立派なジャンプが発生し、町の灯りがともるようにする。

- 短いタップでもジャンプできる。
- 長押し時間が短くても成功する。
- 指が多少動いても操作を継続する。
- 円の中心から外れてもゲーム進行に影響しない。
- スコア、評価、正誤判定、失敗音は存在させない。

中央付近での操作は、遊び込むうちに自然に発見できる演出上の楽しみとして扱う。

### 4.5. 着水の波が町に届く

着水の瞬間に発生した波紋のうち、岸へ進む波の縁に金色の輝きを与える。

波が護岸に届くと、桟橋の照明、街灯、住宅の窓の順番に、約1.5秒かけて一区画が点灯する。

窓の光は海面にも反射させる。点灯済みの区画が増えるほど、海面に映る金色の光も増加する。

**クジラの着水 → 波が進む → 岸に届く → 町が光る**という因果関係を、途中の省略や場面転換なしで見せること。

### 4.6. 操作を促す仕掛け

何も操作されない場合は、以下の順番で誘導する。

- 3秒後：光の円がゆっくり脈打つ。
- 6秒後：円の周囲に光の粒が集まり始める。
- 9秒後：クジラが円に近づき、背中を海面から出す。
- 12秒以降：上記の演出を穏やかに繰り返す。

文字、矢印、手のアイコン、説明用の吹き出しは使用しない。

自動的にジャンプしてゲームを進めることも避ける。子ども自身の操作によって世界が変化することが重要である。

## 5. 盛り上がりの設計

全20区画を5区画ずつ4段階に分け、町の完成後に特別なブリーチを1回行う構成とする。

通常の遊び方で約3〜5分を目標とする。ただし、子どもが景色を眺めたり操作を休んだりする時間は制限しない。

### 第1段階：黄金の夕日（1〜5回目）

海と町は夕日に照らされている。クジラが跳ぶたびに、港の端から小さな灯りがともり始める。

ジャンプの軌道は穏やかにし、光の波が町へ向かう仕掛けを理解できるようにする。

成功音は単音や2音程度の優しい響きから始める。

### 第2段階：燃える夕焼け（6〜10回目）

空のオレンジ色と赤紫色が強くなり、海面に夕焼けが映り込む。

クジラのブリーチはより大きくなり、空中で胸ビレを広げる動作を増やす。第1段階と比較して、ジャンプの速度を最大10％程度、水滴の演出量を20％程度増やす。

町の中央付近まで灯りが広がり、海面にも複数の金色の光の道が現れる。

### 第3段階：星が生まれる薄暮（11〜15回目）

太陽が地平線へ沈み、空が紫色から青色へ移り変わる。

最初の星が現れ、クジラの飛散させた水滴にも星のような輝きが宿る。

成功音には3音の和音を加える。波紋の発光範囲も広げ、着水と町の点灯をさらに印象的にする。

### 第4段階：光の港町（16〜20回目）

月が海を照らし、空には多数の星が輝く。

町のほとんどの建物に灯りがともり、残された区画が徐々に完成していく。

20回目のブリーチで最後の区画に灯りがともると、町全体の窓、街灯、桟橋の照明が一度だけ順番に輝きを増す。

海面には町全体の光が映り、夕方から続けてきた子どもの操作の成果が一目で分かる状態を作る。

### 5.1. クライマックス：星空へ泳ぎ出すクジラ

町が完成した後、海面中央に特別な光の円を出現させる。

通常の円よりも直径を約1.4倍にし、金色と青白い星の粒を含ませる。星の発光色は`#FFF4D0`、`#BDE7FF`を中心とし、色温度6000〜9000K程度の光を混ぜる。

最後の長押しによって、以下の演出を発生させる。

1. クジラがゆっくり深く潜る。
2. 海面の光と星の粒が中央へ集まる。
3. 指を離すと、過去最大の水しぶきとともにクジラが飛び出す。
4. クジラは落下せず、空中で尾ビレを動かしながら星空へ泳ぎ始める。
5. 体から離れた水滴が星の粒に変化し、長い光の軌跡を形成する。
6. 町の灯りと海面の反射が一斉に輝きを増す。
7. クジラの周囲に金色と青白い光が大きく広がる。

クライマックスの上昇高度は海面上25〜30m程度を目安とする。クジラを遠方の小さな点にしてしまわず、全身が十分な大きさで見える状態を維持する。

派手な爆発、激しい閃光、画面振動ではなく、クジラの巨体、星の軌跡、町全体の輝きによって壮大さを表現する。

### 5.2. 静かな余韻と再プレイ

クライマックス後は、約10〜15秒の余韻を設ける。

完成した港町、月光、星空、穏やかな波を見渡せる状態とし、音楽も徐々に静かにする。

その後、自然な光の移り変わりによって夕日の海へ戻す。クジラが再び海面を泳ぎ始め、最初の光の円が現れる。

メニューやリスタートボタンは表示しない。円を触れば新しい遊びが始まる状態に戻す。

## 6. カメラ

カメラはクジラと港町を少し離れた真横に近い位置から観察する構図とする。

`PerspectiveCamera`を使用し、垂直FOVは44〜52度、nearは0.3m、farは600〜1000m程度を初期値とする。

以下を必須条件とする。

- 操作待機中は光の円が画面中央にある。
- 潜水中は光の円とクジラが潜った位置を中央に維持する。
- ブリーチ中はクジラの全身が中央付近に収まる。
- 着水後は波の進行方向と点灯する区画を見やすくする。
- クライマックスでは星空を泳ぐクジラを中央に維持する。

通常時の注視対象は、画面中央から縦横それぞれ画面寸法の5〜8％以内に収めることを目標とする。

### 縦画面・横画面への対応

固定距離のカメラは使用しない。

各場面で、クジラの最大到達位置、胸ビレと尾ビレ、光の円、海岸線、点灯する建物の位置から表示に必要な範囲を求める。

その範囲を現在の画面比率で投影し、必要に応じてカメラ距離を自動調整する。

主要対象の外側には8〜12％程度の安全余白を確保する。縦画面では特に左右の胸ビレが見切れないことを確認する。

クライマックスに入る前から必要な距離を確保し、クジラが飛び出した後に慌ててカメラを引く挙動を避ける。

カメラの位置と注視点の補間時間は0.6〜1.2秒程度とする。急旋回、急ズーム、ロール回転、手持ちカメラ風の揺れは使用しない。

町とクジラの両方を十分な大きさで収められない場合は、カメラだけで解決しようとせず、町の横幅や海岸までの距離も調整する。

## 7. 操作

iPad Safari、iPhone Safari、PCブラウザで、タッチまたはマウスによって操作できるようにする。

Pointer Eventsを使用し、以下の入力を適切に管理する。

- `pointerdown`：長押し開始。
- `pointermove`：押下状態を維持。
- `pointerup`：ジャンプ開始。
- `pointercancel`：押下状態を安全に解除し、再操作可能にする。

最初に触れたポインターだけを有効にし、2本目以降の指は無視する。必要に応じてPointer Captureを使用する。

光の円の当たり判定は、見た目の直径の1.4〜1.8倍とし、画面上で最低80 CSS px程度を目安とする。

円から完全に外れた場所を触っても、不快な反応は発生させない。

`touch-action: none`、`overscroll-behavior: none`、`user-select: none`、`-webkit-touch-callout: none`などを適切に設定する。

ゲーム画面で以下が発生しないようにする。

- ピンチズーム。
- ダブルタップによるズーム。
- ページスクロール。
- 長押しメニュー。
- テキスト選択。
- 操作中の意図しないブラウザ標準ジェスチャー。

ジャンプ中の連打によるアニメーションの多重実行や、点灯区画の二重加算を防ぐ。画面回転、タブ切り替え、入力キャンセルの後にも正常に遊び続けられること。

## 8. 音

すべての音をWebAudioで手続き的に合成する。外部音声ファイルは使用しない。

最初の有効なタップでAudioContextを生成またはresumeする。

| 場面 | 音響設計 |
|---|---|
| 通常時 | フィルターを通したノイズによる海の音 |
| 長押し開始 | 小さな澄んだベル音 |
| 潜水中 | 水泡の音と緩やかな上昇音 |
| ブリーチ | 水を突き破る音と厚みのある低音 |
| 空中 | 高音域の粒状のきらめき |
| 着水 | 低域と中高域を組み合わせた水しぶき音 |
| 波の伝播 | 岸に向かって移動するような響き |
| 町の点灯 | 窓や街灯の点灯に同期した連続音 |
| クライマックス | 広がりのある和音と星の粒に対応する高音 |

成功音はペンタトニックスケールを基本とし、不協和音を避ける。

第1段階は単音、第2段階は2音、第3段階は3音、第4段階は高音を加えた豊かな和音とする。

クライマックスでは、低音から高音へ段階的に音が積み重なる演出を行う。

BGMは控えめな持続音と海の環境音を中心とする。既存楽曲の旋律は使用しない。

Master Gainは0.25〜0.4程度から調整し、DynamicsCompressorNodeなどによって、着水音や和音が重なった際の過大な音量を防止する。

## 9. 画面の文字

ゲームの表示画面には、文字、数字、タイトル、操作説明、スコア、残り回数、ボタンのラベルを一切表示しない。

開始画面も作らず、準備ができたら、夕日の港町と海を泳ぐクジラ、中央の光の円が見える状態にする。

進行状況は、町の灯りが増えることと空の色の変化だけで伝える。

開発者向けのFPSやデバッグ情報についても、通常プレイ時には画面に表示しない。

## 10. 画質の自動調整

2020年モデルのiPad Pro相当の性能を考慮し、実際のゲームプレイ中に50fps以上を目標とする。

high / mid / lowの3段階の画質設定を用意する。

| 項目 | high | mid | low |
|---|---:|---:|---:|
| ピクセル比上限 | 1.75 | 1.25 | 1.0 |
| 影マップ | 2048 | 1024 | なし・疑似影 |
| 水面の反射 | 高精度の疑似反射、必要に応じ低解像度反射RT | 簡易シェーダー反射 | Fresnelと光源による疑似反射 |
| ブルーム | あり | 低解像度 | 発光面による代替 |
| 水滴の最大同時表示数 | 1200 | 600 | 250 |
| 星の表示数 | 650 | 400 | 250 |
| 海面メッシュ分割数の目安 | 160×160 | 96×96 | 64×64 |

起動時はmidを基本とし、フレーム時間を計測して適切な画質へ移行する。

実行中も数秒単位でFPSを監視する。

- 3〜5秒間、平均FPSが50を下回った場合は画質を1段階下げる。
- 10秒以上、平均FPSが58前後を維持できた場合は画質向上を検討する。
- 頻繁な切り替えを防ぐため、画質変更後には一定の待機時間を設ける。
- ブリーチやクライマックスの最中に、目立つ描画設定の切り替えを行わない。

`?q=low`、`?q=mid`、`?q=high`で画質を強制できるようにする。強制指定中は自動画質変更を無効にする。

建物、窓、街灯、星、水滴などはInstancedMeshやPointsを活用する。パーティクルにはオブジェクトプールを使用し、毎フレームのオブジェクト生成を避ける。

lowでもクジラの形状、アニメーション、町の点灯、夕焼けから夜への変化、クライマックスは省略しない。

**画質を下げる際には、遊びの核心ではなく、描画負荷の高い装飾要素から削減すること。**

## 11. 技術構成

### 11.1. ファイル構成

実装先は以下の1ファイルとする。

`site/games/d07/index.html`

HTML、CSS、JavaScript、GLSLシェーダーなど、ゲーム固有の実装はすべてこのHTML内に記述する。

Three.jsはリポジトリ内に同梱されているものを使用する。

- `site/vendor/three/build/three.module.min.js`
- `site/vendor/three/examples/jsm/`

importmapでは、`three`を`../../vendor/three/build/three.module.min.js`へ、`three/addons/`を`../../vendor/three/examples/jsm/`へ対応させる。

CDN、外部API、外部アセット、外部フォントは使用しない。

`<head>`内には以下を必ず追加する。

`<meta name="robots" content="noindex">`

`</body>`の直前には以下を必ず追加する。

`<script src="../../gf-playlog.js" defer></script>`

既存の共通ライブラリやプレイログ用ファイルを不用意に変更しない。

### 11.2. 内部状態の管理

ゲームの状態は、概念的に以下のように分離する。

`WAIT → CHARGING → BREACH → SPLASH → WAVE → LIGHT_UP → WAIT`

全区画の点灯後は以下へ移行する。

`FINAL_WAIT → FINAL_CHARGING → STAR_SWIM → AFTERGLOW → RESET`

各状態の開始時刻、経過時間、現在の段階、点灯済み区画数を一元管理する。

点灯済み区画数を増やす処理は、1回の通常ブリーチにつき1回だけ実行する。

アニメーションと演出はフレーム数ではなく経過時間に基づいて制御する。

### 11.3. 準備完了とエラー管理

- `window.__ready`：初期値はfalse。シーン、入力処理、画質管理、最初の描画の準備が完了した時点でtrueにする。
- `window.__errors`：初期値は空配列。実行時エラー、未処理のPromise rejection、初期化エラーなどを記録する。

エラーを握り潰して空配列に見せかけることは禁止する。

### 11.4. 自動プレイ

`?autotest`を付与すると、自動的に長押しと解放に相当する入力を繰り返し、全20区画の点灯、最後のブリーチ、クライマックス、余韻まで進行するようにする。

自動プレイ専用の演出を作るのではなく、通常操作と同じゲーム処理を通過させる。

ブラウザの自動再生制限によってAudioContextを起動できない場合も、無音で自動テストを継続できるようにする。

### 11.5. 禁止事項

気持ち悪い生き物、おばけ、怪物、不穏な世界、シュールな造形、お姫様、既存キャラクター、ブランド、既存作品名、特定作品を識別できる建築物は使用しない。

別紙の禁止語は、実装コード、コード内のコメント、ログ、変数名、ゲーム内のデータにも記載しない。実装環境に別紙がある場合は確認し、不要な日本語コメントなどの追加も避ける。

## 13. 実装時の最優先事項

本指示文では、20区画、全4段階、最後の特別なブリーチ1回という構成を採用した。モデル寸法、光源の強さ、パーティクル数、演出時間などの数値は実装開始時の目安であり、視覚品質と実測FPSに応じて調整してよい。

制作工数や描画性能に制約がある場合は、以下の優先順位を守ること。

1. ザトウクジラの写実的な造形と自然なブリーチ。
2. 長押しから解放に至る操作の気持ちよさ。
3. 着水の波が町へ届き、灯りをともす因果関係。
4. 夕焼けから星月夜へ変化する空と海。
5. 最後にクジラが星空へ泳ぎ出す壮大なクライマックス。
6. 遠景の建物や生き物などの補助的な装飾。

完成したゲームは、美しい海の中でクジラを眺めるだけの作品ではなく、**自分の小さな指の動きによって、巨大なクジラが跳び、町全体が光に包まれ、ついには星空まで変化する遊び**になっていなければならない。
