# D02 実装指示文：灯台の朝、窓の灯りが空へのぼる

## 1. ゲームの目的と体験の核

5歳の女の子が、文字を読まず、指1本で直感的に遊べる、写真のような写実性を持つ3D Webゲームを実装してください。

夜明け前の海辺の村を舞台に、家々の窓に灯りをともすことで、空に黄金の階段が生まれ、小舟に乗ったプレイヤーが灯台の上までのぼっていきます。最後の窓に灯りをともすと、水平線から朝日が昇り、村と海の全体が黄金色に包まれます。

- **夢×写実：** 石造りの家、窓ガラス、朝もやの海という現実感のある風景の中で、窓の灯りが空へのぼり、小舟が通れる光の階段になるという夢のような現象を体験する。
- **高揚感：** 自分が窓をともすたびに村が目覚め、階段が高くなり、空が群青色から桃色、黄金色へと変化していくことで、次第に期待が膨らむ。
- **爽快感：** 最後の一段を完成させた瞬間、朝日が水平線から現れ、黄金の光が海と村の隅々まで一気に広がる。

最も重要なのは、風景を鑑賞するだけの作品ではなく、**自分の小さな操作によって、目の前の世界全体が変わっていく遊び**にすることです。

窓をともすこと、光の玉が生まれること、階段が増えること、小舟がのぼることを、明確な因果関係として表現してください。

プレイヤー自身の姿は描画しません。小舟に乗っているという設定を、カメラの移動と画面下部に見える舟の一部によって伝えてください。

## 2. 元にした絵から借りる光と色

### 2.1 芸術的な方向性

参考資料B13からは、海辺の村、灯台、石造りの家、桟橋、岩の浜、朝日の海面反射というモチーフと、朝の澄んだ空気感を借りてください。

参考資料B22からは、同じ景色が光の変化によって劇的に別の表情を見せる仕掛けだけを借りてください。本作では、夜明け前から朝へと変化する方向で応用します。

参考作品の構図、建物配置、描画様式、施設、固有の意匠は再現しないでください。

目指すのは、現実と想像が溶け合う海洋幻想の写実3Dです。物体そのものは現実に存在するような質感を持ち、光の現象だけが現実の物理法則を超える世界にしてください。

映画のクライマックスのような魔法の光と驚きを、空の色、窓の発光、海面反射、光の粒子、音楽によって表現します。

### 2.2 時間帯ごとの色彩設計

以下の値を初期設定の目安とし、実際のレンダリング結果を見ながら調整してください。

| 項目 | 第1段階：夜明け前 | 第2段階：村の目覚め | 第3段階：朝焼け | 第4段階：日の出 |
|---|---|---|---|---|
| 天頂の空 | `#294D91` | `#426AB0` | `#659DD4` | `#69BDF0` |
| 水平線 | `#899CC8` | `#C6A2C4` | `#FFC29C` | `#FFE4AE` |
| 海の基調色 | `#28638A` | `#367EA3` | `#479DB6` | `#51B4C5` |
| 窓の灯り | `#FFC36C` | `#FFD18A` | `#FFDB96` | `#FFE5B3` |
| 雲の受光面 | `#A6B6D8` | `#DEC1D8` | `#FFCEB5` | `#FFF1D9` |
| 霧の色 | `#9AAED1` | `#BCBBD2` | `#EBC9BD` | `#D8E9ED` |
| 主光源の色温度目安 | 8500K | 7500K | 4000K | 5000K |

Three.jsの光源には色温度に相当するRGB色を設定してください。

夜明け前でも、石壁の目地、屋根、窓枠、舟の木目、海面の波が十分に視認できるようにしてください。黒に近い空や、建物の輪郭しか見えない照明は禁止します。

### 2.3 Three.jsの照明設定

- `HemisphereLight`：強度1.3〜2.0。空の色を上側、石畳や地面の反射色を下側に設定する。
- `DirectionalLight`：夜明け前は強度0.6〜0.9、日の出後は2.0〜3.0を目安とする。
- 窓の`emissiveIntensity`：消灯時0〜0.08、誘導時0.3〜0.6、点灯後1.5〜2.5。
- 光の玉の発光強度：2.5〜4.0。
- 光の階段の発光強度：通常1.5〜2.5、完成時のみ3.0〜4.0。
- トーンマッピング：`ACESFilmicToneMapping`。
- Exposure：0.95〜1.25を起点に調整する。
- 出力色空間：`SRGBColorSpace`。
- フォグ：`Fog`を使用し、夜明け前はnear 35、far 150、日の出後はnear 70、far 260程度とする。
- ブルーム：high品質時はstrength 0.45〜0.75、radius 0.35〜0.55、threshold 0.85〜1.1を目安とする。

ブルームを画面全体に強く適用して輪郭を失わせないでください。窓枠、石壁、屋根、舟などの質感は常に保持します。

窓や光の玉の中心には白に近い金色、周縁には琥珀色の光を用いて、発光体の内部から光が生まれているように見せてください。

## 3. 舞台と登場するもの

### 3.1 海辺の村

海面をY=0とし、1ワールド単位を約1mと考えて、地形と建物を制作してください。

舞台は幅100〜140m程度の小さな湾です。湾の片側には家々が連なる斜面、中央付近には桟橋、海に突き出した岩場には灯台を配置します。

村全体を一つの連続した3D空間として構築し、段階が変わっても別のマップには切り替えません。

建物は12〜16棟程度とし、それぞれに高さ、屋根の傾斜、石材の色、窓の配置などの差異を設けてください。

家々のうち20個の窓を操作対象として選定します。操作対象以外の窓にも、ゲームの進行に応じて装飾的な灯りをともして構いません。

### 3.2 家屋と窓

家屋は単純な直方体の集合に見えないよう、以下の部品を組み合わせてプロシージャル生成してください。

- 花崗岩やレンガの外壁、切妻屋根、煙突、窓枠、出窓、木製の扉。
- 窓枠の奥行き、窓台の張り出し、屋根の軒、石壁の凹凸。
- 花壇、植木鉢、石畳、木製の柵、家々の間の小道。

外壁には`MeshStandardMaterial`を使用し、roughness 0.75〜0.95、metalness 0を基本とします。

CanvasTextureや手続き的なノイズによって、石材の色むら、モルタルの目地、屋根瓦の継ぎ目、木目を生成してください。必要に応じて法線やバンプの微細な変化を加えます。

窓はガラス面、木製の枠、奥にある発光面の三層構造としてください。

点灯した窓は単なる黄色の平面ではなく、ガラスの反射を残しながら室内から金色の光が漏れ、周囲の窓枠や石壁にも暖色の光が届くようにします。

多数のリアルタイム光源を使用する必要はありません。壁面に投影する加算合成の光、事前生成した放射状テクスチャなどで代用できます。

### 3.3 灯台

灯台は本作の象徴であり、どの段階でもその位置と存在が認識できるようにしてください。

高さ25〜30m程度の白い石造りの塔とし、基部から上部にかけてわずかに細くなる形状にします。上部には展望用の手すり、ガラスに囲まれた灯室、金属製の屋根を設置してください。

灯室には円筒状のレンズと、内部でゆっくり回転する光源を表現します。

ゲーム進行に合わせて灯室の光量を増加させ、最終段階では光の階段の終着点になります。

光線はプレイヤーの視界を横切って強く点滅するものではなく、空中に淡い光の筋として表現してください。

### 3.4 海・波・岩場

海はゲームの写実性を決める重要な要素です。

大きな平面ジオメトリに軽量な水面シェーダーを適用し、複数の正弦波とノイズを組み合わせて、小さな波と細かな法線の変化を表現してください。

- 波の高さ：0.05〜0.20m程度。
- 波の間隔：0.8〜4m程度の複数成分。
- 波の移動速度：0.2〜0.8m/s程度。
- フレネル反射によって、浅い視線角度ほど空の反射を強くする。
- 岩場や岸辺では波が白い泡となって消える表現を加える。
- 窓がともるたびに、その近傍の海面にも金色の反射が増える。
- 日の出では、太陽の方向から手前に向かう長い黄金色の反射を描く。

リアルタイムの完全な鏡面反射に固執せず、空の解析的な反射色と発光体の疑似反射を組み合わせ、低負荷で美しい水面を実現してください。

### 3.5 空・雲・自然物

空は大型のスカイドームとグラデーションシェーダーによって構築します。

雲は手続き的なノイズと半透明のメッシュなどを使用して生成し、空の色が変化するにつれて雲の縁も桃色から黄金色へ変化させてください。

遠景には岬や小島を配置して、湾の奥行きを表現します。

海鳥を3〜5羽程度、遠景に飛ばしても構いません。翼の羽ばたきと滑空を組み合わせた簡潔なアニメーションとし、操作対象にはしません。魚やその他の動物は必須ではありません。

### 3.6 プレイヤーの小舟

全長2.5m程度の木製の小舟を制作してください。

船体は曲線的な断面を積み重ねて生成し、白く塗装された外板、木製の船縁、船底、腰掛けを作ります。

小舟には人物を描画しません。

開始時は港の海面に浮かんでおり、窓から生まれた光が階段を形成するたびに、その一段先へ進みます。

舟が光の階段に乗った後は、水上から空中へ移動しますが、激しい加速、落下、大きな傾きは発生させないでください。

## 4. 指1本で遊ぶ基本ループ

### 4.1 開始画面

ゲーム起動後は、夜明け前の村と、港に浮かぶ小舟を表示します。

タイトル画面、メニュー、開始ボタンは設けません。最初から3Dの世界が表示されている状態としてください。

画面中央には、まだ灯りのともっていない一つの窓があります。その窓のガラスの奥で、小さな金色の光がゆっくり脈動しています。

プレイヤーがこの窓をタップすると、ゲームが始まります。

### 4.2 1回の操作と反応

以下の流れを一つの基本ループとして実装してください。

| 経過時間の目安 | 画面内で起きること |
|---|---|
| 操作前 | 画面中央の窓がかすかに瞬く |
| タップ直後 | 窓全体に金色の灯りがともる |
| 0.1〜0.4秒 | 窓の周囲に光が広がり、成功音が鳴る |
| 0.4〜1.0秒 | 窓から黄金の光の玉が現れる |
| 1.0〜2.8秒 | 光の玉が弧を描きながら空へのぼる |
| 2.8〜3.4秒 | 光の玉が広がり、階段が一段完成する |
| 3.4〜5.0秒 | 小舟が新しい階段の上へ進む |
| 5.0〜6.5秒 | 次の窓が画面中央に入り、瞬き始める |

時間は目安です。実際に遊んだときのテンポを優先してください。

タップに対する最初の反応は100ms以内を目標とし、窓の点灯と音を待たせないことが重要です。

### 4.3 光の玉から階段への変化

光の玉は、窓ガラスの奥から現れ、直径0.3〜0.6m程度まで成長します。

内部は白金色、周囲は黄金色とし、移動方向の後方に細かな粒子が短い尾を引くようにします。

軌道にはベジェ曲線を使用し、窓から階段の先端まで、空中に美しい弧を描いて移動させてください。

階段に到着した光の玉は、以下の変化を連続して起こします。

1. 光の玉が一瞬だけ強く輝く。
2. 横方向へ光が広がる。
3. 光の粒子が集まり、長方形の足場になる。
4. 足場の縁に黄金の光が走る。
5. その足場が安定し、小舟が上へ進む。

階段は抽象的な光の線ではなく、奥行きと厚みを持つ、舟を支えられそうな半透明の黄金の足場としてください。

各段の幅は3.5〜4.5m、奥行きは3〜4m、高低差は1.2〜1.5m程度を初期値とします。

階段が増えるたびに、完成済みの段も順番に短く発光することで、これまで自分が積み上げた成果を実感できるようにしてください。

### 4.4 小舟の上昇

小舟は階段を一段ずつ進みます。

舟が上昇する際には、船底から金色の粒子が少量こぼれ、足場に着いた瞬間に光の輪が広がります。

上昇中も船体はほぼ水平を保ちます。階段の間を飛び跳ねたり、急降下したりする動きは使用しません。

小舟が進むことによって、村の見える角度と水平線の高さが少しずつ変化し、自分が本当に空へのぼっている感覚を生み出してください。

### 4.5 迷わせない誘導

次に触れる窓は常に一つだけです。

操作対象の窓には、以下の誘導を組み合わせてください。

- ガラスの内側で約1.4秒周期の光の脈動が起こる。
- 窓枠に沿って小さな金色の粒子が移動する。
- 3秒間操作がなければ、発光範囲を少し広げる。
- 6秒間操作がなければ、窓の周囲に光の輪が一度だけ広がる。

矢印、手のアイコン、説明文字、数字、点滅するUIは使用しません。

対象外の場所をタップしても、何も悪いことは起こりません。舟は落ちず、灯りも消えず、音による否定的な反応もありません。

時間制限、得点、残機、失敗画面、正誤判定は設けないでください。

## 5. 盛り上がりと全体の進行

全4段階、各5回、合計20回の窓の点灯を基本構成とします。

通常の遊び方で約3〜5分を目指します。ただし、プレイヤーを待たせるためだけの演出や強制的な時間調整は行わないでください。

### 第1段階：港の小さな灯り

**1〜5回目**

海面近くにある漁師の家々の窓をともします。

最初は群青色の空と青い海が広がっています。5個目の窓をともす頃には、桟橋付近に金色の反射が増え、小舟は海面から数m上昇しています。

成功音は単音を中心とし、光の玉も比較的小さくしてください。

この段階で、操作方法と、窓の点灯が階段の生成につながることを理解させます。

### 第2段階：村が目を覚ます

**6〜10回目**

斜面に建つ家々の窓を順にともします。

点灯する窓の周囲にある玄関灯や装飾用の窓にも、連鎖的に灯りがともるようにしてください。

空は群青色から青紫色へ移り、水平線に桃色の帯が現れます。海面には複数の家の灯りが反射します。

成功音には二音の和音を加えます。階段の完成時に出現する光の粒子も、第1段階より増やしてください。

### 第3段階：黄金の階段

**11〜15回目**

灯台へ続く高台の家々や、上階にある窓をともします。

既に完成した階段の側面を、小さな光の粒子が流れるようになります。

小舟が高くなるにつれて村を一望できるようになり、空の桃色と橙色が次第に広がります。

灯台のガラス張りの灯室にも光がともり、階段が灯台の上へ続いていることが理解できるようにしてください。

成功音は三和音へ発展させ、光の玉の移動速度も第1段階より約15〜20％増加させます。

### 第4段階：朝日の扉

**16〜20回目**

灯台に近い家屋、灯台の管理棟、灯台本体の窓をともします。

最後の操作対象は灯台上部の灯室の窓です。

この窓だけは、それまでの窓よりも少し大きな範囲で金色の光が脈動します。特別な瞬間が近づいていることを、文字を使わずに伝えてください。

最後の窓に灯りがともると、大きな光の玉が灯室から生まれ、最後の階段へ移動します。

### 5.1 クライマックス

最後の一段が完成した後、約10〜15秒間の特別な演出を行います。

- 完成した20段の階段を、下から上へ順番に黄金の光が駆けのぼる。
- 小舟が最後の段に到着する。
- 灯台上部から空へ向かって大きな光の輪が広がる。
- 水平線から朝日が昇り始める。
- 海面に長い黄金の反射が出現する。
- 家々の石壁、屋根、花壇、桟橋が朝日の色に染まる。
- 雲の縁が黄金色に変わり、朝もやが徐々に薄くなる。
- 音楽が豊かな長調の和音に到達する。

最大の見せ場は花火や爆発ではなく、**自分が一つずつ灯した光によって、村全体に朝が訪れる瞬間**です。

光は2〜3秒かけて大きく広がるようにしてください。全面白転、急激な点滅、画面振動は使用しません。

### 5.2 静かな余韻と再プレイ

日の出後は、約10〜15秒間、朝の海と村を眺められる状態にします。

波の音、海鳥の声、ゆっくり動く雲、小舟のわずかな揺れを残してください。

その後、画面中央に小さな金色の光の玉が現れます。この光の玉をタップすると、光に包まれながら最初の港へ戻り、再び遊べるようにします。

何も操作されない場合も、約15秒後に滑らかなクロスフェードによって最初の状態へ戻します。

リセット時には、完成した階段を撤去し、窓、空、音楽、小舟の位置、カメラ、進行状態を初期化してください。

## 6. カメラと画面構成

### 6.1 基本方針

透視投影カメラを使用し、村を斜め上から見渡す構図を基本とします。

自由な視点操作は実装せず、プレイヤーは窓のタップだけに集中できるようにしてください。

カメラの目標は常に一つとし、現在の進行状態によって切り替えます。

| 進行状態 | 画面中央に置く対象 |
|---|---|
| 操作待ち | 次にともす窓 |
| 点灯直後 | 点灯した窓 |
| 光の玉の移動中 | 上昇する光の玉 |
| 階段形成中 | 新しい階段の先端 |
| 小舟の上昇中 | 小舟の行き先 |
| クライマックス | 水平線から昇る太陽 |
| 再プレイ待ち | 再開用の光の玉 |

操作対象の窓は、画面中心から画面幅・高さのそれぞれ5％以内を基本位置としてください。

### 6.2 見切れの防止

窓から光の玉が飛び出し、階段へ向かう間は、光の玉と到着先の階段が同時に画面内に収まるようにします。

カメラの移動だけで解決しようとせず、建物の配置、対象窓の順序、階段の軌道そのものを、カメラ設計と一体で調整してください。

具体的には、次に操作する窓と次の階段の先端が、画面上で互いに離れすぎないように配置します。

画面内に収める必要のある対象を3Dバウンディングボックスなどで管理し、画面へ投影した範囲を確認してください。

必要に応じてカメラを後退させ、対象の外側に画面幅・高さの10〜15％程度の余白を確保します。

### 6.3 縦向き・横向きへの対応

- iPad横向きでは、村、窓、灯台、海を横方向に広く見せる。
- 縦向きでは、窓と光の玉の移動軌道、階段の高さを活用した画面構成にする。
- 垂直FOVは40〜50度程度を起点とする。
- 画面比に応じてカメラ距離を自動調整する。
- 画面比が変化しても、窓やクライマックスの対象が画面外に出ないようにする。

画面を単純に切り抜いて縦向きに対応する方法は禁止します。

### 6.4 カメラの動き

フレームレートに依存しない減衰補間やスプライン補間を使用してください。

カメラ移動には0.8〜1.5秒程度の補間時間を設け、急停止や急回転を防ぎます。回転速度は通常毎秒15度以内を目安とします。

大きなロール回転、船酔いを誘発する上下動、急なズーム、視点の反転、手ぶれ演出は使用しません。

次の窓の操作受付は、カメラがその窓を十分に捉えてから開始してください。

## 7. 操作と入力処理

iPad Safariのタッチ操作と、PCのマウス操作に対応してください。

入力にはPointer Eventsを使用し、`pointerdown`、`pointerup`、`pointercancel`を適切に処理します。

- 指1本またはマウスのクリックだけで全工程を遊べるようにする。
- 窓の当たり判定は、見た目の1.3〜1.6倍程度に拡張する。
- 当たり判定の最小サイズは64×64 CSSピクセル程度とする。
- 2本目以降の指による入力は無視する。
- 同じ窓を連打しても、階段が複数生成されないようにする。
- 操作演出中の追加タップによって進行状態が破損しないようにする。

`touch-action: none`、`user-select: none`、`overscroll-behavior: none`などを適切に設定し、ゲーム領域でのピンチズーム、ダブルタップズーム、スクロール、長押しメニュー、テキスト選択を抑止してください。

画面回転、ウィンドウのリサイズ、タッチのキャンセル、バックグラウンドからの復帰にも対応します。

## 8. 音響設計

すべての音をWebAudio APIによって手続き的に合成してください。外部音声ファイルは使用しません。

最初の有効なタップでAudioContextを起動またはresumeします。

### 8.1 操作と結果の音

| 現象 | 音の方向性 |
|---|---|
| 窓の点灯 | 澄んだ小さなベル |
| 光の玉の誕生 | 高音へ向かう短い音 |
| 光の玉の上昇 | きらめく分散和音 |
| 階段の完成 | ガラスと鐘を組み合わせたような響き |
| 小舟の着地 | 丸みのある低音と短い余韻 |
| 朝日の出現 | 広がりのある長調の和音 |

成功音には正弦波や三角波を中心に使用し、短い倍音と残響を加えてください。

第1段階ではC5、E5、G5などの単音、第2段階では二音、第3段階では三和音、第4段階では分散和音を組み合わせます。

最終段階ではCmaj9などの豊かな和音によって、開放感を表現してください。

すべての音に短いアタックと適切な減衰を設定し、クリックノイズや耳を刺激する高音を防ぎます。

### 8.2 環境音とBGM

環境音は、フィルターを通したノイズによる波の音、海風、遠くの海鳥の声を主体とします。

BGMは、長い間隔で鳴る穏やかな持続音や分散和音を中心にし、プレイヤーの操作音を邪魔しないようにしてください。

成功音の方が環境音より明瞭に聞こえるバランスとします。

音源数を制限し、マスターゲインとコンプレッサーによって、複数の音が重なった際のクリッピングを防ぎます。

## 9. 画面表示と禁止事項

ゲーム画面には、文字、数字、得点、進捗バー、ボタンのラベルを一切表示しないでください。

進捗は、点灯済みの窓、完成した階段の数、小舟の高さ、空の色によって自然に伝えます。

以下の要素は禁止します。

- 不気味な生き物、おばけ、怪物、お姫様。
- シュールな造形、不穏な風景、恐怖を感じさせる演出。
- 既存のキャラクター、ブランド、作品名、固有の建築意匠。
- 暗く視認性の悪い場面。
- 失敗音、警告音、時間切れ、落下、画面振動。

また、別紙の禁止語を、ソースコード、コメント、変数名、画面表示などに使用しないでください。表記を変えた使用も禁止します。

## 10. 画質の自動調整と性能最適化

2020年のiPad ProのSafariを主要な性能基準とし、通常プレイ中に50fps以上を維持することを目標とします。

### 10.1 品質プリセット

| 設定 | high | mid | low |
|---|---:|---:|---:|
| ピクセル比上限 | 1.5 | 1.15 | 1.0 |
| シャドウマップ | 2048 | 1024 | 無効 |
| ブルーム | 有効 | 簡易処理 | 疑似発光 |
| 同時光粒子数 | 400 | 180 | 80 |
| 水面メッシュ分割 | 128×128 | 80×80 | 48×48 |
| 水面反射 | 高品質疑似反射 | 簡易反射 | 基本反射 |
| 描画コール数の目安 | 150以下 | 100以下 | 70以下 |

各値は初期目安であり、実測に基づいて調整してください。

low品質でも窓の発光、光の玉、階段の形成、朝日の海面反射は必ず維持します。ゲームの核心となる演出を削除してはいけません。

### 10.2 自動画質制御

初期品質はmidとし、起動直後の描画性能と実行中のFPSを計測します。

- 平均FPSが48未満の状態が約2秒続いた場合は、一段階品質を下げる。
- 平均FPSが57以上の状態が約8秒続いた場合は、一段階品質を上げることを検討する。
- 品質変更後は5秒以上の再変更禁止時間を設ける。
- タブの非表示中や復帰直後の計測値は評価対象から除外する。

URLクエリの`?q=low`、`?q=mid`、`?q=high`によって品質を強制指定できるようにしてください。

### 10.3 実装上の最適化

繰り返し使用する石材、窓枠、屋根瓦、階段、粒子などには、InstancedMeshや共有ジオメトリ、共有マテリアルを活用します。

パーティクルはオブジェクトプールで再利用し、毎フレームの大量生成・破棄を避けてください。

ガラスの透過、雲、発光、海面反射によるオーバードローにも注意してください。

実際に描画する光源数を抑え、多数の窓の発光には疑似照明を使用します。

再プレイを繰り返しても、GPUメモリ、イベントリスナー、音源、描画オブジェクトが蓄積しないようにしてください。

## 11. 技術構成と実装要件

### 11.1 ファイル構成

ゲーム本体は以下の1ファイルに実装してください。

`site/games/d02/index.html`

HTML、CSS、JavaScript、シェーダー、プロシージャルテクスチャ生成処理、音響生成処理を、このHTMLファイル内に収めます。

Three.jsはリポジトリに同梱済みの以下のものを使用してください。

- `site/vendor/three/build/three.module.min.js`
- `site/vendor/three/examples/jsm/`

importmapにおいて、`three`は`../../vendor/three/build/three.module.min.js`、`three/addons/`は`../../vendor/three/examples/jsm/`へ解決されるように設定します。

CDN、外部画像、外部3Dモデル、外部音声、外部フォントなどへの依存は禁止します。

`<head>`内には必ず以下を含めてください。

```html
<meta name="robots" content="noindex">
```

`</body>`の直前には必ず以下を含めてください。

```html
<script src="../../gf-playlog.js" defer></script>
```

### 11.2 内部状態の管理

ゲームの進行には明示的な状態管理を使用してください。

```text
INITIALIZING
→ WAITING_FOR_WINDOW
→ WINDOW_LIGHTING
→ ORB_ASCENDING
→ STEP_FORMING
→ BOAT_ASCENDING
→ NEXT_WINDOW
→ 基本ループを繰り返す
→ GRAND_SUNRISE
→ AFTERGLOW
→ RESET
```

現在の段階、点灯済みの窓、生成済みの階段、操作対象、演出の経過時間を一元管理します。

カメラ、照明、音響、粒子、舟の移動が互いに独立したタイマーによって不整合を起こさないようにしてください。

### 11.3 準備完了とエラーの監視

以下の変数を用意してください。

- `window.__ready`：初期値false。3Dシーンの生成、初回描画、入力処理の準備が完了した時点でtrue。
- `window.__errors`：初期値は空配列。実行時エラーや未処理のPromise rejectionなどを記録する。

AudioContextの起動はユーザー操作まで待つため、準備完了の条件には含めないでください。

エラーを単に握りつぶす実装は禁止します。

### 11.4 自動プレイ

`?autotest`によって、自動プレイを実行できるようにしてください。

操作受付状態になったら現在の窓を自動的に選択し、通常のタップと同一の処理を呼び出します。

20個の窓すべての点灯、階段の形成、小舟の上昇、日の出、余韻、リセットまでを検証できるようにしてください。

自動プレイ専用の処理によって、通常の演出や状態遷移を省略してはいけません。

## 13. 実装時の最優先事項

本作の品質を判断する基準は、建物の数やシェーダーの複雑さではありません。

**一つの窓をともすだけで、世界に美しい変化が起こり、その変化が積み重なって、最後には夜明けそのものを生み出せること**が、このゲームの核心です。

写実的な村と海を基盤としながら、窓から光が生まれる瞬間、光が空へのぼる瞬間、階段が完成する瞬間、朝日が海に広がる瞬間のそれぞれに、十分な視覚的・聴覚的な手ごたえを与えてください。

性能上の制約がある場合は、背景の細部や装飾を先に簡略化し、この四つの瞬間の品質を優先してください。

5歳の子どもが最後まで自然に操作を続け、自分の指で朝を迎えられたことを喜び、もう一度遊びたいと思える作品に仕上げてください。
