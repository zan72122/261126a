# D05 実装指示文：蛍光に光る珊瑚の海

## 0. 制作概要

5歳の女の子が、子どものイルカと一体になって母イルカと海中を泳ぎ、眠っている珊瑚を指1本で次々と目覚めさせる、写実的な3D Webゲームを制作してください。

最初は静かな夕暮れの海ですが、珊瑚に触れるたびに蛍光色が広がり、熱帯魚が集まり、海全体が幻想的な光の庭へと変化します。最後には海底から水面まで続く巨大な珊瑚の塔が完成し、イルカの親子がその頂上から星空へ跳び出します。

このゲームで最も重要なのは、景色を鑑賞することではなく、**自分の指で美しい世界を生み出しているという実感**です。

写実性、操作の分かりやすさ、触った瞬間の手ごたえ、段階的に増していく感動を優先してください。

人間の子どものモデルは制作せず、子どものイルカをプレイヤーの分身とすることで、イルカに乗って海を旅する感覚を表現してください。

---

## 1. ゲームの狙い

- **夢×写実：** 指で触れた珊瑚が宝石のような蛍光色に目覚めるという夢のような現象を、実物に近い珊瑚の骨格、イルカの皮膚、魚の鱗、水中の光学現象によって説得力のある世界として表現する。
- **高揚感：** 最初は色の少なかった海が、自分の操作によって数多くの珊瑚と魚が輝く壮大な光の庭へと変貌していく喜びを生み出す。
- **爽快感：** 海底から水面へ向かって徐々に上昇し、最後にイルカの親子が水面を突き抜け、広大な星空へ跳び出すことで解放感を生み出す。

ゲームを貫く感情の流れは、「発見 → 驚き → 喜び → 期待 → 感動 → 解放」とする。

## 2. 絵から借りる光と色

### 2.1 アートディレクション

参考資料B15からは、蛍光色の珊瑚礁とイルカの親子というモチーフを借りる。参考資料B4からは、青紫色の海中、上方から差し込む光、宝石のように輝く気泡という光学的な表現を借りる。

参考作品の構図、イルカの配置、珊瑚の形状、絵柄を模倣しないこと。

現実の海洋生物を撮影した映像に、現実には存在しない魔法の発光現象が自然に溶け込んでいるような、独自の写実3D世界を目指す。

珊瑚、イルカ、魚、水面そのものは写実的に制作し、幻想性は主に光、色、粒子、音、光の伝播によって付加する。

### 2.2 時間帯と光の変化

ゲームの進行に伴い、夕暮れから星空へと移行させる。ただし、時間帯が夜に近づくほど珊瑚の発光量が増すため、画面全体の視認性は低下させない。

| 項目 | 第1段階 | 第2段階 | 第3段階 | 第4段階・終幕 |
|---|---|---|---|---|
| 時間帯 | 夕暮れ | 日没直後 | 薄暮 | 星空 |
| 水面付近の空 | `#FFC49A` | `#F3A7BA` | `#9CA9E8` | `#5366AB` |
| 海中の基調色 | `#286D91` | `#216C9F` | `#3054A0` | `#36499B` |
| 上方からの光 | `#FFE5C5` | `#FFD5DB` | `#CADFFF` | `#D9E9FF` |
| 光源の色温度目安 | 4200K | 4800K | 7500K | 9000K |
| DirectionalLight intensity | 2.0 | 1.7 | 1.5 | 1.7 |
| HemisphereLight intensity | 1.3 | 1.4 | 1.5 | 1.6 |
| 水中の霧の開始距離 | 9m | 10m | 12m | 13m |
| 水中の霧の終了距離 | 42m | 45m | 50m | 55m |
| ブルーム強度の目安 | 0.25 | 0.40 | 0.55 | 0.70 |

数値は1ワールド単位を約1mとした場合の初期調整値である。Three.jsの同梱バージョン、トーンマッピング、実際の描画結果に応じて調整してよい。

色温度は光源の色を決める際の目安とし、Three.jsでは対応するRGB色を設定する。

### 2.3 珊瑚の色彩

| 状態・種類 | HEX |
|---|---|
| 眠っている珊瑚 | `#899DA6` |
| ピンク珊瑚 | `#FF62C5` |
| エメラルド珊瑚 | `#42F5B1` |
| アクアブルー珊瑚 | `#39CFFF` |
| 紫珊瑚 | `#AC79FF` |
| 黄金色の発光 | `#FFDC8C` |
| 珊瑚の発光先端 | `#F4FCFF` |
| 誘導用の気泡 | `#BDF5FF` |

珊瑚全体を均一なネオン色に塗りつぶさないこと。珊瑚の内部構造、表面の凹凸、枝の分岐が発光後も判別できるようにする。

発光は主に枝の先端、ポリプ、表面の微細な模様に分布させ、根元には自然な陰影を残す。

### 2.4 光学表現

- 水中の光芒は、水面から海底へ向かう半透明の円錐状メッシュやシェーダーで表現する。
- 海底とイルカの背中に、揺れる水面を通過した光の集光模様（コースティクス）を投影する。
- コースティクスの移動速度は0.2〜0.4Hz程度とし、複数の周期を重ねる。
- 発光する物体の輪郭に限定してブルームを適用する。画面全体が白く霞むことを避ける。
- ブルームのthresholdは0.85前後、radiusは0.35〜0.55を初期値とする。
- 水中の微粒子は奥行きに応じて密度と視認性を変える。
- 発光する珊瑚の周囲には局所的な色付きの光を加え、近くを通るイルカや魚にもその色が映り込むようにする。

## 3. 舞台と登場するもの

すべての地形、動物、珊瑚、魚、水面、雲、星、エフェクトをプロシージャルに生成する。

外部の画像、3Dモデル、テクスチャ、音声ファイルは使用しない。必要な環境マップや表面模様は、シェーダー、CanvasTexture、数学的なノイズなどで生成する。

### 3.1 海底地形

海底は水深約22mの場所から始まる。

白い砂地、緩やかな起伏、岩礁、大小の珊瑚、海草を配置する。地形は複数の周波数のノイズを重ねたメッシュとする。

砂地には波によって形成された細かな砂紋を加え、法線の変化とコースティクスによって実在感を出す。

海底を単調な平面にせず、珊瑚の谷、岩の間を通る道、広い砂地などを配置して景色に変化を持たせる。ただし、狭い洞窟や視界を遮る障害物は設けない。

ゲームの主な舞台となる珊瑚礁の中央には、海底から水面方向へ伸びる岩礁の芯を用意する。この芯の周囲に、プレイヤーが目覚めさせた珊瑚が連続的に増えていき、最終的に巨大な珊瑚の塔となる。

### 3.2 珊瑚

最低でも次の6種類の形態を制作する。

| 種類 | 生成方法 |
|---|---|
| 枝状珊瑚 | 再帰的に分岐する曲線と先細りする管状メッシュ |
| 卓状珊瑚 | 放射状に広がる枝と水平に分岐する先端 |
| 脳珊瑚 | 球状の表面に迷路状の隆起と溝 |
| 葉状珊瑚 | 波打つ曲面を重ねた板状構造 |
| ウミウチワ | 扇状に広がる細かな分岐構造 |
| 花状珊瑚 | 小さなポリプが多数集まった群体 |

個々の珊瑚には大きさ、分岐角度、枝の太さ、色、表面模様の違いを与える。固定シードの乱数を使用し、同じ形状の単純な複製に見えないようにする。

PBRマテリアルの初期値はroughness 0.55〜0.85、metalness 0.0とする。

眠っている状態でも珊瑚として自然に見えること。発光前を枯死した珊瑚のように見せない。

### 3.3 イルカの親子

バンドウイルカを参考に、実物に近い身体の比率と輪郭を持つモデルを制作する。

球体を単に連結したモデルではなく、断面形状が滑らかに変化する胴体メッシュを生成する。吻、額、胸びれ、背びれ、尾びれを自然につなげる。

- 母イルカ：全長約2.8m。
- 子どものイルカ：全長約1.7m。
- 背中は青みを帯びた灰色、腹側は白に近い灰色。
- roughnessは0.22〜0.35、metalnessは0.0。
- 目は身体に対して実物に近い大きさとする。
- 口を人間のように動かしたり、誇張された表情を作ったりしない。

泳ぐ動作は胴体後部から尾びれにかけて位相の異なる上下運動を伝えることで表現する。魚のような左右の尾振りにしないこと。

泳いでいる間、母イルカは子どものイルカの斜め前方を並走する。ときどき子どもの方向へ顔を向けたり、速度を合わせたりする。

親子が一緒に旅をしていると自然に感じられる距離感を維持する。

### 3.4 熱帯魚

黄、青、白、オレンジ、紫など、識別しやすい色彩を持つ小型熱帯魚を5〜7種類制作する。

胴体の断面変化、尾びれ、背びれ、胸びれを持たせ、鱗の微細な模様は手続き的なテクスチャまたはシェーダーで表現する。

魚群は簡略化した群泳アルゴリズムで動かす。珊瑚が目覚めると近くの魚が集まり、やがて前方へ流れる光の道を形成する。

魚自体を完全な発光体にするのではなく、鱗に珊瑚の色が反射し、尾の後ろに短い光の粒子が残るようにする。

魚群にはInstancedMeshを活用し、描画負荷を抑える。

### 3.5 水面・海・空

水面は複数の周期を持つ波を合成したシェーダーで表現する。

- 波の振幅：0.08〜0.22m。
- 波長：1.5〜6m程度。
- 水の屈折率の目安：1.333。
- Fresnel反射を利用する。
- 海中から見上げた水面には、波によって歪む夕焼けや星空を表現する。
- 海面上では、空と月光、珊瑚の塔の色が水面に反射する。

物理的に厳密なリアルタイム屈折や反射が重い場合は、手続き的に生成した環境マップと近似シェーダーで代替する。

空は球状の背景にグラデーションを設定する。雲は低周波ノイズを使った半透明表現とし、終幕の星空は小さな点光源風のパーティクルで制作する。

## 4. 指1本のゲームループ

### 4.1 基本ループ

1回の遊びを次の順序で構成する。

| 経過時間の目安 | 内容 |
|---|---|
| 操作前 | 前方の珊瑚に気泡が集まり、次に触る対象を示す |
| タップ直後 | 接触点から小さな光の波紋が発生する |
| 0.1〜0.7秒 | 珊瑚の根元から枝の先端へ蛍光色が伝わる |
| 0.7〜1.5秒 | 珊瑚全体が輝き、周囲の水に色が広がる |
| 1.0〜2.5秒 | 熱帯魚が集まり、光の道を形成する |
| 2.0〜5.5秒 | イルカの親子が光の道を泳ぎ、次の珊瑚へ向かう |
| 移動終了後 | 次の珊瑚に気泡が集まり、再び操作可能になる |

珊瑚の発光がゲームの核である。単なるマテリアルの色変更で済ませず、光が生命を吹き込むように枝分かれした構造を駆け巡るアニメーションを制作する。

### 4.2 次に触る対象の誘導

操作可能な珊瑚は原則として常に1つとする。

対象の珊瑚を画面中央に配置し、その周囲に8〜15個程度の気泡を集める。気泡は珊瑚の周囲を旋回した後、枝の先端へ集まる。

3秒間操作がなければ、珊瑚の先端に微弱な光を走らせる。

さらに3秒間操作がなければ、母イルカが対象へ顔を向け、気泡の動きを少し大きくする。

その後も一定間隔で誘導を繰り返す。

文字、矢印、手のアイコン、説明パネルは使用しない。

### 4.3 成功時の手ごたえ

珊瑚をタップした瞬間に、次の現象を組み合わせる。

- タップ位置から水中を伝わる光の波紋。
- 珊瑚の枝を駆け巡る発光。
- 上方へ舞い上がる色付きの気泡。
- 珊瑚の周囲に集まる魚群。
- イルカの親子が前進する動作。
- 透明感のある短い成功音。
- 周囲の砂地や岩に広がる色付きの反射光。

タップと最初の反応との間に知覚できる遅延を設けない。

### 4.4 失敗のない設計

珊瑚から少し外れた位置を触っても、広めの当たり判定によって操作を受け付ける。

大きく外れた場合には何も悪いことを起こさず、自然な小さな水の波紋を表示してよい。対象の珊瑚は引き続き気泡で誘導する。

制限時間、減点、失敗音、やり直し、敵、衝突ダメージは一切設けない。

イルカの泳ぐ方向や速度を細かく操作する必要もない。プレイヤーは次の珊瑚を目覚めさせることだけに集中できるようにする。

## 5. 盛り上がりの設計

標準的なプレイ時間を約3〜5分とする。

全4段階、各5個、合計20個の珊瑚を目覚めさせる構成とする。プレイヤーが操作を休んでいる時間は制限しない。

### 第1段階：眠っている珊瑚の庭

**水深：約22〜18m**

最初は白い砂地と灰青色の珊瑚礁が広がる静かな海。

第1回目のタップでは、画面中央の枝状珊瑚が鮮やかなピンク色に目覚める。この最初の変化は特に丁寧に制作し、ゲーム開始から数秒以内に操作の意味が理解できるようにする。

5個の珊瑚を目覚めさせると、周囲の小さな珊瑚にも光が連鎖し、海底に最初の光の庭が完成する。

### 第2段階：熱帯魚が集まる光の谷

**水深：約18〜12m**

イルカの親子は珊瑚礁の間を泳ぎながら上昇する。

珊瑚を目覚めさせるたびに、前の段階よりも多くの熱帯魚が集まる。

魚群が色の異なる帯を形成し、イルカの親子と一緒に泳ぐ。

5個の珊瑚を目覚めさせると、下方に見える珊瑚と現在の珊瑚が光によってつながり、巨大な珊瑚の塔の下半分が形成される。

### 第3段階：海を貫く珊瑚の塔

**水深：約12〜5m**

珊瑚の塔の周囲を泳ぎながら、上方の珊瑚を順番に目覚めさせる。

珊瑚の形状を大型化し、卓状珊瑚やウミウチワなどを使用して、塔の輪郭を壮大にする。

珊瑚の発光が塔の上下へ伝播する演出を追加する。すでに目覚めさせた珊瑚も呼応して発光する。

プレイヤーは、自分がこれまでに行った操作が積み重なって巨大な構造物を作っていることを視覚的に理解できる。

### 第4段階：星空への入り口

**水深：約5〜0.5m**

水面が近づき、波の向こうに星空と月が見える。

珊瑚の色彩にはピンク、青、エメラルド、紫、黄金色が共存する。

最後の5個の珊瑚は塔の頂部に配置する。最後の珊瑚は花状に広がった大型の群体とし、黄金色の気泡が集まることで特別な対象だと分かるようにする。

最後のタップでクライマックスへ移行する。

### 段階ごとの変化量

| 要素 | 第1段階 | 第2段階 | 第3段階 | 第4段階 |
|---|---:|---:|---:|---:|
| 珊瑚の代表サイズ | 0.8m | 1.3m | 2.0m | 3.0m |
| 魚群の最大数（high） | 24 | 48 | 80 | 120 |
| イルカの巡航速度 | 1.2m/s | 1.5m/s | 1.8m/s | 2.1m/s |
| 成功時の気泡数（high） | 20 | 35 | 55 | 80 |
| 発光演出の持続 | 1.0秒 | 1.3秒 | 1.6秒 | 2.0秒 |
| 成功音 | 2音 | 3音 | 4音 | 5〜6音 |

速度の増加は爽快感を目的とするが、カメラを急加速させてはならない。

## 6. クライマックス：珊瑚の塔から星空へ

クライマックスは約20〜30秒かけて展開する。

### 6.1 海全体への光の解放

最後の珊瑚に触れると、黄金色の光が塔の頂上から海底へ駆け下りる。

海底へ到達した光は、今度は複数の色を伴って海底から塔の頂上へ駆け上がる。

これまでに目覚めさせた20個の珊瑚と周辺の珊瑚が順番に呼応する。塔の周囲には、螺旋状の魚群と大量の発光する気泡が集まる。

画面の瞬間的な白飛びや激しい点滅は使用せず、色の広がりと空間的な規模によって壮大さを表現する。

### 6.2 水面からの跳躍

イルカの親子は塔の頂部から伸びる光の道に沿って、水面方向へ泳ぐ。

母イルカと子どものイルカがほぼ並んだ状態で水面を突破する。

水中から水上へ移行する瞬間には、水滴、飛沫、水面に広がる波紋、月光の反射を描画する。

水面上では2頭のイルカが、星空を背景に自然な弧を描く。

跳躍の高さは水面から2〜3m程度を目安とし、カメラが急上昇・急降下する演出は避ける。カメラはイルカの運動を外側から追い、落下感を生じさせない。

イルカの親子が水面へ戻った後、海中の巨大な珊瑚の塔が水面越しに輝いている様子を見せる。

### 6.3 余韻と再プレイ

終幕後は約8〜12秒間、穏やかな海面、星空、月光、珊瑚の塔、イルカの親子を見せる。

その後、画面中央に新しい眠った珊瑚を登場させ、気泡を集める。

この珊瑚をタップすると、光の塔が遠景に残った状態で、新しい珊瑚を目覚めさせるフリープレイを開始する。

フリープレイは無制限とし、珊瑚の種類や色を変化させる。ただし、メッシュやパーティクルを際限なく追加せず、不要になったオブジェクトは再利用する。

### 7.2 フレーミングの厳守

次に触る珊瑚の中心を、操作可能時には画面中央から上下左右5%以内に配置する。

イルカの親子と対象の珊瑚は、すべて画面内に収める。吻、尾びれ、珊瑚の枝の先端なども見切れさせない。

カメラの位置を固定値だけで決めず、対象物のBoundingBoxを画面座標に投影して、適切な撮影距離を計算する。

画面の四辺には最低でも8%程度の安全余白を確保する。

### 7.3 カメラの初期設定値

- PerspectiveCameraを使用する。
- 垂直FOV：45〜52度。
- near：0.1m。
- far：150m程度。
- 親子イルカからの撮影距離：通常6〜10mを起点として調整。
- カメラ追従の補間時定数：0.5〜0.8秒。
- ロール角：原則0度。
- カメラの回転速度：毎秒20度程度を上限の目安とする。

縦向きではイルカの横方向の配置間隔も調整し、撮影距離を自動的に増やす。

珊瑚の塔を見せる場面ではカメラを徐々に引き、塔の全体像を収める。跳躍時はイルカの親子と跳躍軌道を包含する範囲を基準にフレーミングする。

カメラがイルカの身体、珊瑚、岩礁、水面などを不自然に貫通しないようにする。

## 8. 操作とタッチ判定

iPad SafariおよびPCブラウザに対応する。

Pointer Eventsを使用し、タッチとマウスを共通の処理で扱う。

タップ対象にはThree.jsのRaycasterを使用する。ただし、細い珊瑚の枝を正確に触る必要がないよう、対象の周囲に不可視の当たり判定用メッシュを設ける。

さらに画面座標上でも判定を補助し、最低96 CSS px程度の操作領域を確保する。

- 1本の指だけで全編を遊べること。
- 複数の指が触れてもゲーム状態を破壊しないこと。
- 連打によって同じ珊瑚が複数回加算されないこと。
- 操作対象が切り替わる際に二重処理を起こさないこと。
- pointercancelを適切に処理すること。
- `touch-action: none`などによってブラウザのジェスチャーを抑制すること。
- スクロール、ピンチズーム、ダブルタップズーム、長押しメニュー、テキスト選択を抑制すること。

端末の回転や画面サイズの変化によって、進行状況がリセットされないようにする。

## 9. 音響設計

音声ファイルは使用せず、すべてWebAudio APIで合成する。

最初の実際のタップを契機としてAudioContextを生成またはresumeする。

### 9.1 環境音

海中では低い周波数のフィルター付きノイズ、微かな水の流れ、時折発生する気泡音を組み合わせる。

連続音は控えめにし、成功音が埋もれないようにする。

水面へ近づくにつれてローパスフィルターのカットオフ周波数を上げ、海面上では開放的な風と波の音へと移行させる。

### 9.2 珊瑚の成功音

基本音階にはCメジャーペンタトニックなど、複数音を組み合わせても不協和感が生じにくい音階を使用する。

| 段階 | 音の構成 |
|---|---|
| 第1段階 | C5、G5による短い透明感のある音 |
| 第2段階 | C5、E5、G5による上昇音 |
| 第3段階 | C5、E5、G5、C6によるアルペジオ |
| 第4段階 | 複数オクターブの音を重ねた華やかな和音 |
| クライマックス | 低音から高音へ広がる壮大な和音と水面突破音 |

sine波とtriangle波を中心に使用し、短いアタックと自然な減衰を設定する。

気泡には短いピッチ上昇音、魚群の到着には微かなきらめき音を付ける。

マスター出力にはDynamicsCompressorNodeを設け、連打や多数の発音による急激な音量増加を防止する。

## 10. 画面の文字と開始画面

ゲーム画面には文字、数字、スコア、進捗バー、ボタンラベル、操作説明を一切表示しない。

開始画面も通常のゲーム世界の一部とする。

最初から海底とイルカの親子が見えており、画面中央には気泡が集まった眠っている珊瑚が存在する。

その珊瑚をタップすると、音響が有効になり、第1回目の珊瑚の発光が発生する。

開始のためだけの余分な操作を要求しない。

段階の進捗は、珊瑚の塔の成長、水面までの距離、魚の数、色彩、成功音によって伝える。

## 11. 画質の自動調整とパフォーマンス

2020年世代のiPad ProのSafariで、通常プレイ中50fps以上、可能であれば安定した60fpsを目標とする。

写実性を追求するために操作の応答性を犠牲にしてはならない。

### 11.1 画質プリセット

| 項目 | high | mid | low |
|---|---:|---:|---:|
| ピクセル比上限 | 1.75 | 1.25 | 1.0 |
| シャドウマップ | 2048² | 1024² | 無効 |
| ブルーム | 有効 | 低解像度 | 簡易発光 |
| ブルーム描画解像度比 | 0.5 | 0.33 | — |
| 水中浮遊粒子 | 800 | 400 | 160 |
| 魚群最大数 | 120 | 72 | 36 |
| 成功時最大気泡数 | 80 | 45 | 24 |
| 局所的な動的光源 | 4 | 2 | 1 |
| 遠景珊瑚のLOD | 高 | 中 | 低 |

lowでも珊瑚が目覚める演出、魚群による光の道、イルカの親子、塔の完成、水面からの跳躍は省略しない。

### 11.2 自動切替

初期設定はmidを基本とし、起動直後からフレーム時間を測定する。

- 3秒程度の平均FPSが48未満なら、1段階画質を下げる。
- 12秒程度の平均FPSが57以上で安定していれば、上位設定を試す。
- 頻繁な往復を避けるため、切替にはクールダウン時間を設ける。
- クライマックスの途中では不要な画質上昇を行わない。

URLパラメータ`?q=low`、`?q=mid`、`?q=high`で画質を強制できるようにする。強制指定時は自動切替を無効にする。

### 11.3 描画負荷の抑制

珊瑚の枝や魚、気泡、浮遊粒子は可能な限りInstancedMeshや共有ジオメトリを利用する。

地形や遠景の珊瑚にはLODを適用する。距離によって細かな表面構造を省略する。

リアルタイムの体積光、複雑な流体シミュレーション、毎フレームのキューブマップ生成、全オブジェクトの動的な影など、描画負荷の大きい処理は避ける。

粒子の生成にはオブジェクトプールを使用する。毎フレームの大量のオブジェクト生成やガベージコレクションを防ぐ。

## 12. 技術構成

### 12.1 ファイル構成

完成物は以下の1ファイルとする。

`site/games/d05/index.html`

HTML、CSS、JavaScript、シェーダー、手続き的な音響生成処理を同一ファイルに収める。

Three.jsはリポジトリに同梱済みのものを利用する。

| importmapの指定 | index.htmlからの相対パス |
|---|---|
| `three` | `../../vendor/three/build/three.module.min.js` |
| `three/addons/` | `../../vendor/three/examples/jsm/` |

CDNや外部ネットワークへの依存は禁止する。

`<head>`内には以下を必ず含める。

`<meta name="robots" content="noindex">`

`</body>`の直前には以下を必ず含める。

`<script src="../../gf-playlog.js" defer></script>`

### 12.2 ゲーム状態の管理

最低限、次の状態を区別して管理する。

| 状態 | 内容 |
|---|---|
| READY | 最初の珊瑚へのタップ待ち |
| WAIT_TOUCH | 対象の珊瑚への操作待ち |
| AWAKEN | 珊瑚が目覚める演出 |
| SWIM | 次の対象への移動 |
| STAGE_TRANSITION | 段階移行演出 |
| CLIMAX | 光の解放と水面からの跳躍 |
| AFTERGLOW | クライマックス後の余韻 |
| FREE_PLAY | 継続して珊瑚を目覚めさせる遊び |

アニメーションはフレーム数ではなく経過時間に基づいて更新する。

ブラウザがバックグラウンドに移行した場合は時間進行を一時停止し、復帰時にアニメーションが飛ばないようにする。

### 12.3 起動確認とエラー収集

- `window.__ready`：初期値はfalse。必要な初期化と最初の描画が完了し、操作を受け付けられる状態でtrueにする。
- `window.__errors`：初期値は空配列。実行時エラーや未処理のPromise rejection、初期化エラーなどを収集する。

AudioContextがユーザー操作を待っていることは、起動エラーとして扱わない。

### 12.4 自動プレイ

`?autotest`を付けて起動した場合、自動プレイを実行する。

通常プレイと共通の操作処理を経由して、20個の珊瑚を順番に目覚めさせ、全4段階、クライマックス、余韻、フリープレイ到達までを自動で進行させる。

単にゲーム状態を最終状態へ書き換えるテストにはしない。

テスト時間を短縮する場合は、アニメーション時間を一定倍率で短縮してよいが、各状態の遷移や演出処理は省略しない。

自動プレイ時にブラウザの音響起動制限が存在しても、映像とゲーム進行のテストを継続できるようにする。

## 13. 制作上の禁止事項

- 気持ち悪い生物、おばけ、怪物、不穏な世界、恐怖演出を出さない。
- 捕食、攻撃、負傷、溺水、酸素不足などを表現しない。
- お姫様、人間の全身モデル、既存キャラクター、既存作品の固有要素、ブランド要素を出さない。
- 参考作品の構図や絵柄を模倣しない。
- 写実性を欠いた単純な球体の集合で海洋生物を表現しない。
- 珊瑚の発光を単純な色変更だけで済ませない。
- 景色を眺めるだけの時間を長くしない。
- 急回転、画面の揺れ、急降下、激しい点滅を使用しない。
- 夜の場面でも、イルカ、珊瑚、水面の形状を十分に判別できる状態を維持する。
- 実装コードおよびコード内のコメントには、別紙の禁止語を使用しない。

## 15. 最終的な品質目標

完成時に目指すのは、美しい海中を移動するだけの鑑賞型コンテンツではない。

子どもが珊瑚に触れるたびに、色が生まれ、魚が集まり、光が広がり、イルカが前進し、水面が近づき、世界が変わる。

一つひとつの小さな操作が、最後には海全体を貫く巨大な光の塔という成果につながる。

クライマックスでは、それまで自分が目覚めさせた珊瑚のすべてが呼応し、イルカの親子とともに星空へ飛び出す。

この因果関係と達成感を、文字による説明なしで伝えること。

**最初の一度のタップで夢中になり、最後の跳躍でもう一度遊びたくなる作品を完成させてください。**
