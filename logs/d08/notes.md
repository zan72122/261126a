# D08 月面から青い地球へ跳ぶ — 実装メモ

## 実装の要点

- 1ファイル `site/games/d08/index.html`（HTML＋CSS＋JS＋GLSL）。Three.js は同梱版（r0.187.0）を importmap で読む。外部画像・モデル・テクスチャ・音声・フォントは使っていない。地形・岩・地球・雲・星・宇宙服の子ども・ウサギ・音・光の粒はすべてコード内で生成。
- **月面**: 解析的な高さ関数（多周波ノイズ＋半径 3〜25m のクレーター約 260 個＋小さな窪み約 900 個＋第4段階の大きな丘）。クレーターは「中心の窪み・盛り上がったふち・外側の斜面」を smooth-min でつないだ連続曲面。地形メッシュは進行方向に沿った帯状（幅 ±200m）で、中央ほど密な格子（画質で 40/65/100% の密度）。チャンクに分けて視錐台カリング。
  - 色は頂点カラー（砂 `#BCB8AF`、クレーター内部 `#626D83`、ふち周辺は日照色 `#E4DED3` 寄り）＋ 256² の手続き生成の砂粒テクスチャ（法線・色むら）。MeshStandardMaterial（roughness 0.93, metalness 0.02）。
  - 夢の演出として月面をカメラから 20m より先で丸く落とす（頂点シェーダーで gl_Position のみ変更。影の計算は元の座標のまま）。跳ぶほど地平線が下がり、クライマックスで上昇すると月が丸い天体として遠ざかる。
  - 岩は InstancedMesh（変形した球の 3 形状、大きさ・回転・色を変える）。進路の帯（|x|<2.7m）には置かない。進路近くは小石だけ。
- **地球**: 起動時に GPU で正距円筒の地表テクスチャと雲テクスチャを焼く（high 2048×1024、mid/low 1024×512。毎フレーム再生成しない）。大陸は緯度経度の楕円の集合＋ノイズの海岸線で実在の配置を連想させる形。深い海 `#1255B5`・沿岸 `#35CBEF`・森林・乾燥帯・山・極氷。雲は別の球（半径 1.008 倍）で、渦（5か所）・雲帯・細かな雲を多層ノイズと座標のゆがみで作り、地表と少し違う速度で回す。海だけに太陽の鏡面反射（白金色）。大気は 2 層（薄い層 1.035 倍と広がる光 1.2 倍）で、視線と球の最近接距離から輪郭ほど強く、太陽側で強く光る。
  - 地球は「無限遠」として毎フレームカメラから一定距離に置き、見かけの直径（画面短辺比）は成功回数に結び付けて 14% → 24% → 38% → 55% → 67.5%、クライマックスで 80%（大気を含め四辺 7% の余白に収まる上限）。ジャンプ中に放物線の進み具合に合わせて大きくなる（時間経過だけでは変化しない）。
  - 画面上の位置: 水平は常に中央（進路とカメラの向きが一直線）。縦は上端の余白 7% を守る位置を目標に、カメラの傾きに対してゆっくり追従させ、四辺の余白をはみ出す場合だけ強制的に収める。
- **星**: Points（high 1600 / mid 800 / low 400）。白中心に一部青白・淡い金色。各星が独立した周期でわずかに瞬く。地球より奥に置いて深度で隠す（地球の手前に星が透けない）。左上遠方に小さな環のある琥珀色の惑星を 1 つ。
- **空**: 紺 → 青紫のごく緩いグラデーション、紫と金の淡い星雲の帯、地球方向の淡い光。
- **子ども（宇宙服）**: 階層モデル（腰・胴・頭／肩・肘／股・膝）。白い宇宙服、布のひだ（細いリング）、銀色の接合部、生命維持装置、金色がかったバイザー（環境マップの反射）。顔は描かない。膝を曲げる踏み切り、空中で腕を広げる、着地で膝を沈める、歩き。宇宙服・ウサギには進行に応じて地球の青い輪郭光（フレネル）が増える。
- **ウサギ**: 胴・胸・腰（後ろ脚）・後ろ足・前脚・頭・頬・耳（内側は桜色）・目（黒褐色）・鼻・尾を立体で構成。踏み切り前に縮む、空中で後ろ脚を伸ばす、着地後に耳が揺れる、待機中は耳・鼻を動かし地球を見上げ、小さく跳ねる。子どもより 0.15 秒早く跳び、少し先に着地する（離れすぎない）。
- **ゲームループ**（状態: WAIT 待機 / APPROACH 接近 / TAKEOFF 踏み切り / FLIGHT 浮遊 / LAND 着地 / STAGE 段階移行 / FINAL 最終跳躍 / AFTER 余韻 / RETURN 再開）
  - 開始時から光るふちの前に立っている。光るふち（クレーターの手前側のふちに沿った金色の帯、波紋が外へ流れ、光の粒が立ちのぼる）に触れると最初のジャンプ。
  - ジャンプはクレーターを飛び越える放物線（重力 1.62m/s²、高さ 2.3→8.6m、滞空 3.4→6.5 秒、水平 9→33m、24 回）。着地点から次のふちへ自動で歩く（2 秒前後）。
  - 入力: タップした瞬間（同じフレーム）に鈴の音・足元の金色の輪・光の粒・ふちの閃光。接近中のタップは予約し、到着時に自動で跳ぶ。待機中に触らなければ 2.5 秒でふちがゆっくり明滅、5 秒でウサギが見本の跳躍。何もない場所のタップは光の粒と澄んだ音だけ（失敗表現なし）。ジャンプ中の連打は無視。当たり判定はふちの投影長の 1.5 倍の楕円（最小は短辺の 20%×15%）＋子ども・ウサギの周り。
  - 段階: 6 回ごとに段階移行（地球を見上げる間、水色の大きな輪、澄んだ音）。第2段階以降は着地で青い点光源が近くの岩を一瞬照らす。第3段階以降は空中で青白い光の粒が流れる。第4段階のふちは金色と水色が重なる。最後のふちは直径 26m のクレーターを一周する大きな光の輪で、ウサギと子どもが地球を見上げて待つ。
  - クライマックス（15 秒）: 0〜2 秒 金と水色の光が足元へ集まり深く縮む → 2 秒 大きな踏み切り（光の粒・輪・和音）→ 上昇しながら月が遠ざかり、地球が 80% まで大きくなって画面中央へ、光の粒が流れ下る → 9.5〜15 秒 地球の輪郭から広がる光が画面全体を包む（地球の円は常に見えたまま）。カメラはロール 0、回転は毎秒 15 度以下に制限。
  - 余韻 13 秒（光が落ち着き、星の中で穏やかに浮かぶ）→ 青白い光のクロスフェード（1.9 秒で覆い、その間に初期化、2.7 秒で戻す）→ 最初のふちが光り、触れると再プレイ。
- **カメラ**: 子どもの後方 6.2m（縦長は最大 7.6m）・高さ 3m から追従（時定数 0.4〜0.55 秒）。光るふちが画面上端から 60% の位置に来るよう傾きを計算（毎秒 15 度以下）。縦 FOV は横長 50 度、縦長 52〜58 度。画面回転・リサイズでは再計算のみ（進行は維持）。
- **音**（WebAudio のみ）: 最初の pointerdown/pointerup/touchend で AudioContext を生成・再開。マスター 0.5 → DynamicsCompressor、生成したインパルスの残響。タップ＝鈴、踏み切り＝正弦波＋三角波 250→600Hz、浮遊＝持続音（段階で 1→2→3→4 音）、最高点＝小さな倍音、着地＝フィルターを通したノイズ＋和音（単音→2音→長三和音→オクターブと高域）、点灯＝遠い鈴、クライマックス＝ C を基にした 10 音を時間差で重ねる。低音量の環境音。同時発音数を制限、非表示で suspend・復帰で resume。
- **画質**: 初期 mid。0.5 秒ごとの FPS で、48 未満が 3 秒続けば 1 段下げ、58 以上が 12 秒続けば 1 段上げ（変更後 8〜14 秒は待機、待機・接近・着地中のみ変更）。`?q=low|mid|high` で固定。
  - low: ピクセル比上限 0.85、影 512²、ブルームなし、星 400、粒子 80、地球テクスチャ 1024、地形密度 40%、岩 520。mid: 1.15、1024²、半解像度ブルーム、800、180、1024、65%、900。high: 1.5、2048²、ブルーム、1600、360、2048、100%、1400。ACESFilmic、露出 1.06。ブルーム強度は段階で 0.25→0.4→0.65→0.95、threshold 0.92、radius 0.45。
  - 地形密度と地球テクスチャの解像度は起動時の画質で決め、自動調整では作り直さない（それ以外は即時に切り替え）。
- **必須項目**: `<meta name="robots" content="noindex">`、`</body>` 直前に `gf-playlog.js`、`window.__ready`（3 フレーム描画後に true）、`window.__errors`（error〔リソース読み込み含む〕/ unhandledrejection / フレーム内例外 / 初期化エラーを記録。最初の script で登録）、`?autotest`（通常と同じ `onDown/onUp`→当たり判定→状態遷移に合成座標を渡す。接近中の予約タップ、外れタップ、空中の連打も混ぜる。全 24 回 → クライマックス → 余韻 → 再開 → 再プレイ開始まで。時間倍率は既定 3 倍、`&speed=1` で等倍）。ゲーム画面に文字・数字なし（読み込み中は中央の小さな光の輪だけ）。
- 再プレイでは粒子・輪・メッシュ・音源・リスナーを作り直さず再利用。テスト用の読み取り専用フック `window.__d08`（状態、目標と地球の画面座標など）。

## 確認結果（このクラウド環境）

- `python3 -m http.server`（ルート `site/`）＋ Playwright の Chromium（ヘッドレス、`--use-angle=swiftshader --enable-unsafe-swiftshader`）。結果は `logs/d08/test.txt`（tee で保存）。
- `games/d08/index.html?autotest&q=low` を最初から通しで実行（途中を飛ばす仕組みは使っていない）。結果は下の「最終テスト結果」を参照。
- 最終テスト結果:
  - 1024x768（横）: `__ready`=true（約 3.4 秒）、`__errors`=[]、コンソールエラー 0。着地 23 回＋最終跳躍 → 9 状態すべて通過（WAIT/APPROACH/TAKEOFF/FLIGHT/LAND/STAGE/FINAL/AFTER/RETURN）→ 再プレイ開始。PASS。
  - 768x1024（縦）: 同上（`__ready` 約 3.7 秒）。PASS。
  - 構図（約 150ms ごとに投影座標を取得）: 待機・接近中の光るふちの横位置は中央から 0.0%、縦は上端から 60% 前後（45〜65% を外れたサンプル 0/221）。地球の中心の横ずれ 0.0%、大気を含めた外周が上・左右の 7% 余白を割ったサンプル 0/812（横）・0/813（縦）。クライマックス・余韻では四辺すべての 7% 余白内（0/85 違反、横画面の下端は最大 93.0%）。
  - 実際のポインター入力（同じ test.txt の末尾）: 1024x768 high（マウス）、834x1194 mid（タッチ）、390x844 mid（タッチ）、1194x834 low（マウス）で、隅の外れタップでは状態が変わらず、ふちへのタップで即 TAKEOFF → FLIGHT。エラーなし。
- スクリーンショット（low 画質）: `shot-1.jpg` 序盤（第1段階 3 回目の浮遊）、`shot-2.jpg` 中盤（第3段階の浮遊）、`shot-3.jpg` クライマックス（地球の光に包まれる場面）。サムネイル `site/thumbs/d08.jpg`（640x480、mid 画質、文字なし）。
- 禁止語の grep（ゲーム本体・メモ）: 該当なし。

## 未解決の点・注意

- iPad 実機での性能（50fps 目標）・見え方・音は未確認。ヘッドレスは SwiftShader（CPU 描画、約 10fps）なので FPS は参考にならず、自動画質調整のしきい値も実機では未検証。
- 第3〜4段階の地上では、地球（直径が短辺の 38〜67%）の下部が月の地平線に隠れる（地球が地平線から昇る見え方）。画面の端で切れることはなく、跳んで高く上がると地平線が下がって全体が見える。クライマックス・余韻では地球全体が四辺 7% の余白内に収まることを確認。
- 縦長（768x1024）ではクライマックスの光が画面全体を覆うため、子どもとウサギが淡くかすむ（地球の円は見えたまま）。
- 宇宙服の子どもとウサギは単純な形状の組み合わせで、近くで見ると簡素。
- 自動画質調整で画質を上げても、地形の密度と地球テクスチャの解像度は起動時のまま。
- 位置合わせの試行用に `?dbg` のときだけ内部オブジェクトを `window.__dbg` に出す（通常プレイには影響なし）。
