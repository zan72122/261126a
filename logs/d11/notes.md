# D11 オーロラの譜面で舟をのぼらせる — 実装メモ

## 実装の要点

- 1ファイル `site/games/d11/index.html`（HTML＋CSS＋JS＋GLSL）。Three.js は同梱版を importmap で読む。外部画像・モデル・音声・フォントなし。湖・薄氷・雪山・針葉樹・舟・木目・空・月・星・オーロラ・音はすべてコードで生成。
- **舞台**: 直径約 820m の湖（岸の半径 412m＋ゆらぎ）。周囲は極座標の地形メッシュ（尾根状のフラクタルノイズ、高さはおよそ 60〜200m）。斜面角と標高で雪・岩・氷の頂点色を混ぜる。岸辺に InstancedMesh の針葉樹。霧は FogExp2（#789BC5 基準、進行で色が変わる）。
- **水面**: 専用シェーダー。方向と周期の違う 4 つの波＋ノイズで法線を時間変化。フレネル。反射は毎フレーム低解像度の鏡面 RenderTarget（斜め近クリップ面つき）に空・オーロラ・光の帯・舟・光球（mid/high は山と木も）を描き、法線で揺らして読む。月のきらめきは水面の法線で細かく分断。ランタンの暖色の映り込み。タップで円形の波紋（最大 5 つ）。
- **薄氷**: 不規則な多角形（厚さ 6〜26mm）を舟の周りに配置し、舟の前方は水路として空ける。専用シェーダーで Voronoi の亀裂 2 段・微細な法線・霜・フレネル反射（鏡面 RT）・月の映り込み。タップの 0.6 秒後に舟から外へ光が伝わり、亀裂がきらめく。
- **舟**: 断面を変えながらロフトした船体（全長 3.2m・幅 1.25m）、Canvas で描いた木目と板の継ぎ目（#9A6841〜#C59B70、bumpMap）、舷縁、座板 2 枚、床板、真鍮の金具（metalness 0.82、空から作った PMREM 環境で反射）、船首のガラスのランタン（暖色の PointLight＋小さな光）。水上では小さく上下・傾くが、カメラには伝えない。人物・動物は出さない。
- **オーロラ**: 舟に追従する「空のフレーム」の中に、CatmullRom の中心曲線から作ったカーテン状メッシュを最大 7 枚（low 3 / mid 5 / high 7、分割は 64×12〜256×32）。頂点シェーダーで、3 周波数の折り目のうねり・高さのゆらぎ・タップ位置から左右へ進む波（カーテンを押し広げ、裾を下げる）・光球へ向かう裾の垂れ下がりを GPU で計算。フラグメントでは下縁が濃く上へ消える発光、縦の光の筋（3 オクターブ、ゆっくり移動）、折り目で見かけの厚みが増える効果、緑→青→紫の縦の色勾配と下縁の桃色、タップごとに加わる色の筋（各帯 6 本まで累積）。加算合成（アルファは書かない）。
- **光の帯（湖から天空への坂道）**: 舟の進路（湖上で平ら → 傾き最大 0.6 で上昇 → 高度約 150m で湖上空を半径 170m で周回）に沿った幅 8.4m の帯と、その両縁から垂れる短いカーテン。13 回目から空の側に現れ、タップごとに舟へ伸び、18 回目で船底に届く。流れる光、タップで前方へ走る波。
- **光球**: 白金色の芯＋オーロラ色の光輪＋淡い十字の光。1.2 秒周期で呼吸。見かけの直径を常に画面短辺の 10% に保つ（距離から毎フレーム計算）。当たり判定は見た目の 1.7 倍（最小半径 32px）。放置 3 秒で脈動が強まり、6 秒で光の粒が吸い寄せられ、10 秒で小さな光の輪（3.2 秒ごと）。
- **進行（24 回）**: 状態は INTRO / STAGE_1〜4 / CLIMAX / AFTERGLOW / FREEPLAY。成功回数・オーロラの下縁の高さ・舟の位置と速度・発光強度・色の進行を別々の変数で持ち、経過時間で更新。タップ直後に鈴と光の輪、0.2 秒でカーテンの波、0.4 秒で色の筋、0.6 秒で薄氷と湖面、1 秒で裾が湖へ近づき、約 1.9 秒で次の光球。6 回目で青い帯、12 回目で紫の帯が空を横切って現れ、13〜18 回目で裾が湖面へ降りて光の帯が伸び、舟の下に光の粒が集まる。18 回目で帯が船底に届き、水滴（落ちると波紋）と波紋を残して舟が浮く。19〜24 回目は速度 2→8m/s、左右を光の粒が後方へ流れる。24 回目でクライマックス（約 18 秒）: 最後の光球から大きな光が広がり、全カーテンを順に波が駆け抜け、空全体に色が満ち、ブルームが一時的に強まり、最も豊かな和音。舟は 11m/s で上昇し、カメラは事前に引く。余韻 10 秒で減速して漂い、以後は舟の前に光球が現れ続けるフリープレイ（湖の上空を周回）。
- **カメラ**: 舟の後方 7.5m（縦長 8.8m）・高さ 3.2m（3.6m）から、次の光球を注視。光球の位置は次に出る分も先に計算して向きを合わせる。位置は時定数 0.45 秒、向きは毎秒 15 度（クライマックス 11 度）以下に制限し、ヨー・ピッチだけでロールは 0。縦長は縦 FOV を広げる（52〜68 度）。上昇中・クライマックスは距離と高さを段階的に増やす。
- **音（WebAudio のみ）**: 最初の pointerdown / touchend で AudioContext を作成・再開。マスター → コンプレッサー、生成インパルスの残響。成功音は C のペンタトニックで 24 音の独自の旋律（第1段階: 鈴の単音、第2: 鈴＋ハープ、第3: 和音と長い残響、第4: 高音の旋律と広い和音、クライマックス: 低音から高音までの 12 音の協和音と鈴のカスケード）。環境音: 風・湖のさざ波・薄氷の微かな音・舟が浮く時の水滴・上昇中の空気。同時発音数を制限。非表示で suspend。
- **画質**: 起動は mid（`?q=` で固定、固定時は自動切替なし）。0.5 秒ごとの FPS で、48 未満が 3 秒続けば 1 段下げ、57 以上が 15 秒続けば 1 段上げ（変更後 10〜20 秒は待機、クライマックス中は上げない）。全画質で HalfFloat の合成バッファに描いてから ACESFilmic（露出 0.96）で出力（low はブルームなし、mid は半解像度、high は等倍のブルーム）。ピクセル比上限 0.75 / 1.0 / 1.5、影 なし / 512 / 1024、星 800 / 1500 / 2500、粒子 180 / 500 / 1200、鏡面反射 RT 1/4・1/3・1/2 解像度。地形・樹木・薄氷の量は起動時の画質で決める。
- **必須項目**: noindex、`</body>` 直前の `gf-playlog.js`、`window.__ready`（3 フレーム描画後）、`window.__errors`（error / unhandledrejection / フレーム内例外 / 初期化エラー）、`?autotest`（光球が完全に形成されたら、その画面座標へ実際の PointerEvent を canvas に送る。通常と同じ当たり判定・成功処理。外れタップも 3 回混ぜる。速度は既定 2 倍、`&speed=` で変更）。ゲーム画面に文字・数字なし（読み込み中は中央の小さな光の輪だけ）。テスト用の読み取りフック `window.__d11`。`?dbg` のときだけ内部オブジェクトと一時停止フック（撮影用）を `window.__dbg` に出す。

## 確認結果（このクラウド環境）

- `python3 -m http.server`（ルート `site/`）＋ Playwright の Chromium（ヘッドレス、`--use-angle=swiftshader --enable-unsafe-swiftshader`）。結果は `logs/d11/test.txt`（tee で保存）。
- `games/d11/index.html?autotest&q=low` を最初から通しで実行:
  - 1024x768（横）: `__ready`=true、`__errors`=[]、ゲーム由来のコンソールエラー 0。24 回成功 → STAGE_1〜4 / CLIMAX / AFTERGLOW / FREEPLAY をすべて通過し、フリープレイで次の光球が出るところまで到達。光球が触れられる間の中心からのずれは最大 3.6%（8% 超 0 件）、見かけの直径は短辺の 10%。クライマックスの光は中心から上下 32% 以内。PASS。
  - 768x1024（縦）: 同上。ずれ最大 7.4%（8% 超 0 件）、クライマックスの光は中心から 24% 以内。PASS。
  - コンソールに出る唯一のエラーは `gf-playlog.js` がプレイログを送る `https://gf-playlog.zan72122.workers.dev/log` への通信がこの環境のネットワークで遮断されたもの（ゲーム本体の通信ではない）。それ以外の外部通信なし。
- mid / high も自動プレイでクライマックス・フリープレイまで到達することを撮影用スクリプトで確認（エラーなし）。
- スクリーンショット（low、1024x768）: `shot-1.jpg` 序盤（第1段階）、`shot-2.jpg` 中盤（第3段階、光の帯が伸びる）、`shot-3.jpg` クライマックス。サムネイル `site/thumbs/d11.jpg`（640x480、mid、オーロラが湖へ降りてくる場面、文字なし）。
- 禁止語の grep（ゲーム本体・メモ）: 該当なし。

## 未解決の点・注意

- iPad 実機での性能（50fps 目標）・見え方・音・タッチは未確認。ヘッドレスは SwiftShader（約 10fps）なので FPS と自動画質調整のしきい値は実機では未検証。mid/high は鏡面反射で山も描き直すため、実機で重ければ自動で low へ下がる。
- 画質（特にブルームの有無）で白飛びの度合いが変わる。mid/high のクライマックスと上昇中は光の量が多く、やや白っぽい。
- オーロラは舟に追従する「空のフレーム」に置いている（遠くにあるものとして振る舞う）。そのため舟が進んでもオーロラとの距離は大きく変わらず、近づく感じは裾の下降と光の帯で表している。
- 縦長では光球の位置が新しい光球の出現直後に中心から最大 7.4% ずれる瞬間がある（8% 以内）。
- 影は舟の周りだけ（mid/high）。地形には影を落としていない。
- 鏡面反射は水面全体を y=0 の平面として扱うため、薄氷（厚さ数 mm）の反射もそれで近似している。
