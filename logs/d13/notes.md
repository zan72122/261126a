# D13 浮かぶ乗りもので巨木の森を抜ける — 実装メモ

## 実装の要点

- 1ファイル `site/games/d13/index.html`（HTML＋CSS＋JS＋GLSL）。Three.js は同梱版を importmap で読む（EffectComposer / RenderPass / UnrealBloomPass / OutputPass / BufferGeometryUtils）。外部画像・モデル・音声・フォント・CDN なし。樹皮・岩・地面・葉・草・シダ・葉の舟の葉脈・木の床・翅・雲・光の粒の画像はすべて Canvas とノイズで生成（樹皮・岩・地面は法線マップも生成）。
- **進行**: ステートマシン INIT / WAIT_SEED / GERMINATE / GROW / FLY / STAGE_TRANSITION / FINALE / AFTERGLOW / RESET。4段階×6回＝24回。1回の成功は「タップ→0.1秒で発光と鈴→0.5秒まで外皮（3枚の殻）が開き光の粒が散る→0.45〜1.4秒で岩が飛んで集まり島の本体が育つ→1.0〜2.0秒で土の上に草が中心から外へ広がる→1.4〜2.8秒で根・幹・枝・葉の順に成長→2.8秒で島の上面を金色の波紋が走り花粉が舞い上がる→舟が島の上を通って次の地点へ（約3〜4.6秒）→飛行の後半で次の種が現れる」。時間はすべて deltaTime。処理中の連打・2本目以降の指は無視。
- **経路**: セッションごとの乱数で、待機点 W0〜W23 と島の上空の通過点を CatmullRom（centripetal）でつなぐ。高度は 5.5→20（第1段階）→65（第2段階）→115（第3段階）→160m（第4段階）。各ホップの長さ 14/24/34/44m、速度 4.2/6.6/9.4/12m/s 前後（加減速は連続イージング）。
- **島**: 極座標の格子で上面（起伏・池のくぼみ）と下に垂れた岩の側面（ノイズで変形、下向きの突起、地層の縞、苔）を作る。島ごとに乱数で輪郭・岩の色・木の形・花の色を変え、再プレイ時は新しいシードで作り直す（古い島は dispose）。島の直径は段階ごとに約 3.4〜4 / 4.2〜5.8 / 6.2〜8.8 / 8.2〜11.8m、最後は 23m。木は第1段階が若木、第2段階が枝の広がった花の咲く木、第3段階は複数の木・花畑・泉・滝、第4段階は大きめの木と滝。舟が島の上を低く通るように、木は経路から樹冠半径＋1.3m 以上横にずらして置く。
- **成長の見せ方**: 幹・枝・根・葉を1つのジオメトリにまとめ、各頂点に「付け根の位置」と「開始時刻・長さ」を持たせ、頂点シェーダーで付け根を中心に伸ばす（幹→枝→小枝→葉の順。葉は少し膨らんでから落ち着く）。草・花・シダは InstancedMesh で中心から外へ順に生える。土→草の色の変化と完成時の金色の波紋は島の頂点色をシェーダーで切り替えて表現。成長が終わるまで影は落とさない。
- **森**: 樹高およそ 30〜68m の巨木（幹は断面の半径と根元の張り出し・溝を変化させたチューブ、地表に広がる根、枝、葉の房）を経路の周りに約60本、遠景に簡略な木を約120本。舟とカメラの通り道（経路の点と、その3.5m・6.5m上・4m下）と枝葉・幹が交わらない位置だけに置く。地面は苔と土の生成テクスチャ＋法線、シダと苔むした石。森の中は太陽方向に傾いた透過の光の筋（low 3 / mid 8 / high 16本）と漂う花粉（舟が通ると押し流される）。蝶（森）と白い鳥（樹冠より上）は羽ばたきのあるプロシージャルメッシュで、カメラに近づかない。
- **空と雲海**: 天頂〜地平線のグラデーションと太陽のシェーダー。雲海は y=50 の2枚の半透明シェーダー面（多重ノイズ、太陽方向の陰影、遠方は地平線色へ）＋ビルボードの雲。森の上は雲に穴を開けて森が見えるようにし、第2段階の終わりで樹冠を抜けると雲海と遠くの浮き島（16個）が見える（和音と光の粒の演出）。泉は Fresnel・2〜4方向の波の法線・空と太陽の疑似反射・縁の透明感、滝は流れる筋のシェーダー＋しぶきの粒。
- **段階の色と光**: 指示文の表（空・太陽色・光の強さ・霧・Bloom）を高度から求めた段階値で補間。ACESFilmic、sRGB 出力、露出 1.06。ポストエフェクトは常に EffectComposer → OutputPass でトーンマッピングを1回だけ行う。
- **舟**: 全長 3.2m・幅 1.6m の葉の船体（先端が反り上がる流線形、縁が反り返る、生成した葉脈テクスチャと法線、roughness 0.42）、太い中央の葉脈、後ろで丸まる葉柄、木の床（5枚の板と梁）。停止中は周期4秒・振幅0.07mで上下、傾きは最大5度。船底に青緑の光の粒、後方に金と青緑の光の航跡。人物は出さない。
- **種**: 長径約0.95m、琥珀色の半透明の3枚の殻（繊維テクスチャ）＋発光する芯＋光の輪＋周回する14個の光の粒、1.7秒周期の明滅、ゆっくり回転。段階が進むとエメラルド・桃色・青紫・金色に。放置2.5秒で発光が強まり波紋、6.5秒以降は前後に小さく揺れて芯が脈打つ（約4秒ごとに繰り返す）。逃げない・時間切れなし。最後の種は3.2倍の大きさで第4段階の途中から遠くに見える。
- **クライマックス**: 24回目で金色の光の輪→岩が集まり直径23mの島→中央から高さ約21mの大樹が約6秒で成長（10本の枝と小枝、葉と花）→4本の滝→周囲の浮き島から光の柱→虹色と金色の粒が立ち上り、樹冠に光のかさ。舟は大樹の手前で止まる。余韻13秒（花びら・鳥・滝）のあと、雲が画面を覆うシェーダーで穏やかに場面転換して森の最初の種に戻る（落下演出なし）。
- **カメラ**: 舟の斜め後方（8〜9m、高さ2.4〜2.7m）から、その時点の対象（種／成長中の島の最終サイズの箱／次の種／最後の島の箱）を注視。対象の最終的な BoundingBox の8頂点から、上下左右に10%の余白が残る距離を水平・垂直FOVで解析的に求め、足りなければ注視線に沿って引く（成長前から引き始める）。位置0.6秒・注視0.45秒の時定数で追従、ロール0。縦向きは垂直FOVを60度に広げる。カメラが島の木や本体の球に入りそうなら押し出す。
- **音（WebAudio のみ）**: 最初の pointerdown / touchend で AudioContext を作成・再開。コンプレッサー＋生成インパルスの残響。種のタップ＝鈴、岩＝低い集積音、根と幹＝上昇する木琴、葉と花＝高い鈴の連なり、完成＝Cメジャー・ペンタトニックの和音（段階ごとに単音→3和音→分散和音→多音域）、飛行＝風切り、クライマックス＝広い和音。環境音は森の風・葉ずれ・小鳥・雲上の風・滝（距離で音量）、風は速度で音量とフィルターが変化。非表示時は suspend。
- **画質**: 起動は mid（`?q=low|mid|high` で固定）。最初の2.5秒の平均で low/high へ、その後は 50fps 未満が3秒で1段下げ、58fps 以上が10秒で1段上げ（変更後8〜15秒待機、非表示中と復帰直後は測らない）。ピクセル比 0.75/1.0/1.5、影 なし/1024/2048、Bloom なし（疑似発光の光輪のみ）/半解像度/等倍、光の筋 3/8/16、粒子 180/450/900、葉の描画量・シダの数・雲のビルボード・水と雲のシェーダーの詳細度も切り替え。
- **必須項目**: noindex、`</body>` 直前の `gf-playlog.js`、`window.__ready`（3フレーム描画後）、`window.__errors`（error / unhandledrejection / フレーム内例外）、`?autotest`（種が現れたら画面上の種の位置へ実際の PointerEvent を送る。通常と同じ判定・成功処理。直後の2度押しと、空白への外れタップも混ぜる。既定で時間2倍、`&speed=` で変更）。コンソールに `[D13] {...}` で到達段階・成功回数・クライマックス到達・平均FPS・エラー数を出す。`window.__d13()` はテスト用の読み取り。ゲーム画面に文字・数字なし。

## 確認結果（このクラウド環境）

- `python3 -m http.server`（ルート `site/`）＋ Playwright の Chromium（ヘッドレス、`--use-angle=swiftshader --enable-unsafe-swiftshader`）。結果は `logs/d13/test.txt`（tee で保存）。
- `games/d13/index.html?autotest&q=low` を最初から通しで実行（自動テストの既定の時間2倍）:
  - 1024x768（横）: `__ready`=true（約6秒）、`__errors`=[]、ゲーム由来のコンソールエラー 0。24回成功 → 第1〜4段階 → FINALE（クライマックス）→ AFTERGLOW → 雲の場面転換 → 再プレイ可能な最初の種まで到達。種が触れられる間の画面中心からのずれは最大 0.77%（画面半幅比）。成長中の島とクライマックスの島＋大樹の箱の8頂点は NDC で最大 0.811 / 0.801（＝上下左右に約10%の余白、見切れなし）。PASS。
  - 768x1024（縦）: 同上。ずれ最大 0.55%、箱の最大 0.808 / 0.801。PASS。
  - コンソールのエラーは `gf-playlog.js` がプレイログを送る `https://gf-playlog.zan72122.workers.dev/log` への通信がこの環境で遮断されたもの（`net::ERR_TUNNEL_CONNECTION_FAILED`）だけで、ゲーム本体の通信ではない。
  - 自動テストでは、種への直後の2度押し（島は1つだけ）と空白への外れタップ（何も起きない）も確認。
- mid でも自動プレイでクライマックスまで到達（撮影用の実行、エラーなし）。
- スクリーンショット（low、1024x768）: `shot-1.jpg` 序盤（巨木の森）、`shot-2.jpg` 中盤（第3段階、島の上を通過）、`shot-3.jpg` クライマックス後の天空の庭園。サムネイル `site/thumbs/d13.jpg`（640x480、mid、天空の庭園、文字なし）。
- 禁止語の grep（ゲーム本体・メモ）: 該当なし。

## 未解決の点・注意

- iPad 実機での性能（50fps 目標）・見え方・音・タッチは未確認。ヘッドレスは SwiftShader（森の中で約4fps、雲の上で10〜20fps）なので、FPS と自動画質調整のしきい値は実機では未検証。森の葉の枚数が多いので、実機で重ければ自動で low に下がる想定。
- 第3〜4段階は霧の色（指示文の値）が白に近く、遠くの浮き島や雲海がやや白っぽく見える。霧の距離は指示文の値の約1.5〜1.7倍にしている。HemisphereLight は指示値の0.78倍（白飛びを避けるため）。
- 木の成長は付け根を中心に伸ばす方式で、枝の付け根は幹が伸びきる前は幹の表面からわずかにずれることがある。
- 森の配置・経路はセッションごとに1回だけ作る（再プレイでは島・木・花・種の色が変わる）。
- クライマックスは島全体（根を含む箱）を必ず画面に収めるため、舟は画面の中で小さめになる。
- 画面回転・pointercancel は実装済みだが、実機では未確認。
