# D06 深い海で光るイルカと泳ぐ — 実装メモ

## 実装の要点

- 1ファイル `site/games/d06/index.html`（HTML＋CSS＋JS＋GLSL）。Three.js は同梱版を importmap で読む。外部画像・モデル・HDRI・音声・フォントは使っていない。扇状珊瑚の網目は Canvas、肌の細かな凹凸は DataTexture で手続き生成し、音はすべて WebAudio で合成している。
- **イルカ**: バンドウイルカの断面（背側の高さ・腹側の高さ・幅・中心高さ）を体軸方向 16 点の表で持ち、Hermite 補間した 105 断面×30 分割でロフトした連続メッシュ（短い吻、吻と額の境目、ふくらんだ額、最大胴回り、横に薄い尾柄）。背びれ（鎌形）、胸びれ、尾びれ（中央に切れ込み）は Shape を押し出して角を丸め、厚みを持たせた。目は小さな黒い球。全部を1つのジオメトリに統合し、1頭1ドローコール。
  - 色: 頂点カラーで背 `#688AA0` → 腹 `#D1DEE5`。境目は波打たせ、背中にやや濃い部分を入れた。MeshPhysicalMaterial（roughness 0.32, clearcoat 0.28, clearcoatRoughness 0.22）、法線マップ強さ 0.06。
  - 泳ぎ: 頂点シェーダーで体軸の後ろ 7 割に上下方向の波（後ろほど振幅が大きく、体の傾きに合わせて断面と法線も回す）を流す。頭はわずかに逆位相で上下する。周期は速度に応じて 1.3 秒 → 0.6 秒、胸びれは付け根を軸に上下・前後に回す。個体ごとに位相・周期・胸びれの角度を変えている。
  - 輪郭の光: Fresnel 項（power 3.0）を emissive に加算。通常 0.55 前後、操作対象は 1.25±0.35 を 1.7 秒周期で脈動（消えない）、3 秒操作がないとさらに +0.35。尾から光の粒（寿命 0.8〜1.7 秒）を出す。
  - 動き: 各個体は「目標位置＋目標速度」へ臨界減衰ばねで追従し、向きは速度方向へ補間（瞬間的に向きを変えない）。個体間は 1.75m 未満で押し離す。
- **基本ループ**: `START → WELCOME → WAIT_INPUT → GUIDING → FORM_RING → PASS_RING →（WAIT_INPUT / STAGE_TRANSITION）`、18 回目のあと `CLIMAX → AFTERGLOW → REPLAY_WAIT → DIVE → START`。
  - 群れは輪の円周上を周回し、1か所だけ空いている。離れた1頭はその輪の中心軸上・手前で、左右にゆっくり8の字を描いて泳ぐ（画面中央）。空いた区間以外の光の輪が淡く見えていて、1頭戻れば閉じることが配置から分かる。
  - 入力成立後、1.5〜1.75 秒の Hermite 曲線で空いた場所へ泳ぎ、輪が閉じる瞬間に光が一周・成功音・尾びれの大きな一打ち・外側へ広がる光の粒・海の透明度の上昇を同時に起こす。
  - 完成した光の輪はその場に残り、群れは次の輪の位置へ先に泳いでいく。カメラは輪の中心を通り抜け（通過時に左右へ流れる光の粒と音）、次の1頭は輪の自分の位置から中央へ泳ぎ出る（その抜けた場所が次の空き）。
  - 段階: 4頭（輪の直径 5.5m）→ 6頭（7.5m）→ 8頭（9.5m）。第1段階の4回目で遠方（約 78m 先）に珊瑚礁を配置し、7回目以降に見えてくる。段階が変わるとき 2頭が遠くから泳いで合流する。第2段階では成功のたびに珊瑚の発光が強まり、輪の真下から発光の波が広がり、光の粒が海底へ流れる。第3段階では輪の面が 3°→11° 上向きに傾き、気泡・上向きの粒の流れ・周回速度・金白色が少しずつ増える。水深は約 38m → 28m → 24m から上昇。
- **入力**: Pointer Events。最初のポインターだけを扱い、2本目以降は無視。Pointer Capture、`touch-action:none`、長押しメニュー・選択・ドラッグ・ダブルタップ・ピンチを抑止。当たり判定はイルカの投影長の 1.5 倍（最小半径 44px）。20px 以上の移動で、方向が目標から ±60° 以内、または対象の上から始まった・対象の上で終わったなぐり書きなら成立。対象へのタップも成立。外れた位置のタップは光の粒と澄んだ音だけで、何も失わない。1回の入力で成功は1回。触れた瞬間に指先へ光の粒、なぞると水色の光の流れ、イルカは指の方へ寄る。
  - 待ち時間の合図: 3 秒で輪郭光が強まり、6 秒でこちらへ近づいて顔を向け、胸びれを動かし、短い鳴き声（以後 7 秒ごと）。
- **カメラ**: 注視点と位置をそれぞれ臨界減衰ばねで追従、ロール 0、上向きは最大 52°。距離は画面の短辺とアスペクト比から計算（輪：短辺の約 78%、クライマックスの輪：約 83%、渦：82%）。縦 FOV は横長 48°・縦長 53〜55°。中央のイルカは短辺の約 33% になる位置に置く。
- **クライマックス**（約 20 秒）: 0〜4 秒 輪が大きく広がり全員金白色 → 4〜10 秒 軸を 40° 上向きに傾け、群れが周回しながら上昇（光の尾と気泡で渦）。カメラは渦の軸上を後ろから追い、残された大きな光の輪をくぐる → 10〜13 秒 水面へ。水面の裏側（スネルの窓・全反射）→ 気泡が通り過ぎ、水中/海上の描画設定（霧・空・環境マップ・音）をカメラ高さで連続的に切り替え → 13 秒以降 満月を画面中央へ。3頭が順に跳び、水しぶき。光の粒が海面と夜空へ広がり、Cadd9 の和音。
  - 余韻 10 秒（イルカが海面近くで泳ぎ、ときどき跳ぶ、月光の道）→ 1頭が光って待つ → 触れると潜る演出（カメラが海中へ、深い藍色にゆっくり溶けてから最初の海へ戻る。点滅なし）。
- **空・海面**: 星は方向ベクトルのセルハッシュ、薄い雲は fbm（月の周りは避ける）、月は fbm の海と小さなクレーター・周辺減光の円盤＋控えめな光輪。見かけの直径は短辺の 19%。海面は 4 方向の頂点波（波長 2.2〜7.6m、波高 0.045〜0.16m）＋画質に応じて 1〜4 本の細かな法線波（遠くでは弱める）、Fresnel 反射、月の鏡面反射（長い光の道）、水平線の霞。
- **水中**: 距離による色の吸収（Fog と背景の色を段階の色表で補間）、背景球（上ほど光が強く、月の方向に淡い光だまり）、海底の手続きコースティクス、月光の筋（加算合成の板、2/4/8 本）、浮遊物（手前の小さな粒）、光の粒（幻想、加算合成の光点）と気泡（輪郭とハイライトのある透明な球）は別のシェーダーで描き分けている。
- **音**: 水の流れ（フィルター付きノイズ）、段階ごとに音が増える持続音、なぞる音（サイン波の上昇）、合流のガラスの響き（第1段階は単音、第2段階は和音、第3段階はオクターブを加える）、輪の通過（ノイズ＋上昇音）、水面突破（しぶき＋長い和音）、短い鳴き声。マスター 0.32＋コンプレッサー、同時発音数を制限。最初の pointerdown / pointerup / touchend で AudioContext を作成・再開。失敗音・警告音はなし。
- **画質**: 初期 mid。約 2.5 秒の移動平均で 48fps 未満が 3 秒続くと1段下げ、57fps 以上が 10 秒続くと1段上げ、変更後は待機（8〜12 秒）。非表示からの復帰・リサイズ直後は判定しない。`?q=low|mid|high` で固定（自動調整停止）。
  - low: ピクセル比 1.0、ブルームなし（加算合成の光輪で補う）、光の粒 250、気泡 40、月光の筋 2、海面 64²・細かい波 1、珊瑚 35%。mid: 1.25、半解像度ブルーム、600、90、4、96²・2、65%。high: 1.75、ブルーム、1200、180、8、128²・4、100%。影は使っていない。
- **必須項目**: `<meta name="robots" content="noindex">`、`</body>` 直前に `gf-playlog.js`、`window.__ready`（3 フレーム描画後に true）、`window.__errors`（error / unhandledrejection / フレーム内例外 / 初期化エラー）、`?autotest`（受け付け状態になると、通常と同じ `onDown/onMove/onUp` に合成座標を渡す。なぞる・タップ・外れタップ→なぞるを順に繰り返し、余韻のあとのイルカにも触れて再プレイの開始まで進む。時間倍率 2 倍、`&speed=1` で等倍）。ゲーム画面に文字・数字なし（読み込み中は中央の小さな光の輪だけ）。
- 再プレイしてもイルカ・光の輪・粒子・音源・リスナーは作り直さず再利用している。
- テスト用の読み取り専用フック `window.__d06`（状態、投影座標の取得）。

## 確認結果（このクラウド環境）

- `python3 -m http.server`（ルート `site/`）＋ Playwright の Chromium（ヘッドレス、`--use-angle=swiftshader --enable-unsafe-swiftshader`）。結果は `logs/d06/test.txt`（tee で保存）。
- `games/d06/index.html?autotest&q=low` を最初から通しで実行（途中を飛ばす仕組みは使っていない）。
  - 1024x768（横）: `__ready`=true（約 3.8 秒）、`__errors`=[]、コンソールエラーなし。18 回 → 3 段階（STAGE_TRANSITION を 2 回）→ CLIMAX → AFTERGLOW → REPLAY_WAIT → DIVE → 再び START まで到達。PASS（約 127 秒、2 倍速）。
  - 768x1024（縦）: 同上。PASS（約 126 秒）。
- 構図の確認（約 250ms ごとに投影座標を取得）:
  - 操作待ちのイルカの画面中央からのずれ: 最大 3.5%（横）/ 4.7%（縦）。余韻のあとに光って待つイルカは最大 5.1%（横）/ 3.2%（縦）。
  - 完成した光の輪は全サンプルで画面内（21/21、24/24）。群れ全員の吻と尾は、待ち・輪の完成・渦の上昇中の全サンプルで画面内（33/33、34/34）。
  - クライマックスの満月の中央からのずれ: 最大 1.7%（横）/ 2.0%（縦）。
- 追加確認（同じ test.txt の末尾）: Playwright の実際のタッチ（タップ）とマウス（なぞり）で、`?q=high` 1024x768、`?q=mid` 390x844、`?q=mid` 834x1194 の開始〜1回目の誘導が成立し、エラーなし。390x844 でも輪は画面内。
- 外部への通信は共通スクリプト `gf-playlog.js` の送信のみ（テストでは 204 を返すように差し替え）。ゲーム本体は外部へ通信しない。
- スクリーンショット: `shot-1.jpg`（序盤・2 回目の輪の完成）、`shot-2.jpg`（中盤・第2段階の珊瑚礁）、`shot-3.jpg`（クライマックス・満月と光の解放）。いずれも low 画質。サムネイル `site/thumbs/d06.jpg`（640x480、mid 画質＝ブルームありのクライマックス画面、文字なし）。
- 禁止語の grep（ゲーム本体・メモ）: 該当なし。

## 未解決の点・注意

- iPad 実機での性能（50fps 目標）と見え方は未確認。ヘッドレスは SwiftShader（CPU 描画）なので FPS は参考にならない。自動画質調整のしきい値も実機では未検証。
- 第3段階の海の色は、指示文の `#247EB0` / `#63B8DB` のままだと昼の海のように白っぽくなり夜の感じが消えたため、`#1C679B` / `#2E7DAE` に少し深くした。環境光・輪郭光（金白色 `#FFF6DD` へ移行）は指示文どおり。
- three.js の Fog はトーンマッピング後の出力色空間で混ぜられるため、背景球の水平線付近だけ同じ方法で霧の色へ寄せて境目を消している。
- ブルームの strength は段階で 0.35→0.50→0.65（指示文どおり）、radius 0.42。threshold は指示文の 0.8〜1.1 では画面全体が白く霞み、満月も白飛びしたため 1.25 にした（ブルームありのときは月の輝度も下げている）。mid/high の見え方はヘッドレスで数枚確認しただけ。
- 珊瑚・岩は手続き生成で、近くで見ると簡素。イルカの表情や目は控えめ（擬人化しない方針）。
- 輪の下側で周回するイルカは背中を外側に向けるため、上下が逆さに見える個体がいる（群れが輪を作る見た目を優先）。
- 余韻のあとに待つイルカの中央からのずれは横画面で最大 5.1% と、目安の ±5% をわずかに超えた（海面近くを左右に泳ぐのをカメラが追う遅れ）。
- 音はヘッドレスでは鳴らせない（自動再生の制限）ため、耳での確認はしていない。
