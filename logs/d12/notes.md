# D12 北斗の花びらが降る小道 — 実装メモ

## 実装の要点

- 1ファイル `site/games/d12/index.html`（HTML＋CSS＋JS＋GLSL）。Three.js は同梱版を importmap で読む。外部画像・モデル・音声・フォントは使っていない。地形・桜・シカ・道・星・雲・水・音はすべてコード内で生成。
- **道のりは1本の曲線**（CatmullRomCurve3, centripetal）。森の小道（地面）→ 樹冠の高さ（約 9m）→ 雲の上（雲の層 y=18.5、道の終わり y≈31）→ 北斗七星（7つの星の位置そのものが曲線の制御点）。0.1m 間隔で弧長を再標本化し、25回分の区間端（6＋6＋6＋7）を決めている。
- **花びらの道**: 曲線に沿った断面（上面は丸み、側面と底面あり）を全長ぶん一度に作り、シェーダーの `uBuilt`（弧長）で見える範囲をのばす。先端は花びらが積もるように低い位置から盛り上がる。上面はセル単位で重なり合う切れ込み付き花びら模様（重なり順・縁の陰・ねじれた法線）。花びらの隙間と縁から桜色〜金色の光がにじむ。地上は厚さ 0.1m、空では 0.42m。段階に応じて桜色 → 藤色＋銀 → 金色に変わる。縁には流れるように明滅する光の粒（Points）。
- **1回の成功**（状態: `WAITING_FOR_TAP → COLLECTING_PETALS → BUILDING_PATH → RUNNING`）: タップと同じフレームで渦が縮み澄んだ音・光の輪 → 0.1〜0.8 秒 渦の花びら＋追加の花びらがシカの周りを立体的に旋回（手前・奥を回る）→ 0.8〜1.9 秒 道の新しい区間へ弧を描いて流れ、着地に合わせて道の先端がのびる → 1.8〜2.5 秒 道の上を光が走る。星が灯る回は道の先から光の粒が星へ飛び、星が輝く → 2.5 秒〜 シカが新しい道を駆ける → 到着後、次の渦が上空（星の方向）から舞い降りる。
- 星の点灯: 3・6 回目（第1段階）、9・12 回目（第2段階）、14・16・18 回目（第3段階）で7つすべて点灯。第4段階は渦をタップするごとに次の星まで道ができ、到着した星は金色に輝き、花びらの花冠が広がる（訪問済みは維持）。
- 6 回目の後は小道の終わりから花びらが空へ舞い上がり、道が持ち上がる。12 回目は樹冠の上に広い範囲の花吹雪。
- **北斗七星**: 地上では正面上方の約 300m 先に、ひしゃくの形のまま大きく見える（開始時のカメラから配置）。第3段階の進行に合わせて、道の先の実際の位置（ひしゃくの柄から入って器を回る配置、間隔 6〜10m、緩い上り）へ少しずつ近づく。星は芯＋細い光条＋淡い光の暈のスプライトで、円形のボタンには見せない。
- **クライマックス**（`CLIMAX` 約 10 秒 → `AFTERGLOW` 約 6.5 秒 → `FREE_PLAY`）: 七つ星をつなぐ道全体に光が走る → 星が順に光の輪を放ち花びらを放出 → 桜色・銀・金の花吹雪がシカを包み、七つ星の周りにも大きな花びらが舞う → 空・霧・雲・水が星の光で明るさを増す（白一色や点滅はしない）→ 七つ星の音を重ねた和音と長い余韻。カメラは時間をかけて引き、七つ星の中心を画面中央に置き、星とシカを四辺 8% 以上の余白に収める。余韻のあと、シカの前に再び渦が現れ、触れるたびに花吹雪・和音・星の輝きが起こるフリープレイ。
- **シカ**: 胴・首・頭を断面を補間したロフト形状で作り（球をつないだだけにしない）、脚は肩／股〜肘・膝〜管骨〜蹄の関節連鎖。毛色 `#F3F0E7` 系、MeshPhysicalMaterial の sheen で月光の当たる部分を銀白色に、毛流れの法線マップ、鼻・目・耳の内側・蹄の色は指示どおり。待機中は呼吸・耳の動き・瞬き・首の小さな動き。走行はトロット〜ギャロップを速度で混ぜ、脚の振り幅と速度から歩調を決めて足の滑りを抑える。足音は接地の瞬間（地上は土、空は花びらの音＋小さな鈴）。
- **森**: 桜は幹→太枝→細枝の分岐を手続き生成（樹皮テクスチャに横縞の皮目・節）、枝先に花の房のカード（5弁・切れ込みのある花をキャンバスで描いた透過テクスチャ）。3種類を InstancedMesh で配置し、画質で本数を変える。若草（風で揺れる）、小石、地面に積もった花びら、月を映す池と水たまり（複数の波・フレネル・月の反射・浅瀬と深部の色）、遠景の森と雲。
- **空**: 天頂と地平線の色（段階で補間）、2層の星、淡い天の川のもや、月（円盤＋暈）。雲は薄い層（下から見ると薄く、上に出ると道の下に広がる）と遠景の雲。
- **カメラ**: シカの斜め後ろ（左右に 9° ずらす）。注視点＝現在の渦で、渦は常に画面中央。シカの全身（頭・耳・脚・尾を含む箱）と渦（と第4段階では次の星）を投影し、四辺 11% の余白に収まる最小距離を毎フレーム二分探索。縦向きは縦 FOV を広げたうえで同じ処理で引く。位置は減衰付き追従、回転は yaw/pitch のみ（ロールなし）で通常 15°/秒以内（大きくずれたときのみ 26°/秒）。シカの上下動はカメラに伝えない。
- **入力**: Pointer Events（タッチ・マウス共通）。最初の指だけを処理、`pointercancel`/`lostpointercapture`/blur で解除。判定は画面上の距離（渦の見た目の半径の 1.6 倍、または画面短辺の 13%、最低 50px＝直径 100px 以上）＋ Raycaster（半径 1.15m の球）。外れたタップは小さな光の粒が出るだけ。`touch-action:none`、ピンチ／ダブルタップ／長押しメニュー／選択／スクロールを抑止。
- **音**（WebAudio のみ）: 最初のタップ（pointerdown／touchend／click）で AudioContext を生成・resume。コンプレッサー＋生成した残響。風・葉・水（フィルターしたノイズ、ランダムに変わる音量）、水滴、段階で厚くなる持続音。成功音は C メジャー・ペンタトニック（第1段階 単音＋倍音、第2段階 2〜3音の上昇アルペジオ、第3段階 3〜4音の和音、第4段階 星ごとに違う音程と豊かな倍音、クライマックス 7音の和音と長い余韻）。同時発音数を制限、タブ非表示で停止。
- **画質**: `low / mid / high`（ピクセル比 1.0/1.25/1.75、影 なし（接地影）/1024/2048、ブルーム なし（発光表現）/半解像度/有効、漂う花びら 150/350/700、クライマックス上限 350/800/1600、木の本数 少/中/多、水面の波数）。初期は mid。0.5 秒ごとの FPS の直近 3 秒平均が 50 未満なら 1 段下げ、57 以上が 15 秒続けば 1 段上げ（変更後は待機期間）。`?q=low|mid|high` で固定。
- **必須項目**: `<meta name="robots" content="noindex">`、`</body>` 直前に `gf-playlog.js`、`window.__ready`（3 フレーム描画後に true）、`window.__errors`（error／リソース失敗／unhandledrejection／フレーム内の例外）、`?autotest`（通常の pointerdown ハンドラーに合成イベントを渡して 25 回 → クライマックス → フリープレイ 3 回まで。途中に外れタップ、2本指の同時タップ、3連打、6.5 秒の放置（光の波紋と花びらの集まり）を含む。時間倍率は既定 3 倍、`&speed=1` で等倍）。`?seed=` で乱数シード固定（既定値あり）。ゲーム画面に文字・数字なし（読み込み中は桜色の光の粒だけ）。
- テスト用の読み取り専用フック `window.__d12`（状態、成功回数、点灯・訪問した星、渦・シカ・星の画面座標など）。`?dbg` のときだけ内部オブジェクトを `window.__dbg` に出す。

## 確認結果（このクラウド環境）

- `python3 -m http.server`（ルート `site/`）＋ Playwright の Chromium（ヘッドレス、`--use-angle=swiftshader --enable-unsafe-swiftshader`）。スクリプトは `logs/d12/autotest.js`、結果は `logs/d12/test.txt`（tee で保存）。
- `games/d12/index.html?autotest&q=low` を 1024x768（横、途中で 768x1024 に回転して戻す）と 768x1024（縦）で最初から通しで実行。結果は下記（詳細は test.txt）。
- プレイログの送信先（外部）はこの環境から接続できないため、テストではその通信だけ Playwright で 204 を返している（ゲーム本体からの外部通信はない）。
- スクリーンショット（low 画質、横）: `shot-1.jpg` 序盤（森の小道・渦・シカ）、`shot-2.jpg` 中盤（雲の上へ続く道）、`shot-3.jpg` クライマックス（七つ星と花吹雪）。サムネイル `site/thumbs/d12.jpg`（640x480、文字なし）。
- 禁止語の grep（ゲーム本体・ログ）: 該当なし。

- 最終テスト結果（test.txt）:
  - 1024x768（横、9 回目の走行中に 768x1024 へ回転し 10 回目で戻す）: `__ready`=true（約 3 秒）、`__errors`=[]、コンソールエラー 0、25 回成功 → 7 つの星すべて点灯・訪問 → CLIMAX → AFTERGLOW → FREE_PLAY（フリープレイ 3 回）まで到達。RESULT: PASS。回転後も進行は保持。
  - 768x1024（縦）: 同じく `__ready`=true、`__errors`=[]、コンソールエラー 0、全段階・クライマックス・フリープレイ到達。RESULT: PASS。
  - 待機中の渦の位置は横・縦とも画面の 50%,50%（中央から 6% 以上ずれたサンプル 0/58・0/59）。クライマックス〜余韻では七つ星の中心が 50%,50%、七つ星とシカが四辺 8% の余白の外に出たサンプル 0。
  - 自動テスト中の外れタップ・2本指同時タップ・3連打で成功が重複しないこと（25 回目で止まり、taps=31）を確認。
  - サムネイルは mid 画質（ブルームあり）の開始画面（月・七つ星・桜の小道・シカ・光る花びらの渦）。mid 画質でも `__errors` 空を確認。

## 未解決の点・注意

- iPad 実機での性能（50fps 目標）・見え方・音・タッチの感触は未確認。ヘッドレスは SwiftShader（CPU 描画）で 2〜10fps 程度しか出ないため、FPS と自動画質調整のしきい値は実機で未検証（low でも花のカードの重なりが最も重い）。
- high の水面は簡易反射ではなく、全画質で天空色と月の反射の近似（波の数だけ画質で変える）。
- シカは形・関節・歩様を手続き的に作ったが、胴体はやや単純な筒形で、近くで見ると毛並みの表現は法線マップの範囲にとどまる。
- 北斗七星は第4段階で歩けるよう横に寝かせた配置にしているため、クライマックスでは真上からではなく斜め横から見たひしゃく形になる。七つ星全体を収めるためカメラが遠く（約 55m）なり、シカと花吹雪は小さく見える。
- 自動テストの「シカの外接箱が画面外」判定で、走り出しの一瞬とクライマックス→フリープレイへのカメラ移動中に、全サンプルの 1〜2% 程度でわずかに外へ出る瞬間がある（待機中・クライマックス中は 0）。
- PC のマウス操作・実機のタッチは、ヘッドレスでの合成ポインターイベントによる確認のみ。
