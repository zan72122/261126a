# D07 夕焼けの町に灯りをともすクジラ — 実装メモ

## 実装の要点

- 1ファイル `site/games/d07/index.html`（HTML＋CSS＋JS＋GLSL）。Three.js は同梱版を importmap で読む。外部画像・モデル・音声・フォント・CDN は使っていない。テクスチャ（漆喰・瓦・石・木・敷石・日よけ・クジラの肌の法線と粗さ）は Canvas / DataTexture で手続き生成、音はすべて WebAudio で合成。
- **ザトウクジラ**（体長 13m）: 体軸方向 15 点の断面表（幅・背側の高さ・腹側の高さ・中心高さ）を Catmull-Rom で補間し、超楕円の断面をつないだ連続メッシュ（尾柄は縦に薄いキール形、頭部は上面が平ら）。頭部の小隆起（上あご・下あごの約 40 個の小さな半球）、目（まぶたの膨らみ付き、小さく控えめ）、噴気孔、口の線、背びれのこぶ、長い胸ビレ（翼断面のロフト、前縁に 11 個の起伏）、中央に切れ込みと後縁のぎざぎざがある尾ビレ。喉から腹の縦溝は、頂点の円周角を使ったフラグメントシェーダーの法線ゆらぎと色の濃淡で表現。
  - 色: 頂点カラーで背 `#354B5A` → 側面 `#647C8A` → 腹 `#CBD5D6`（境界をノイズで波打たせ、色むらと斑を追加）。胸ビレは白く付け根の上面だけ灰色、尾ビレの裏は白地に黒の模様。MeshPhysicalMaterial（metalness 0、roughness 0.38×粗さマップ、clearcoat 0.55、clearcoatRoughness 0.18、法線マップ 0.16）＋空のプロシージャル環境マップ（PMREM）。
  - 変形は頂点シェーダー: 体の反り（uArch）、尾から胴へ伝わる上下の波、頭の小さな逆位相、左右の曲がり。胸ビレは付け根を軸に独立して回転（広げる・羽ばたく）。水中にある部分は深さに応じて海の色に溶ける。
- **海**: 中心が細かく外側が粗い格子（low 64² / mid 96² / high 160²）に Gerstner 波を 3〜5 本（波長 3.8〜18m、波高 0.07〜0.30m）、残りの短い波（1.4〜2.3m）と 2 層のノイズは法線のみ。Fresnel で空の反射と水の色を混ぜ、反射は空と同じ関数（太陽・月・雲・星を含む）を反射ベクトルで評価するので、夕焼け・月・星が波で砕けて映る。太陽と月の鏡面光の道、クジラの周りの青緑、着水波紋（4 枠を別管理、変位＋泡＋岸向きの縁だけ金色）、海面の盛り上がり（ブリーチ直前）。点灯済み区画の灯りは反射レイと各区画の壁面平面の交点で計算し、縦に揺れる光の筋として海面に映る（点灯数に比例して増える）。円の周辺だけ半透明にして、水面下のクジラと魚が見える（海中にカメラは入れない）。
- **港町**: 10 列×前後 2 段＝20 区画、建物 40〜60 棟（白壁・淡い色の壁、切妻・寄棟・陸屋根、煙突、商店の日よけ）。窓は「枠＋奥行きのある開口＋窓台＋ガラス」をインスタンス描画し、鎧戸・バルコニー付きもある。灯りはガラスと街灯のシェーダーで区画ごとの経過時間から点灯（桟橋の灯り→街灯→窓の順に約 1.5 秒）、窓 `#FFD38A`・街灯 `#FFE5B5`、PointLight は使わず、壁の下部に疑似的な照り返し、街灯には光のにじみ（加算の点）。石の護岸、敷石の段丘、木の桟橋、ヤシ。背後はノイズ地形の丘と遠くのなだらかな火山（霧で大気遠近）。
- **空**: 球面のシェーダー（地平線→天頂のグラデーション、太陽の光輪と円盤、fbm の雲を太陽方向へずらしたサンプルで受光面と陰を作る、月の円盤と模様、ハッシュの星）＋瞬く星の Points（low 250 / mid 400 / high 650、色 `#FFF4D0` / `#BDE7FF`）。
- **4 段階の色**: 指示文の表の色（空の上部・地平線・雲・海・主光源）と強さ（環境光・太陽・月）を 1 秒あたり 1/8 段で補間（約 8 秒）。霧の色＝地平線の色。太陽は高度 7°→2.6°→-2.6°→-9° と沈み、月は -30° 方位で昇る。
- **ゲームの流れ**: `WAIT → CHARGING → BREACH → SPLASH → WAVE → LIGHT_UP → WAIT`、20 区画のあと `FINALE`（町全体が一度だけ順番に輝く）→ `FINAL_WAIT → FINAL_CHARGING → STAR_SWIM → AFTERGLOW → RESET`。点灯は着水の波の前縁が対象区画の護岸に届いた時点で 1 回だけ（`secStart` で二重点灯を防止）。
  - 長押し: 円が脈打ち・触れた所から波紋、クジラが頭を下げて潜り尾ビレが水上へ（水滴が落ちる）、気泡、円の外の光が中央へ集まる（約 1.25 秒）。押し続けても待つだけ。短いタップでも、潜りきっていない分を最大 0.9 秒の潜水で補ってから跳ぶ。
  - 離す: 円が収束 → 海面の盛り上がり → 0.5 秒で頭が水面を割る（大量の水滴と霧）→ 胸ビレを広げ背を反らせて最高点（頭の高さ 約 8〜11m）→ ひねって背中・横向きに着水（3.3 秒）→ 王冠状の水しぶきと波紋 → 金色の縁の波が岸へ（秒速 19m）→ 区画が点灯。ジャンプごとに高さ・ひねり・向き・胸ビレ角度を変える。第 2 段階は速度 1.1 倍・水滴 1.2 倍、第 3 段階から水滴の一部が星の光に、波紋の発光幅も段階で広がる。円の中央付近を押すと水滴 1.5 倍・金色が強いブリーチ。
  - 待機の誘導（文字・矢印なし）: 3 秒で円がゆっくり脈打つ、6 秒で円の周りに光の粒が集まる、9 秒でクジラが円へ近づき背中を出す、12 秒以降はこれを繰り返す。自動でジャンプはしない。
  - クライマックス: 直径 1.4 倍の円（金色＋青白い星の粒）。長押しでクジラが深く潜り、海面の光と星の粒が集まる。離すと最大の水しぶきで飛び出し、落ちずに尾ビレで漕ぎながら高度 約 27m まで星空へ泳ぎ上がる。尾・胸ビレから長く残る星の光の軌跡、体の周りに金色と青白い光、町の灯りと海面の反射が強まる。約 14 秒 → 余韻 12 秒（音を静かに）→ クジラが海へ戻り、空が夕日へ戻り、灯りが消えて最初の円が出る。
- **カメラ**: 真横に近い固定方向（ヨー -3°、ロールなし、揺れなし）。注視点・距離・ピッチを臨界減衰ばねで追従（約 0.6〜1.2 秒）。距離は毎回「含めたい点（円の縁、クジラの遊泳範囲、ブリーチ中の全身の姿勢、着水点と点灯区画の四隅）」を現在の画角・縦横比で投影して必要距離を求め、余白 11%。ブリーチと星空遊泳は事前に数姿勢をサンプルして距離を決めておき、跳んでから慌てて引かない（クライマックスは FINAL_WAIT の時点で引いておく）。縦画面は FOV 50〜52°、横は 46°。
- **入力**: Pointer Events、最初の指だけ有効、Pointer Capture、pointercancel／タブ切り替えで安全に待機へ戻す。当たり判定は見た目の 1.6 倍（画面上の半径 60px 以上）。円の外を触ると小さな光の粒と澄んだ音だけ。`touch-action:none` などでズーム・スクロール・長押しメニュー・選択を抑止。
- **音**: 海のノイズ（ゆっくりうねる）、段階で音が増える持続音、触れた時のベル、潜水の気泡と上昇音、ブリーチ（ノイズ＋低音）、空中のきらめき、着水、岸へ移る波の音（定位が動く）、点灯に合わせたベルと段階ごとの成功音（単音→2 音→3 音→高音を加えた和音、ペンタトニック）、クライマックスの低音から高音への積み上げ。Master 0.32＋コンプレッサー、同時発音数制限。最初の pointerdown / pointerup / touchend で AudioContext を作成・再開（ヘッドレスでは無音のまま進む）。
- **画質**: 初期 mid。0.5 秒ごとに FPS を計測し約 4 秒の平均、50 未満が 4 秒続けば 1 段下げ、58 超が 10 秒続けば上げる（変更後 8〜20 秒待機、待機・点灯・余韻の状態でのみ切り替え）。`?q=low|mid|high` で固定。
  - low: ピクセル比 1.0、影なし、ブルームなし（街灯の光のにじみで代替）、水滴 250、星 250、海 64²・頂点波 3。mid: 1.25、影 1024、半解像度ブルーム、600、400、96²・4。high: 1.75、影 2048、ブルーム、1200、650、160²・5、MSAA。低画質でもクジラ・点灯・空の変化・クライマックスは同じ。
- **必須項目**: `<meta name="robots" content="noindex">`、`</body>` 直前の `gf-playlog.js`、`window.__ready`（3 フレーム描画後に true）、`window.__errors`（error / unhandledrejection / フレーム内例外 / 初期化エラーを記録）、`?autotest`（通常と同じ onDown/onUp に円の画面座標を渡す。中央長押し・短いタップ・中心から外れた位置・外れタップのあと長押し、を繰り返し、最後の長押し→クライマックス→余韻→再プレイ待ちまで。時間倍率 2.5、`&speed=` で変更可）。ゲーム画面に文字・数字なし（読み込み中は中央の小さな光の輪だけ）。
- テスト用の読み取り専用フック `window.__d07.info()`。`?autotest&lit=N` は開発用（N 区画点灯済みから始める）で、サムネイル撮影にだけ使った。

## 確認結果（このクラウド環境）

- `python3 -m http.server`（ルート `site/`）＋ Playwright の Chromium（ヘッドレス、`--use-angle=swiftshader --enable-unsafe-swiftshader`）。結果は `logs/d07/test.txt`。
- `games/d07/index.html?autotest&q=low` を最初から通しで実行（途中を飛ばしていない、時間倍率 2.5）。
  - 1024x768（横）: `__ready`=true（約 4.1 秒）、`__errors`=[]、コンソールエラーなし。20 区画すべて点灯 → 4 段階 → FINALE → FINAL_WAIT → STAR_SWIM → AFTERGLOW → RESET → 再び最初の円（再プレイ可能）まで到達。PASS。
  - 768x1024（縦）: 同上。PASS（`__ready` 約 4.2 秒）。
- 構図（約 250ms ごとに投影座標を取得）:
  - 待機中の光の円の画面中央からのずれ: 最大 3.6%（横）/ 2.8%（縦）、クライマックスの円 4.4% / 3.5%。
  - 空中のクジラ（吻・背・腹・尾ビレ両端・胸ビレ両先端など 10 点）が画面内に収まったサンプル: 188/188（横）、193/193（縦）。
  - 星空遊泳中のクジラ中心のずれ: 最大 5.3%（横）/ 4.7%（縦）。
- 最初の通し実行のあと、ブルームと光の量（クライマックスの白いかすみ対策）だけを調整し、同じ条件で両方向を実行し直した。test.txt は最終実行の出力（tee ではなくリダイレクトで保存）。
- スクリーンショット（low 画質、最終実行のもの）: `shot-1.jpg`（序盤・2 回目のブリーチ、夕日）、`shot-2.jpg`（中盤・薄暮で区画が点灯）、`shot-3.jpg`（クライマックス・星空を泳ぐクジラ）。

## 未解決の点・注意

- iPad 実機・iPhone 実機での性能（50fps 目標）と見え方は未確認。ヘッドレスは SwiftShader（CPU 描画、約 4fps）なので FPS は参考にならず、自動画質調整のしきい値も実機では未検証。確認した画面サイズは 1024x768 と 768x1024 の通し実行と、640x480（mid）のみ。390x844・844x390・834x1194・1194x834・1440x900 は未確認。
- 音はヘッドレスでは鳴らせない（自動再生の制限）ため、耳での確認はしていない。
- ブルームのクライマックス値: 指示文の強さ 0.8〜1.1 では mid で画面全体が白くかすんだため、「画面全体を白くしない」を優先して強さ 0.42・しきい値を高めにした（輝きは窓・星の粒・クジラの縁で出している）。
- 夜の段階では、窓の灯りが水面に映る筋に加えて、着水波の金色の帯がやや面として見える角度がある。
- 丘の木は簡素な形（霧で遠景として見せている）。小舟は画面左下に置き、カメラの移動に合わせてゆっくり漂って追従する。ウミガメは入れていない（魚の群れのみ）。
- 背の高い前列の建物で後列の下部が少し隠れることがある。
