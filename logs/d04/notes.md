# D04 水面の上と下の日の出イルカ — 実装メモ

## 実装の要点

- 1ファイル `site/games/d04/index.html`（HTML＋CSS＋JS＋GLSL）。Three.js は同梱版を importmap で読む。外部画像・モデル・HDRI・音声・フォントなし。砂紋・扇状珊瑚の網目・光の玉はすべて Canvas で生成、音はすべて WebAudio で合成。
- **水面の上下を同時に描く方法**: 同じシーンを2台のカメラで、画面の上半分（空気）と下半分（水中）に Scissor で分けて描画。上のカメラは水面上 0.8m、下のカメラは水面下 0.35m。投影行列の縦方向シフトを `s = h·f / D`（D＝カメラからイルカまでの距離）にとることで、イルカのいる奥行きでは上下の投影が一致し、水面 y=0 が常に画面中央の水平線になる（境界を通過するイルカがずれたり二重になったりしない）。上半分の中央〜水平線の帯には遠くの海面（空の反射・太陽の金色の帯・波紋）、下半分の上端には水面の裏側（全反射のきらめき）が見える。中央には波で 1% ほど揺れる水際の線（膜・ハイライト）を重ねる。
- 空: 空専用シェーダー（天頂/水平線のグラデーション、水平線の帯、太陽の光輪、筋状の雲と遠くの積雲、星、クライマックスの光条）。太陽は見かけの半径 1.6°、水平線より下は隠れる。高度は −2.4°→（6回）−1.3°→（12回）−0.3°→（18回）+0.8°→（23回）+1.45°→ 最終ジャンプで +5.2°。最後のジャンプまで太陽の下端は水平線の下にある。
- 海面: Gerstner 風に4つの正弦波（波高 0.1〜0.25m）＋細かい法線用の4波、フレネル反射（空シェーダーと同じ関数で反射色）、太陽の鏡面反射、波紋（8個まで、ジャンプ・着水・水滴で発生）。
- 色: 指示文の4段階 HEX（天頂・水平線・海面・海中・主光源）を成功回数/8 で連続補間。光源強度・霧（空気 50→80 / 250→350m、海中 8→12 / 50→75m）も補間。
- イルカ: 断面（高さ・幅・中心）を Catmull-Rom で補間してつないだ独自 BufferGeometry（吻部・額のふくらみ・最大胴回り・横に薄い尾柄）＋押し出しの背びれ・胸びれ・尾びれ＋目。背 #648BA3 / 側面 #91AAB5 / 腹 #D8E2E5 の頂点カラー。MeshPhysicalMaterial（roughness 0.3, clearcoat 0.62）、反射は空から作った PMREM（ジャンプごとに更新）をイルカにだけ使う。頂点シェーダーで尾びれを上下に波打たせ、空中では弧を描くように曲げる。
- 海底: 周期 180m のノイズ地形タイル3枚を前方へ再利用（継ぎ目なし）。珊瑚は枝状・扇状（網目の alphaMap）・半球状・卓状の4種＋岩を InstancedMesh で配置、タイル再利用時に並べ直す。コースティクスは手続きシェーダーを MeshStandardMaterial に注入。
- 魚: 3種（黄色の帯模様・青・橙）を InstancedMesh、頂点シェーダーで尾を振る。群れは中央のレーンを避けて配置。第3段階から遠くに仲間のイルカ2頭（ときどき跳ぶ）。
- 光の筋: 水面から海底までの加算合成の帯（水面より上にも淡く伸びる）＋中を流れる金色の粒子。最後の光は 1.5 倍の太さで金色。待機中は脈動、2秒操作がなければ 1.5 秒周期の脈動、さらに4秒で粒子がイルカの周りに集まり誘導音。
- 状態: READY → (タップ) ACCELERATING → LEAPING → LANDING → SUNRISE → SWIMMING → TOUCH_WINDOW → … 24回目は FINALE → AFTERGLOW（約10秒）→ FREE_PLAY（太陽は朝の位置のまま、何度でも跳べる）。経過時間ベース、タブ非表示で一時停止。
- タイミング: 泳いでいる途中のタップは予約され、光に重なった瞬間に跳ぶ。遅れても光のそばで泳いで待つ。連打は1回分しか数えない。失敗・減点・時間切れなし。タップ直後に光の収縮・閃光・音（同じフレーム内）。
- ジャンプ: 段階ごとに速度 3.5/4.5/5.5/6.5 m/s、最高点 1.2/1.6/2.0/2.5m、最終 3.0m。光のそばでは斜めを向いて待ち、跳ぶときは画面中央を斜めに横切る（真後ろからの単調な見え方を避けつつ、左右の移動量は待機位置の左右反転までに制限）。水面突破で水滴・霧・波紋・飛沫音、頂点で和音と太陽の上昇・色の変化、着水で波紋・泡・着水音。
- クライマックス: 金色の粒子が集まる → 長い加速 → 3m の跳躍、頂点付近で約0.5秒スローモーション → 太陽が水平線から完全に現れる → 空（光条）→ 海面 → 珊瑚礁の順に金色の光が広がる（各 1.5〜2 秒）→ 海中に6本の大きな光の柱 → 着水で金色の波紋。白いフラッシュや画面の揺れはなし。
- カメラ: ロール・ピッチ 0。太陽と光の筋は常に画面中央の縦軸（x=0）。カメラ距離は「次のジャンプの高さ・潜る深さ・左右の幅」から画面端 10% の余白が残る距離を求め、ジャンプの前から減衰補間で移す（最終ジャンプも同様）。縦 FOV は横長 45° / 縦長 50° / 細長い画面 55°。
- 音: 波・水中のざわめき・持続音（段階ごとに音が増える）、光の出現のベル、タップの澄んだ音＋上昇音、加速の水流音、突破の飛沫音、頂点の和音（C5+G5 → C-E-G → A5 を加えたアルペジオ → 複数オクターブ）、太陽の上昇アルペジオ、着水と泡、クライマックスの低音から高音へ広がる約4秒の和音。マスター 0.3＋コンプレッサー、同時発音数を制限。最初のタップ（pointerdown / pointerup / touchend）で AudioContext を作成・再開。
- 画質: 初期 mid。直近3秒の平均 FPS < 48 で1段下げ、10秒の平均 ≥ 57 で1段上げ、変更後 10 秒は待機、ジャンプ中は大きな低下（< 30fps）以外は変更しない。`?q=low|mid|high` で固定。low: PixelRatio 1.0・水面 32²・水滴 80・魚 24・珊瑚 35%・ブルームなし（加算合成で代替）、mid: 1.25・64²・160・50・60%・半解像度ブルーム、high: 1.75・96²・350・100・100%・ブルーム。
- 必須項目: `<meta name="robots" content="noindex">`、`</body>` 直前の `gf-playlog.js`、`window.__ready` / `window.__errors`（error と unhandledrejection、フレーム内例外も記録）、`?autotest`（受付状態になったら通常タップと同じ `handleTap()` を投影座標で呼ぶ。3回に1回は泳いでいる途中にタップして予約の経路も通す。時間倍率 2 倍、`&speed=1` で等倍）。
- 入力: Pointer Events の `isPrimary` のみ処理（2本目以降の指は無視）、touch-action/overscroll/user-select/長押しメニュー/ダブルタップズーム/ピンチを抑止。visualViewport の変化・回転で再計算（状態は保持）。
- 開発用: `?skip=N`（N 回跳んだ状態から始める。確認用で、autotest の判定には使っていない）。`window.__d04`（状態と投影座標の取得のみ）。

## 確認結果（このクラウド環境）

- `python3 -m http.server`（ルート `site/`）＋ Playwright の Chromium（ヘッドレス、`--use-angle=swiftshader --enable-unsafe-swiftshader`）。結果は `logs/d04/test.txt`。
- `games/d04/index.html?autotest&q=low` を最初から通しで実行（skip なし）。
  - 1024x768（横）: `__ready`=true（約2.8秒）、`__errors`=[]、コンソールエラーなし、24回 → FINALE → AFTERGLOW → FREE_PLAY（自由ジャンプ2回）まで到達。PASS（約342秒）。
  - 768x1024（縦）: 同上。PASS（約295秒）。
- 見切れ確認（約150ms ごとにイルカの中心・吻端・尾の投影座標を取得）: 画面外に出たサンプル 0（横 1262 / 縦 1256 サンプル）。光の筋・太陽の横方向のずれ 0%（常に中央）。イルカ中心の横方向のずれは最大 15.7%（横）/ 18.4%（縦）。
- 外部への通信は共通スクリプト `gf-playlog.js` の送信のみ（テストでは 204 を返すように差し替え。ゲーム本体は外部へ通信しない）。
- 補足確認: `?q=mid`（ブルームあり）でクライマックス付近、`?q=high` で 1024x768、834x1194、390x844 の開始画面を表示し、エラーなし。
- スクリーンショット: `shot-1.jpg`（序盤・2回目のジャンプ）、`shot-2.jpg`（中盤・13回目、桃色の海）、`shot-3.jpg`（クライマックス・太陽が水平線から現れる）。サムネイル `site/thumbs/d04.jpg`（640x480、クライマックスの画面）。

## 未解決の点・注意

- iPad 実機での性能（50fps 目標）は未検証。ヘッドレスは SwiftShader（CPU 描画）なので FPS は参考にならない。mid/high（ブルーム）は実機で見え方の確認が必要。
- ブルームの閾値は指示文の 0.85 ではなく 3.0 にした（トーンマッピング前の線形 HDR 値に対して効くため、0.85 だと空全体が光って画面が白く霞んだ）。強さ・半径は指示文の範囲で補間。
- 影（Shadow Map）は使っていない。カメラ構図上、イルカの影が落ちる海底がほぼ画面外になるため。
- 金色の朝（最終段階）は指示文の HEX に合わせているため、やや白っぽく淡い空になる。もう少し濃い金色にするなら水平線色を調整する余地がある。
- 海中にいるイルカはおおむね斜め後ろから見る構図で、画面上はやや小さめ（全身と跳躍の最高点を余白10%で収めるための距離）。
- 珊瑚・魚・岩は手続き生成のローポリ寄りで、近くで見ると簡素。
- 1周は自動プレイ（2倍速）で約4.5〜5.5分、等倍なら約4分。
