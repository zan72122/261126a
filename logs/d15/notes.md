# D15 海から宇宙へ泳ぎ出すイルカ — 実装メモ

## 実装の要点

- 1ファイル `site/games/d15/index.html`（HTML＋CSS＋JS＋GLSL）。Three.js は同梱版を importmap で読む。外部画像・モデル・音声・フォントは使っていない。海・イルカ・珊瑚・雲・月・惑星・地球・星・音はすべてコード内で生成。
- **道のりは1本の曲線**（CatmullRomCurve3, centripetal）。夜の海面 → 跳躍6回（輪の高さ 2.1 / 3 / 4.2 / 6 / 10 / 16）→ 雲の層を抜けて上昇 → 月（半径15）の縁を高度約7で回り込む → 黄褐色のガス惑星（渦の位置は通過する輪の方向に向けて焼き込み）→ 青緑の惑星の大気沿い → 金色の環の上 → 約160°の大きな弧で振り返りながら地球へ。輪24個の位置は曲線の制御点そのもので、弧長で管理。
- **ゲームループ**（状態: `LOADING / READY / APPROACH / WAIT_INPUT / BOOST / TRANSITION / CLIMAX / AFTERGLOW / RESTART`）: 輪の手前の待機点まで泳ぐ → 輪が画面中央に入ったら受付（輪の泡の一部が中心へ流れ込み、発光が強まる）→ タップで同じフレームに尾びれの強い振り＋上昇音 → 輪の中心を通過した瞬間に輪が放射状に弾け、水しぶき／星くずが飛び、段階ごとの成功音。
  - 早いタップは保持して、受付に入った瞬間に跳ぶ。遅いタップでもイルカは待機点の手前でゆっくり泳ぎ続け、輪が後ろへ流れることはない。失敗・減点・時間制限・ゲームオーバーなし。
  - 判定は輪の見た目の1.5倍・最低64px・短辺の34%のうち最大。2本目以降の指（isPrimary=false、別 pointerId）は無視。BOOST 中の連打は無効（輪ごとに1回）。
  - 放置 2.5 秒で輪の発光がゆっくり脈打ち、5 秒で泡が中心に集まる＋予告の鈴＋イルカが少し体を持ち上げる。以後 5 秒ごとに繰り返す。放置だけでは進まない。
- **水しぶき → 星くず**: 1つの粒子プール（high 1200 / mid 600 / low 250、InstancedMesh ではなく Points＋CPU 更新、毎フレーム drawRange のみ更新）。各粒子が「水滴の色」と「星の色」を持ち、6回目の海面離脱時に水滴が追従粒子になってイルカの後ろを追いかける。7回目の輪の通過で全粒子が約2秒かけて個別のタイミングで重力が消え、発光・色（銀・水色・金）・光条のある形へ連続的に変わる（消えて入れ替わるのではなく同じ粒子が変化）。音も水音からガラス質の和音へ移る。
- **海**: Gerstner 波 6 本（波長 2.2〜17、振幅 0.05〜0.30）の頂点変位、細部は法線のゆらぎ。Fresnel 反射、月への反射で縦長の光の道（高次の鏡面＋細かい法線で分裂）。海面はカメラ位置にグリッドスナップして循環、上昇時は拡大してフォグに溶ける。イルカの周りは水を少し澄ませて輪郭が見えるようにした。海底は砂地（コースティクス）＋InstancedMesh の珊瑚（枝状・丸形）。
- **イルカ**: 断面が連続的に変わる胴体（キーフレーム補間の超楕円断面、額から吻への段差あり）＋湾曲した背びれ・胸びれ2枚・水平な尾びれを1つの BufferGeometry に結合。背 `#627F9A`→側面 `#91AFC2`→腹 `#DAE8ED` の頂点カラー。MeshPhysicalMaterial（roughness 0.25, clearcoat 0.42）に段階ごとの手続き環境マップ（PMREM）。泳ぎは頂点シェーダーで上下方向の波（後半から尾へ伝わる）、通常 1.4Hz・加速 2.0Hz。跳躍中は胴が弧を描き胸びれが少し開く。
- **天体**: GPU で正距円筒テクスチャを一度だけ焼き込む（high/mid 1024×512、low 512×256）。月はクレーター（くぼみ＋外縁の隆起）を3オクターブ重ねた高さから物体空間法線マップを作成。ガス惑星は緯度方向の縞＋ノイズ＋回転させた渦、環は RingGeometry＋半径方向の細い縞と隙間・惑星の影。地球は海・大陸（ドメインワープしたノイズ、海岸の浅瀬、砂漠、極氷）・粗さマップ（海は光沢）・陸の起伏法線・別球の雲（1.4%大）・大気（内側 Fresnel と外側のレイ最近接距離による発光殻）。
- **段階の色**: 指示文の表の背景上部/下部・主光源・補助光・輪の色を段階値（0〜3、遷移約3秒）で補間。主光源方向も段階ごとに補間（海では月の方向、地球では左手前から）。ACES、露出 1.2、Bloom（strength 0.5 / radius 0.55 / threshold 0.88）。宇宙でも背景は群青〜紫の星雲で真っ黒にしない。
- **カメラ**: 注視点は常に次の輪の中心（クライマックスは地球の中心）。旋回は最大 14°/秒（クライマックス 10°/秒）、ロール 0。位置はイルカの後方・上方・横 1.8 で、イルカの外接球と輪が縦横どちらにも収まる距離を毎フレーム探索して滑らかに追従（縦画面では自動的に遠くなる）。輪の中心が 2.2° 以内に入ってから受付。クライマックスは大気込みの地球が短辺の約75%に収まる距離へゆっくり引く。
- **クライマックス**: 24回目の通過で輪が金と青白の光に分解、イルカの周りから星くずが広がって地球の縁に沿って周回、大気と海・雲の発光が強まり、Cmaj9 の和音が約4秒響く。白一色のフラッシュはなし。約7.5秒後に余韻（約12秒、地球の前をイルカがゆっくり泳ぐ）→ 星くずが集まって輪になる → 触れると青い光に包まれて最初の海へ戻る（`RESTART` → `READY`）。得点画面・終了画面なし。
- **音**: すべて WebAudio。最初のタップで AudioContext を作成/resume。波（ローパスしたピンク寄りノイズ＋ゆっくりした揺れ）、風、持続音（段階ごとに和音が変化）、鈴、上昇音、水しぶき（ノイズ＋短い高音）、ガラス音、段階ごとに単音→2音→3和音→付加音・オクターブ。マスター 0.32＋コンプレッサー、同時発音数を制限。
- **画質**: high/mid/low（ピクセル比 1.75/1.25/1.0、海の分割 128/80/48、球の分割 64×48/48×32/32×24、粒子 1200/600/250、Bloom 有効/半解像度/無効＝輪の疑似発光を強める、雲の層 3/2/1、星 2600/1800/1100）。初期 mid、直近3秒平均が 50fps 未満を2回続けて観測したら1段下げ、58fps 以上が約10秒続いたら1段上げ、切り替え後はクールダウン。`?q=low|mid|high` で固定（自動変更なし）。全画質とも半精度の中間バッファに描いてから出力する（加算光の見え方を画質間でそろえるため）。シャドウマップは使っていない（海と宇宙では効果が小さいため）。
- **文字なし**: ゲーム画面に文字・数字・ボタンなし。読み込み中は光の粒が集まる CSS アニメーション。
- **操作の抑止**: `touch-action:none`、`overscroll-behavior:none`、`user-select:none`、`-webkit-touch-callout:none`、viewport の拡大禁止、gesturestart / dblclick / contextmenu / touchmove / selectstart / dragstart の既定動作を止める。Pointer Events に統一。
- **自動プレイ** `?autotest`: 同じ `pointerdown` ハンドラーへ合成イベントを送り、通常と同じ判定・状態遷移で 24 回通過 → クライマックス → 余韻 → 再スタートの輪をタップ → `READY` まで進む。途中で、早押し（保持）、3連打、2本目の指、5秒以上の放置（誘導）も試す。時間は 1.35 倍速。開発者向けに `window.__d15`（state / n / stage / q / fps / climax / done / seen / view()）と `[d15]` のコンソールログ。`?at=N` で N 番目の輪から始められる（確認用）。
- `window.__ready`（初回描画後に true）、`window.__errors`（モジュール読み込み前から error / unhandledrejection を記録）、`<meta name="robots" content="noindex">`、`</body>` 直前に `../../gf-playlog.js`。

## 確認結果（このクラウド環境）

- `python3 -m http.server`（ルート `site/`）＋ヘッドレス Chromium（Playwright、SwiftShader: `--use-angle=swiftshader --enable-unsafe-swiftshader`）で `games/d15/index.html?autotest&q=low` を 1024×768 と 768×1024（途中で横に回転して戻す）で実行。記録は `logs/d15/test.txt`、ドライバーは `logs/d15/autotest.js`。
- 両方とも `RESULT: PASS`: `__ready=true`、`__errors=[]`、コンソールエラーなし、24回通過・全4段階・クライマックス・余韻・再スタートまで到達。
- 受付中の輪の中心は画面の x 47〜52% / y 49〜52%（±5% を超えたサンプル 0）。余韻中の地球（大気込み）とイルカは画面外に出たサンプル 0、地球の直径は短辺の約72%。
- 外部へのリクエストはプレイログ送信先（`gf-playlog.js` によるもの。テストでは応答を差し替え）のみ。ゲーム本体は外部通信なしで動く。
- 禁止語（指定4語とそのひらがな・カタカナ表記）が `site/games/d15/`・`logs/d15/` に無いことを grep で確認。
- スクリーンショット: `shot-1.jpg`（序盤：月光の海と輪）、`shot-2.jpg`（中盤：月の縁／惑星の環）、`shot-3.jpg`（クライマックス：地球と星くず）。サムネイル `site/thumbs/d15.jpg`（640×480）。

## 未解決の点・注意

- iPad 実機（Safari）での性能・見え方・音・タッチ感触は未確認。ヘッドレスは CPU 描画（SwiftShader）で 10〜50fps 程度のため、50fps 目標と自動画質調整のしきい値は実機で未検証。
- 「イルカの外接球が画面外」判定で、全サンプルの約3%（主に海上の高い跳躍中や輪の通過直後のカメラ移動中）にわずかに外へ出る瞬間がある。受付中・クライマックス中は 0。
- 海上で 5・6 回目（高さ 10・16）の輪を待つ間は輪と水面のイルカを両方入れるためカメラが遠くなり、イルカが小さめに見える。
- 地球の大陸は手続き生成のため実在の地形ではない（指示どおり）。雲や海の質感は写真ほど細かくはない。
- 惑星・地球は段階に応じて透明度でフェードインするため、フェード中の一瞬だけ前後関係が不自然になる可能性がある。
- PC のマウス操作・実機タッチは、ヘッドレスでの合成ポインターイベントによる確認のみ。
