# D05 蛍光に光る珊瑚の海 — 実装メモ

## 実装の要点

- 1ファイル `site/games/d05/index.html`（HTML＋CSS＋JS＋GLSL）。Three.js は同梱版を importmap で読む（EffectComposer / UnrealBloomPass / OutputPass のみ addons から）。外部画像・モデル・音声・フォントなし。光の円（ハロー）は Canvas で生成。
- 舞台: 水深22mの砂地（複数周波数ノイズ＋砂紋はフラグメントで法線を揺らす）、中央に海底から水深4.6mまで伸びる岩礁の芯（段・こぶ付き、岩肌の法線ノイズ）、半径40m以遠の外側の棚（フリープレイ用）、岩・海草（InstancedMesh、揺れ）。
- 珊瑚: 6形態をプロシージャル生成（枝状＝再帰分岐チューブ、卓状、脳＝迷路状に隆起するドーム、葉状＝波打つ板、ウミウチワ＝平面の再帰分岐、花状＝ポリプ群体）。固定シード乱数で大きさ・角度・太さ・色が個体ごとに違う。各頂点に「根元→先端」の値（aT）を持たせ、シェーダーで発光の前線が根元から枝先へ駆け上がる（前線は白い帯、通過後は先端・ポリプ斑点ほど強く光り、根元は陰影を残す）。眠っている色 `#899DA6`、目覚めの色はピンク/エメラルド/アクア/紫、最後は黄金。
- 珊瑚の塔: 20個の操作対象を芯の周りに螺旋状に配置（第1段階は裾、以降は上へ）。周辺の装飾珊瑚を段階ごとに1メッシュへ結合し、頂点ごとの遅延値で「目覚めた珊瑚の近くから順に」光と成長（0.55→1倍）が連鎖する。5個ごとに段階の群が全部点灯＋塔を下から上へ多色の光が上る。第3段階以降はタップ位置から上下へ光が伝わり、既に目覚めた珊瑚も呼応する。
- イルカ: バンドウイルカの断面プロファイル（吻・メロン・胴・尾柄）を Catmull-Rom 補間したロフトメッシュ＋背びれ・胸びれ・尾びれ（翼断面のロフト）＋目。背は青灰 `#5d7385`、腹は白に近い灰のカウンターシェーディング、roughness 0.3。泳ぎは頂点シェーダーで胴体後部→尾びれへ位相をずらした上下運動（法線も補正）。母 2.8m・子 1.7m。母は子の斜め前方を並走し、ときどき子の方を向く。
- 熱帯魚: 6種（黄・青・白黄・橙白帯・紫黄・水色黄）のロフト魚（背びれ・尻びれ・尾びれは断面の上下拡張）を InstancedMesh で描画、尾は左右に振る。魚群は簡易ばねモデルで「珊瑚の周回」「次の珊瑚への光の道（種ごとの色の帯）」「塔の螺旋」「イルカの周り」を切り替える。鱗に珊瑚の色がフレネルで映り、光の道では尾の後ろに短い光の粒が残る。数は段階で 24→48→80→120（high、品質で縮小）。
- 水中の光学: 自前の霧（距離の吸収＋上下で明暗が変わる水の色、背景も同じ式で描くので境目が出ない。発光は霧を一部透過）、コースティクス（0.2〜0.4Hz の2層、上向きの面・イルカの背に投影）、水面から下へ伸びる半透明の円錐の光芒、奥行きで見え方が変わる浮遊粒子、宝石のような気泡（リング＋ハイライトの点スプライト）、目覚めた珊瑚ごとの色付き点光源（品質で 4/2/1）。
- 水面: 4方向の深水波（振幅 0.04〜0.13m、波長 1.6〜5.5m）＋跳躍の波紋。下からは屈折率 1.333 の屈折で空を映す（窓の外は全反射）。上からはフレネル反射で夕焼け〜星空・月光の照り返し、水中の塔の光が透けて見える。
- 空: 段階の表の色（水面付近の空・海の基調色・上からの光・強さ・霧の距離・ブルーム強度）を進行度 0〜3 で連続補間。夕暮れ→日没直後→薄暮→星空。雲はノイズ、星は点群（瞬き）、月はシェーダー。
- ループ: 気泡が対象の周りを旋回→枝先へ集まる。3秒無操作で先端に光が走り、6秒で母イルカが対象を向き気泡の輪が大きくなる（繰り返し）。タップで光の波紋、枝を駆ける発光、色付きの気泡、周囲の色の光、魚の集合、イルカの前進、成功音（段階ごとに 2→3→4→6 音）。外れたタップは小さな水の波紋と気泡だけ。
- クライマックス（約21秒＋余韻）: 黄金の光が塔の頂上から海底へ → 多色の光が海底から頂上へ（全珊瑚が順に呼応、魚の螺旋、大量の気泡、点光源が光の前線に沿って回る）→ カメラが引いて塔全体 → 親子が光の道に沿って上昇し、ほぼ並んで水面を突破（高さ約2.5mの放物線、飛沫・水面の波紋・星空）→ 着水 → 水面越しに輝く塔を見せる余韻（約10秒）→ 潜って外側の棚へ移動し、新しい眠った珊瑚が育つ → フリープレイ（8個のプールを再利用し、種類と色を巡回。メッシュは増えない）。
- カメラ: 対象の中心を注視点にし、対象の BoundingBox の8隅とイルカの主要点（吻・尾びれ先・背びれ・胸びれなど）を画面座標に投影して、四辺8%の余白に収まる撮影距離を閉形式で計算。注視点の移動速度と方位の変化を毎秒約20度に制限、時定数 0.6〜0.9 秒で補間、ロール0。水面より上に出ない（クライマックスは指定の高さで水面を越える）、海底・塔にめり込まない。縦向きは FOV 52° と横方向の配置間隔を詰める。
- 音: すべて WebAudio。低いフィルター付きノイズの環境音（浅くなるほどカットオフが上がる）、ときどきの気泡音、成功音（C メジャーペンタトニック、sine＋triangle、残響）、魚の到着のきらめき、上昇音、クライマックスの和音（C2〜G6）、水面突破の飛沫音、水上では風と波。マスターに DynamicsCompressor。最初の実際のタップで AudioContext を生成/再開。
- 画質: low/mid/high（ピクセル比 1/1.25/1.75、影 なし/1024/2048、ブルーム なし（ハローの簡易発光）/0.33/0.5、浮遊粒子 160/400/800、魚 36/72/120、気泡 24/45/80、点光源 1/2/4、装飾珊瑚の LOD 低/中/高）。初期 mid、3秒平均 48fps 未満で下げる、12秒平均 57fps 以上で上げる（クールダウンあり、クライマックス中は上げない）。`?q=low|mid|high` で固定（自動切替なし）。
- 状態: READY / WAIT_TOUCH / AWAKEN / SWIM / STAGE_TRANSITION / CLIMAX / AFTERGLOW / FREE_PLAY。時間は経過時間ベース、非表示中は停止。回転・リサイズで進行は保たれる。
- 入力: Pointer Events（タッチ・マウス共通）、最初の1本の指だけ受け付け、pointercancel 処理、当たり判定は見えない球（Raycaster）＋画面上の半径（最低 72px＝直径 144px）。連打・多指は状態チェックで1回だけ加算。スクロール・ピンチ・ダブルタップ・長押しメニュー・選択を抑止。
- 必須項目: `<meta name="robots" content="noindex">`、`</body>` 直前の `gf-playlog.js`、`window.__ready`（3フレーム描画後 true）、`window.__errors`（error / unhandledrejection / リソース読込失敗 / WebGL コンテキスト喪失 / フレーム内の例外）。
- `?autotest`: 通常のタップと同じ `handleTap()` に対象の画面座標を渡して20個→クライマックス→余韻→フリープレイ3回まで進む（2個目の待ちで画面隅を1回外し打ち、4個目で3連打）。時間は3倍速。結果は `window.__autotest`、確認用に `window.__game.probe()`。
- 確認用パラメータ: `?skip=N`（N個目覚めた状態から開始）、`?ts=倍率`（時間倍率）、`?debug`。

## 確認結果（このクラウド環境）

- `python3 -m http.server`（ルート `site/`）＋ Playwright の Chromium（ヘッドレス、`--use-angle=swiftshader --enable-unsafe-swiftshader`）。
- `games/d05/index.html?autotest&q=low` を 1024x768（横）と 768x1024（縦）で通し実行。結果は `logs/d05/test.txt`。
  - 1024x768: `__ready`=true（約2.4秒）、`__errors`=[]、コンソールエラーなし、全状態（クライマックス・余韻・フリープレイ）到達、PASS。操作待ち中の対象の中心ずれ 最大0.36%（基準5%）、対象の見切れ 0。イルカの一部が画面外になったサンプル 1/1428（余韻後に外側の棚へ潜る移動中、はみ出し約5.6%）。クライマックス中は 0。
  - 768x1024: 同上 PASS。中心ずれ 最大0.61%、対象・イルカの見切れ 0/2226。
  - タップ時の中心ずれ（ゲーム内計測）: 最大 0.08%（横）/ 0.14%（縦）。
  - mid / high でも起動し `__errors` 空を確認（スクリーンショットで目視）。
  - 外部リクエストは gf-playlog の送信のみ（テストでは 204 を返した）。
- スクリーンショット: `shot-1.jpg`（序盤・3個目のエメラルドの珊瑚が目覚める瞬間）、`shot-2.jpg`（中盤・13個目、光の波紋と魚）、`shot-3.jpg`（クライマックス・星空への跳躍）。サムネイル `site/thumbs/d05.jpg`（640x480、中盤の塔とイルカ）。
- 禁止語の grep（ソース・メモ、ひらがな・カタカナ表記含む）: 該当なし。

## 未解決の点・注意

- iPad 実機での性能（50fps 目標）と見た目は未検証。ヘッドレスは SwiftShader（CPU 描画、約4〜5fps）のため FPS は参考にならず、通し確認は low のみ。
- 390x844（iPhone 縦）は今回テストしていない（縦向きの FOV と余白計算で対応する設計）。
- 余韻後に外側の棚へ移動する数秒間、イルカの尾が画面端からわずかにはみ出すことがある（横向きで1サンプル）。
- 岩礁の芯はまだ「岩の柱」の印象が残る部分がある（装飾珊瑚の密度を上げると改善するが描画負荷とのバランス）。装飾珊瑚の LOD は起動時の画質で決まり、実行中の画質切替では作り直さない。
- 余韻の水上からの見下ろしでは水中が紫色の霞で一様に見える。
- 影は直射光1つ・カメラ周辺のみ（mid/high）。シェーダーで動かすイルカの尾・魚の尾は影に反映されない。
