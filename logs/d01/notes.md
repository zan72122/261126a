# D01 実装メモ（月夜の港町から、一番輝く星へ）

## 実装の要点
- 1ファイル `site/games/d01/index.html`（HTML+CSS+JS）。Three.js は同梱版を importmap で読込。CDN・外部画像・外部モデル・音声ファイルなし（テクスチャは CanvasTexture / DataTexture、音は WebAudio で合成）。
- `<meta name="robots" content="noindex">`、`</body>` 直前に `../../gf-playlog.js`。`window.__ready` / `window.__errors`（error・unhandledrejection・初期化/フレーム例外を記録）。
- 状態: WAITING → TRANSFORMING → JOINING → ADVANCING → … ×18 → STAR_WAITING → CLIMAX(16秒) → AFTERGLOW(12秒) → フリープレイ（`G.free`、同じ状態機械を再利用）。成功回数・段階・点灯区画・仲間・音・カメラはすべて `G` から決まる。
- 1回の成功で「雲→動物（puff 補間）」「仲間が隊列へ」「町の1区画が連鎖点灯＋川面の反射が出現」「光の粒が動物から町と星へ流れる」「星が一段大きくなる」が連動。6回目で石橋と川沿いの街灯が連鎖点灯、12回目と18回目は川沿いを光の波が走る。
- 動物6種（クジラ・馬・白鳥・イルカ・ウサギ・シカ）は関節付き楕円体パーツの骨格で、雲の puff が各パーツへ補間移動。再登場時は大きさ・銀色の濃淡・動作速度を変える。最初はクジラ。
- 雲: InstancedMesh の puff（頂点ノイズ変形＋月側の銀の縁取り＋密度陰影＋輪郭の微粒子）。毎フレーム奥→手前に並べ替えて半透明合成。
- 水面: 自作シェーダー。タイル可能な波の傾きテクスチャ（ミップマップ付き）を複数スケールで重ね、フレネル、月光の銀の帯、窓・街灯の疑似反射（区画の点灯度に連動）、川の中央/岸で色と波の強さを変える。
- 白い鳥: 旋盤体の胴＋先細りの首＋頭/くちばし、羽は InstancedMesh の羽根（初列・次列風切、大/中雨覆、小翼羽、尾羽）を毎フレーム配置。3〜5秒ごとに羽ばたき、それ以外は滑空。初列風切は1枚ずつしなる。カメラは鳥ではなくリグに追従するので羽ばたきで揺れない。
- カメラ: 常に操作対象（雲／変身中の動物／星）を注視（lookAt）、ロールなし、角速度上限 9°/秒。仲間は「カメラ座標系の画面スロット（NDC）」に配置するので画面外に出ない。横向き・縦向きで別のスロット表。縦長ほどカメラを引く。
- 画質: low/mid/high（ピクセル比・影・ブルーム・粒子数・puff 数・背景の星・波の合成数・反射光源数）。起動は mid → 計測で初期画質を決定 → 移動平均 FPS で 45 未満3秒で下げ、58 以上12秒で上げ、切替後10秒の猶予。`?q=` 指定時と `?autotest` 時は自動切替なし。
- 入力: Pointer Events、最初の1本だけ処理、pointercancel/blur/回転で復帰、ピンチ・ダブルタップ・スクロール・長押し・選択を抑止。判定は見た目の1.5倍の球へのレイ判定＋画面距離（最低半径 40px）。誤タップは小さなきらめきと小さな音だけ。
- 音: 最初の pointerdown（と pointerup/touchend）で AudioContext を生成/resume。D メジャー・ペンタトニック。段階ごとに和音を厚く。風・水音・持続音は合成ノイズ/オシレーター。Master Gain + DynamicsCompressor。
- `?autotest`: 通常と同じ `handleTap()` を、対象の画面座標で呼ぶ（成功回数を直接書き換えない）。演出時間は3倍速。フリープレイで1回成功すると `__d01.done = true`。テスト用に `window.__d01`（state/count/bounds/hold）を公開。画面には何も表示しない。
- 画面に文字・数字なし（ロード中は脈動する光の円だけ）。

## 確認結果（このクラウド環境、ヘッドレス Chromium + SwiftShader）
- 詳細は `logs/d01/test.txt`。
- `?autotest` で 1024x768 / 768x1024（low）、1024x768（mid・high）、1194x834 / 834x1194 / 390x844 / 1440x900（low）を実行し、すべて `__ready=true`、`__errors=[]`、コンソールエラーなし、18回→星→クライマックス→余韻→フリープレイ到達（PASS）。
- 対象の画面中心からのずれ: 雲待ち・星待ち・クライマックス(星接近中)とも NDC 0.000。
- 仲間の外接円の最大 |NDC|: 約 0.81〜0.85（画面端から約 7.5〜9.5% の余白）。翼端の最大 |NDC|: 約 0.5〜0.78。
- クライマックスの星の最大の見かけの大きさ: 短辺の 0.62（画面内に収まる）。
- スクリーンショット: `shot-1.jpg`（第1段階、雲をタップした瞬間）、`shot-2.jpg`（第2段階、10体）、`shot-3.jpg`（クライマックス、18体の編隊と星）。
- サムネイル: `site/thumbs/d01.jpg`（640x480）。
- gf-playlog の外部送信は、このサンドボックスにインターネットがないためテスト時だけローカルで 204 を返した（ゲーム側の挙動ではない）。

## 未解決・未検証
- 実機（iPad Safari）での FPS・タッチ・音の確認はしていない。SwiftShader（CPU 描画）では low で約10fps、high で約5fps なので、実機の 50fps 目標は未実測。
- 音はヘッドレスでは鳴らせないため、合成処理がエラーなく動くことしか確認していない（autotest は無音）。
- 自動画質切替はコード上の実装のみで、実機での切替挙動は未確認（テストは `?q=` 固定）。
- 低画質（puff 40個）では細い脚などがやや粗い。高画質ほど動物の形がはっきりする。
- クライマックスで翼を広げた鳥はカメラとほぼ同じ高さのため、翼が細い線に見える瞬間がある。
